# 역사 연표 (History Timeline)

동아시아사를 한눈에 보는 연표 프로그램입니다. 설치 없이 **`index.html` 파일을 더블클릭**하면 브라우저에서 바로 열립니다.
다른 지역·주제의 역사는 **DLC(팩 파일 .htpack — 또는 .json)** 로 얼마든지 추가할 수 있고, DLC는 함께 들어 있는 **DLC 메이커**(`dlc-maker.html`)로 직접 만들 수 있습니다. 연표는 **보기 전용**이고, 고치는 일은 모두 메이커에서 합니다.

현재 `codex/desktop-next` 작업본의 대상은 **웹 · PWA(설치형 웹앱) · Windows 프로그램**입니다. 일반 휴대폰 브라우저의 터치 · 좁은 화면 동작은 유지합니다. 안드로이드 앱 포팅은 별도 작업본에 보존하며, 분리 내용을 `master`에 반영하는 일은 감독 확인을 기다립니다. 위치와 이어가는 방법은 [모바일 분리 안내](docs/모바일-분리.md)를 보세요.

> 크롬 또는 엣지 브라우저를 권장합니다. (파이어폭스는 보안 정책 때문에 파일을 직접 열면 저장 기능이 동작하지 않을 수 있습니다.)

## 1. 기본으로 들어 있는 내용

**동아시아사 기본팩** — 한국 · 중국 · 일본 · 베트남 4개 트랙, 시대 84개와 사건 200여 개 (흉노·돌궐·요·금·몽골 같은 북방 정권은 중국 트랙 안의 정권으로 함께 놓입니다)
(고조선·상나라부터 현대까지. 고대의 건국 연도 등 전승에 따른 연대는 빗금 막대와 설명으로 표시했습니다.)

## 1-1. 연표를 읽는 방식 — 트랙 › 민족 › 정권 띠

한 나라 안에서도 정권이 동시에 여럿일 때가 많습니다(요·금·송, 삼국 시대, 남북조, 군벌 할거기). 그래서 **정권마다 자기 줄(띠)을 갖고, 그 정권의 사건이 자기 띠 안에 놓입니다.**

```
┌ 트랙(나라) ┬ 민족 ┬ 정권 띠 ─────────────────────────────────────────┐
│           │      │ ┌ 지도자 칸 ─ 태조 │ 정종 │ 태종 │ 세종 … ┐   ← [지도자]   │
│   한      │ 한   │ │ 내각 칸 ──── 김홍집 내각 ─────────────┤   ← [내각]     │
│   국      │ 민   │ │ ● 사건 이름 1592년      ● 사건 이름   │   ← 사건 줄     │
│           │ 족   │ │ ├──────────┤   ├─────────────┤       │   ← 기간 레일   │
│           │      │ └──────────────────────────────────────┘                │
└───────────┴──────┴───────────────────────────────────────────────────────────┘
```

* **트랙** — 나라·지역. 왼쪽 세로 이름을 누르면 트랙이 **접혀** 가는 막대만 남습니다. 필터 바의 `모두 접기 / 모두 펴기`로 한 번에 접습니다.
* **민족** — 트랙 안에서 정권을 묶는 세로 칸. 대명제 → 세부 민족처럼 **여러 단계**로 나뉘며(한민족 › 예맥·한(삼한), 오호 › 흉노족·선비족 …, 후기 유력 이민족 › 거란족·몽골계 › 몽골족 …) 단계마다 칸이 하나씩 놓입니다. 어느 칸이든 누르면 그 아래가 통째로 접혀 한 줄에 가는 막대로 남고, 다시 누르면 펼쳐집니다.
* **정권 띠** — **승계(직접 · 간접 · 부흥 · 부분)로 이어진 정권만 같은 줄**을 이어 씁니다(조선 → 대한제국, 후금 → 청). 관계가 없으면 같은 민족이라도 새 줄입니다. 왼쓴 라벨은 지금 화면 가운데 시기의 정권을 보여 주며, 시간을 옮기면 따라 바뀝니다. 정권이 아무리 많아도 이름을 숨기지 않고 세로로 늘어납니다(스크롤).
* **건국·멸망 네모와 승계선** — 띠 안쪽 왼쪽 끝에 채운 둥근 네모(건국), 오른쪽 끝에 빈 둥근 네모(멸망·종료)가 찍히고, 승계 관계가 있으면 줄 사이 통로를 따라가는 꺾은선으로 이어집니다. **직접 승계는 실선, 간접 승계(지역·거시적 승계)는 점선, 부흥은 점선에 작은 고리, 부분 승계는 가는 실선**(나라는 끊겼으나 지배층 · 백성 · 영역 · 제도 · 문화의 일부가 넘어감 — 직접 승계의 굵은 실선보다 가는 한 줄. 정도 약 · 중 · 강과 이어진 것은 선에 올리거나 상세 창에서 글로 봄). 같은 줄에서 **곧바로 이어지면**(두 띠가 맞닿거나 가까우면) 이음매 쪽 네모가 조금(맞닿으면 3px) 안으로 비켜 앉고 두 네모 사이에 **다리**가 놓입니다 — 왼쪽 반은 앞 나라, 오른쪽 반은 뒤 나라의 테두리색이고, 선이 지나는 띠 테두리는 **문**처럼 열립니다(간접 승계는 이음매 한가운데가 빈 점선, 부흥은 이음매 위 작은 고리). 틈이 벌어지면 같은 다리가 그대로 길어지고, 네모가 생략될 만큼 멀리서 보거나 이음매 쪽 끝에 연대 폭 · 미정이 있으면 다리 없이 띠 뒤 선만 남습니다. 다른 줄로 곧바로 이어지면 멸망 네모 밑(위)에서 곧게 나오는 **내림줄**(선대 띠의 그쪽이 칸 · 사건으로 막혔으면 후대의 건국 네모로 곧게 드는 **오름줄**)로 잇고, 해가 실제로 겹칠 때만 줄 사이 빈 곳(책갈피 탭 위의 틈)으로 돌아갑니다. 어느 선이든 네모에서 띠 테두리까지의 끝은 띠 위에 짙게 그려져 선이 네모에 닿는 모습이 보이고(연대 폭이 있는 끝은 네모가 끝 해에 서서 테두리와 떨어져 있으므로 빼고), 사건 글자는 네모 · 내림줄을 1.5px 넘게 비켜 갑니다. 같은 해에 시작하는 나라들이 앞 나라의 줄을 나눌 때는 직접 승계가 먼저입니다(한 앞 나라의 줄을 둘이 다투면 직접 승계가 잇고, 그다음 부흥 · 간접, 부분 승계가 마지막이며, 직접 · 간접 앞 나라를 함께 둔 나라는 직접 쪽 줄을 이음). **이미 있던 나라로 들어가는 승계(합류)** — 뒤 나라가 앞 나라의 끝보다 먼저 있었고 앞 나라가 끝난 뒤에도 이어지면, 선은 뒤 나라의 건국 네모로 거꾸로 돌아가지 않고 멸망 네모 밑(위)에서 곧게 내려가(올라가) **그해의 띠 테두리**에 닿으며, 닿는 자리에 앞 나라 색의 짧은 **합류 조각**이 놓입니다(상세 창에는 `· 640년 합류`). 승계 종류와 상관없이 같습니다 — 앞 나라 띠 안의 그쪽이 칸 · 사건으로 막혀 있으면 띠 밖 통로로 곧게 내려가고, 뒤 나라의 책갈피 탭이나 둥근 모서리에 걸릴 자리면 예전처럼 건국 네모로 돌아갑니다. 평소에는 옅게 보이다가 띠에 마우스를 올리거나 고르면 그 정권의 선만 진해집니다(굵기는 그대로 — 띠 위의 다리 · 관문은 처음부터 짙고, 그 위를 누르면 밑의 띠가 골라짐). 그림 내보내기(PNG · SVG)에도 네모 · 승계선 · 다리 · 소속선이 화면과 같은 자리에 들어갑니다. 메뉴의 `승계선`에서 모두 / 직접만 / 숨기기를 고릅니다.
* **빈 줄 접기** — 지금 화면 범위에 아무것도 없는 줄은 높이까지 접혀 아래 줄이 위로 올라옵니다. 시간을 옮기면 부드럽게 다시 펼쳐집니다.
* **지도자 칸 / 내각 칸** — 띠 위쪽 두 줄. 대한제국의 고종과 박제순 내각, 일본의 메이지 천황과 가쓰라 내각처럼 지도자와 내각이 공존한 시기를 나란히 봅니다. 지도자는 묘호·시호·이름·대수를 따로 가질 수 있어 `지도자: 기본 이름 / 묘호 / 시호 / 이름 / 묘호·시호 / 모두`로 표기를 바꾸고 `대수` 체크로 "4대 세종"처럼 붙입니다. 이어지는 지도자 칸은 하나의 긴 둥근 칸에 가는 구분선으로 나뉘고(맨 위 연호 줄도 한 왕조의 연호는 이어서, 간지 줄은 해마다 이어서), 비는 해가 있거나 왕조가 바뀌는 곳에서만 끊깁니다. 좁으면 앞글자만 보이고 마우스를 올리면 전체가 뜹니다. 각각 `지도자`·`내각` 체크로 켜고 끕니다.
* **시기 구분(학계)** — 후대 학계가 한 나라 안을 나눈 시기(앞 시기 · 가운데 시기 · 뒤 시기 …)를 띠 안 **왕조 칸 아래 · 지도자 칸 위**에 얇은 줄로 봅니다. 출전 · 학설마다 이름도 경계도 다를 수 있어 **체계를 여럿** 적을 수 있고, 체계마다 한 줄씩(한 띠에 셋까지) 쌓이며 줄 왼쪽 끝에 작은 체계 이름이 붙습니다. 나라 색이 아니라 종이빛 중립으로 조용하게 그려 왕조 칸과 헷갈리지 않고, 시기 구분이 있는 줄만 그만큼 높아집니다. 시기를 누르면 그 기간이 띠 안에 조명되고 시기 창이 열려, 같은 체계의 앞뒤 시기와 **체계 견주기**(모든 체계를 같은 시간 축에 나란히 — 경계가 어떻게 다른지 한눈에)를 봅니다. 필터의 `시기`로 켜고 끄며 `빽빽하게` · `조감`에서는 숨습니다. 맨 위 날짜 칸의 `시대 구분`(여러 나라에 걸친 큰 시대)과는 다른 것입니다. 형식은 `DLC-형식.md`의 "시기 구분(학계)", 예시는 견본 `samples/sample-lantern.json`(등불 왕국 · 하연 연합 왕국 · 설원 제국).
* **지위** — 정권의 지위(공 → 왕 → 황제 …)가 바뀐 나라는 띠 안 **지도자 칸 위**(시기 구분이 있으면 그 아래)에 얇은 **지위 단**이 생깁니다. 이어지는 지위는 하나의 긴 둥근 칸에 가는 구분선이고, **서열이 높을수록 나라 색이 짙게**(지위 사전의 서열을 네 묶음으로 — 같은 지위는 어느 나라에서나 같은 짙기, 대통령 · 총리처럼 서열 밖은 중립) 그립니다. 지위가 하나뿐인 나라는 단 대신 책갈피 탭의 이름 뒤에 작은 지위 딱지가 붙고, 지위 단은 지위가 바뀐 나라가 있는 줄만 그만큼 높아집니다. 지위를 누르면 그 기간이 조명되고 지위 창(서열 · 지위 변천의 승격 ▲ · 격하 ▼ · 그 기간의 지도자)이 열립니다. 지도자에게만 지위를 적어도 변천이 끌어내지고, 지도자 칸 설명글 · 왼쪽 줄 이름 아래 부제 · 같은 해 보기에도 지위가 나옵니다. 내장 사전은 서열 뼈대(황제 · 왕 · 대공 · 공 · 후 · 백 · 자 · 남과 서열 밖의 대통령 · 총리 · 주석 · 섭정)뿐이고, 문화권마다 다른 칭호는 DLC의 지위 사전(`rankDefs`)에 서열 · 별칭과 함께 적습니다. 필터의 `지위`로 켜고 끄며 `빽빽하게` · `조감`에서는 단이 숨습니다. 형식은 `DLC-형식.md`의 "지위", 예시는 견본 `samples/sample-lantern.json`(등불 왕국의 격하 · 적석 왕국의 승격 · 지위 사전의 등왕과 도선장).
* 어느 정권에도 속하지 않는 사건은 트랙 맨 아래 **"그 밖"** 줄의 가는 선 위에 놓입니다.
* **사건 분류별 글줄** — 한 띠에 사건 분류가 둘 이상이면 분류마다 글줄이 하나씩 생기고 그만큼 띠가 높아집니다(정치 → 전쟁 → 외교·교류 → 사회·경제 → 문화·사상 순, 그 띠에 없는 분류는 건너뜀). 글줄 사이는 옅은 점선, 왼쪽 줄 이름 칸 오른쪽 끝의 색 점이 어느 분류의 글줄인지 알려 줍니다(올리면 이름). 분류가 하나뿐인 띠는 예전처럼 글줄 1~2개(정권이 6개를 넘는 트랙은 한 줄)에 자유롭게 놓입니다.
* `넉넉하게 / 자동 / 빽빽하게`로 직접 조절할 수 있습니다. `빽빽하게`는 분류를 가리지 않고 모든 사건을 한 글줄에 모읍니다.
* **조감** — 나라가 많아 전체 구도가 한눈에 들지 않을 때: 밀도 목록의 넷째 `조감`(또는 `V` 키 · 확대 단추 옆 `↕`)을 고르면 줄이 **띠 하나 높이**(14px · 줄 사이 6px)로 줄어, 기본팩을 한 화면에 볼 때 37줄 가운데 35줄쯤이 듭니다(`빽빽하게`는 7줄쯤). 칸 · 책갈피 탭 · 사건 글자 · 기간 막대 · 인물 단 · 기관 칸과 이설 표시(시대 띠 윗변의 다른 견해 고리 · 칸의 유령 구분선 · 칸을 고르면 나오는 이설 조명 — 상세 창에는 그대로)는 빠지고(칸 조명과 `같은 시기를 타국에도`의 칠은 조감에서도 띠 안에 그대로 · 맨 위 날짜 칸은 크기도 이설 표시도 그대로), 나라 이름은 **띠 안 왼쪽**에 — 띠 시작에 붙어 있고(화면 가장자리를 따라오지 않음 — 옆으로 옮겨도 점이 숨거나 드러나지 않게), 들어가는 대로 이름 → 첫 글자 → 없음. 띠 시작이 화면 왼쪽 밖이거나 이름 끝이 오른쪽 밖이면 반쯤 잘린 이름 대신 이름 없이 둡니다(그 자리는 그대로 비워 둠). 사건은 작은 점과 개수 알약으로 남되, 이름과 그 둘레에 걸린 점은 옮기지 않고 숨깁니다. 네모가 없으므로 승계선은 **띠 끝 가운데**에 닿습니다 — 테두리에 문을 열고 3px 들어간 짧은 끝이 관문이고, 곧바로 이어지면 두 짧은 끝 사이가 다리(맞닿으면 문 하나), 다른 줄로 맞닿으면 멸망 네모가 있을 자리에서 곧게 내려오는 내림줄입니다. 소속 펼치기 `▸n` · 할거 `▸ 〈성격〉 n`은 이름 뒤의 작은 단추로 남습니다. 모양은 필터 바의 `조감:` 목록에서 — `이름 + 점`(기본) · `이름만`(점 · 알약 없이) · `띠 · 선만`(8px로 가장 낮게, 글자 없이 — 이름은 띠에 올리면 풍선으로, 왼쪽 줄 이름 칸은 색 점만). 필터 바의 `축소하면 조감`(기본 끔)을 켜면 보기 폭이 2,600년을 넘을 때(사건 이름이 모두 꺼지는 넓이) 저절로 조감으로 들어가고 2,392년 아래로 좁히면 고른 밀도로 돌아옵니다 — 문턱이 두 개라 경계에서 깜빡이지 않고, 끌거나 굴리는 동안이 아니라 손을 뗀 뒤 한 번에 바뀝니다. 자동으로 든 조감을 `↕` · `V`로 풀면 다시 좁혔다 넓힐 때까지 쉽니다. 밀도를 바꾸면(조감 ↔ 다른 밀도 · 넉넉 ↔ 빽빽도) 줄 높이 · 왼쪽 줄 이름 · 민족 칸이 한 번에 흐르고 옛 칸 · 글자는 옅어지며 새 것이 떠오르며, 보던 줄은 화면에서 제자리입니다(내용이 화면보다 짧아지면 스크롤이 닿는 데까지 — 한 방향으로). 조감에서 손으로 옮기거나 무엇을 고르지 않고 나오면 들기 전에 보던 줄이 그때의 자리로 돌아옵니다. 고른 밀도 · 모양 · 자동 조감은 브라우저에 기억되고, 그림 내보내기도 화면과 같은 조감으로 나옵니다.
* 왼쪽 줄 이름이 칸보다 길면 연도를 빼고, 그래도 넘치면 글자를 10px까지 줄이며, 그래도 안 되면 괄호 속 딴이름을 뗀 이름으로 적습니다(말줄임 없이 — 온 이름은 풍선에). 민족 칸 · 민족 딱지 · 트랙 이름의 세로 글도 칸에 다 들지 않으면 뜻이 남는 차례로 줄입니다 — 괄호를 떼거나(`한(삼한)` → `한`), 한 낱말이면 끝의 `족`을 떼고 그다음 첫 글자(`흉노족` → `흉노` → `흉` — 책갈피 탭의 첫 글자와 같은 말투), 여러 낱말이면 첫 낱말까지만(`초기 유력 이민족` → `초기` · `여진-만주족` → `여진`). 여러 낱말 이름을 잘라 뜻 없는 한 글자(`초` · `후`)를 만들지는 않고, 그것도 안 되면 글 없이 칸의 색으로만 둡니다(이름은 풍선에).

### 맨 위 날짜 칸 — 연도 · 간지 · 연호 묶음 · 도읍 묶음

```
  4,631년 보기 │ 기원전 2000        0        1000        2000      ← 연도
  간지         │ … 갑자 1864 ┆ 갑자 1924 …  (확대하면 해마다)     ← [간지]
  연호 2개 나라 ▸│ ━━━━━━━  ━━━━━━━━━━                        ← 접힌 묶음: 나라마다 가는 막대
  도읍 ▾        │                                                ← 펼친 묶음 (누르면 접힘)
   └ 한국 배도 ▸ │ ( 철원 | 개경 ┆ 강화 ┆ 개경 )( 한양 …        ← 천도 = 구분선, 임시 = 점선 칸
   └ 중국       │  ( 남경 | 북경 …                                ← 겹치면 갈래가 나뉨
```

* **간지(육십갑자)** — 넓게 보면 갑자년만, 조금 확대하면 몇 해마다, 더 확대하면 해마다 간지가 붙습니다. 갑자년은 강조됩니다.
* **연호·도읍 묶음** — 나라가 많아도 날짜 칸이 길어지지 않도록 `연호`·`도읍`은 큰 묶음 한 줄로 접혀 있습니다. 묶음 이름(또는 막대 자리)을 누르면 그 안에 나라별 줄이 펼쳐지고, 펼친 상태는 기억됩니다.
* **연호** — 각 나라가 **스스로 선포한 연호만** 그 나라 줄에 놓입니다(빌려 쓴 연호는 넣지 않음). 명·청처럼 같은 시기에 두 정권이 연호를 쓰면 **갈래**가 나뉘고, 줄 왼쪽 라벨(`중국 ▾`)을 누르면 한 줄로 접힙니다.
* **도읍** — 한 정권의 도읍은 하나의 긴 둥근 칸으로 이어지고 천도한 곳에 가는 구분선, 임시 도읍(강화 천도·피난)은 점선 칸입니다. 도읍 칸에 올리면 **같은 도시를 도읍으로 쓴 다른 나라 칸까지 함께 진해집니다**(평양 = 고구려 평양성 · 고려 서경). 배도(별도·5경·소경)는 나라 이름 옆 `배도 n ▸`로 아래 옅은 갈래에 펼칩니다.
* **도읍 노선도 카드** — 도읍이 있는 정권은 왼쪽 줄 이름 뒤에 작은 노선 표시가 붙습니다. 줄 이름에 잠깐 올리면(키보드 Enter, 상세 패널 `🚇 노선도`) 그 정권의 도읍 내력이 지하철 노선도로 뜹니다 — 본선 = 정도, 위 지선 = 배도, 아래 점선 우회선 = 임시 도읍, 겹고리 ⇄ = 같은 도시를 쓴 다른 나라(환승). 역을 누르면 그 시기로 가고, 📌로 고정하며, 아래 칩(← →)으로 같은 트랙의 다른 정권으로 넘어갑니다.

### 정권의 종류

정권(시대)은 다섯 종류로 나뉘고 띠 모양이 다릅니다. 여기에 시대와는 따로 적는 **기관**과 **문화**가 더해집니다. 필터 바의 `종류` 칩(두 종류 이상 있을 때 나타남)으로 켜고 끕니다.

| 종류 | 모양 | 예 |
| --- | --- | --- |
| **국가** (기본) | 보통 띠 | 조선, 당 |
| **종속국** | 옅은 띠 — 섬긴 나라(상국)의 띠 아래에 이름표로 매달림(아래 '자율성이 다른 나라와 소속 관계') | 보호국·속국 |
| **연맹** | 속이 빈 겹줄 띠 | 가야 연맹 (구성국은 "소속"으로 연맹을 가리킴) |
| **조직체** | 모서리가 각진 가는 점선 띠 | 절도사, 막부, 군벌 |
| **시대 이름** | 테두리 없는 옅은 띠 | 야요이 시대, 전국 시대 |
| **기관** *(따로 적음)* | 아주 옅게 그립니다. 통감부 같은 **기관**은 시대 띠 안 맨 아래(기간 막대 아래)의 기관 칸에, 조계지·조차지 같은 **구역**은 시대 띠 아래로 살짝 내려오는 탭으로. 제 줄이 없습니다 | 통감부·총독부(대한제국 위에), 조계지·조차지(청·중화민국 위에), 군정청 |
| **문화** *(따로 적음)* | 승계한 국가의 줄 **밑에 깔리는 바탕 띠**(옅은 무늬). 승계국이 없으면 트랙 맨 위 "문화" 묶음 | 빗살무늬토기 문화, 청동기 문화, 조몬 문화 (국가 이전) |
| **왕조** *(따로 적음)* | 다스린 나라 띠 **맨 위의 왕조 칸**에 왕조마다 긴 둥근 칸. 그 나라의 지도자 칸은 왕조가 바뀌는 곳에서 끊기고, 줄 이름 아래에 지금 왕조가 함께 나옵니다. 나라와 왕조가 같으면(동아시아) 적지 않아도 됩니다 | 프랑스 왕국의 카페 → 발루아 → 부르봉, 합스부르크(오스트리아·스페인) |

**시대 구분**(삼국 시대 · 남북국 시대 · 고려 시대, 중국의 남북조 시대 · 오대십국 시대, 일본의 헤이안 시대 · 에도 시대 …)은 맨 위 날짜 칸에 나라별 파스텔 띠로 나옵니다. 겹치는 구분은 두 단에 나뉘고, 띠를 누르면 상세·문서가 열립니다. `시대 구분` 체크로 켜고 끕니다. DLC의 `epochs`에 적습니다.

**대범위**는 여러 민족 묶음에 흩어져 있는 나라들을 **한 집합으로 묶어 켜고 끄는** 단위입니다(어느 시대의 작은 나라들 · 이름만 남은 본국 아래의 군벌들 · 멸망한 나라를 되살리려는 세력들 …). 켜면 구성 정권들이 제 민족 묶음을 떠나 **한 가지로 모이고**, 그 둘레에 대범위 색의 옅은 **테두리**가 생깁니다 — 테두리의 가로는 구성 정권 띠 전체를 품고(띠가 테두리를 뚫고 나가지 않음), 그 안에서 대범위의 기간은 조금 더 짙은 세로 구간입니다. 테두리 왼쪽 위의 이름표를 누르면 상세가, 왼쪽의 점선 세로 칸을 누르면 가지가 접힙니다. 모인 나라마다의 민족은 왼쪽 칸 오른쪽 끝의 **민족 딱지**가 알려 줍니다. 끄면 제자리(제 민족 묶음)로 돌아가며, 켜고 꺼도 다른 민족 묶음의 차례와 왼쪽 칸의 폭은 그대로입니다. 켜고 끌 때는 구성 정권의 줄이 있던 자리에서 새 자리로 **흘러 모이고**(끄면 제 묶음으로 흩어지고), 트랙 높이 · 왼쪽 줄 이름 · 민족 칸 · 건국·멸망 네모가 같은 곡선으로 함께 도착합니다 — 승계선 줄로 합쳐지는 나라는 그 줄 안에서만 옮겨 가고, 접혀 있던 줄에서 오거나 접힌 줄로 들어가는 나라는 옮기지 않고 그 자리에서 떠오릅니다. 화면(스크롤)은 그대로이고, 켠 테두리가 화면 밖에 생기면 보일 만큼만 데려오며, 상세 창에 연 나라가 가려지게 되면 그만큼만 데려옵니다(정권마다의 '밀려남 알림'은 띄우지 않음). **상징적 본국**을 적은 대범위는 켜면 본국 줄 **바로 아래**에 모이고(테두리가 본국 띠 아랫변에 매달린 모양 · 본국 띠의 단추로 켜고 끄면 상세 창이 어디에 열려 있든 본국 줄은 화면에서 움직이지 않음 — 위쪽 줄이 빠지면 나머지가 함께 미끄러짐. 다만 그러면 켠 테두리나 창에 연 나라가 화면 밖으로 나가게 될 때는 보일 만큼만 함께 옮겨짐), 본국 띠의 그 기간은 가운데가 비어 가는 **할거기 칠**로 보입니다(꺼 두어도). 그 구간 왼쪽 위의 작은 단추(`▸ 할거 4`처럼 성격과 개수)로 띠에서 바로 켜고 끕니다. 본국이 이미 끝난 뒤의 대범위(부흥 운동)는 본국 줄 아래 · 본국이 끝난 자리의 오른쪽에 모이고, 구성 정권이 본국을 `부흥`(승계 종류 `revival`)으로 이었으면 세력마다의 부흥선 대신 본국에서 테두리로 가는 **한 줄**로 묶어 그립니다(끄면 세력마다의 부흥선으로 돌아감). 켜고 끄는 곳: 필터 시트의 `대범위` 칩 줄(누르면 시트가 먼저 접힘) · 대범위 상세의 `모아 보기` · 이어진 시대 구분이나 든 정권의 상세 · 오른쪽 클릭 메뉴 — 모두 '보기'라 연표에서도 됩니다. 켜고 끈 것은 브라우저에 기억되고, 처음 상태는 DLC가 정합니다. DLC 파일의 `scopes`에 적고, 메이커에서는 편집 창에서 만들고 고칩니다(6절).

**색**은 파스텔 열두 가지로 고정되어 있습니다. 세로 눈금(연도 간격)은 옅은 점선으로만 표시해 승계선·소속선과 헷갈리지 않습니다.

**화면의 모양**은 HistoryArchive(위키 아카이브 앱)의 디자인을 따릅니다(2026-10-13): 흰 바탕 하나 · 검은 잉크의 불투명도 다섯 단계 · 링크 파랑, 그림자와 유리 흐림 없이 1px 선으로 나누고, 선택과 으뜸 단추는 반전 채움(검은 바탕 + 흰 글자)입니다. 글꼴은 Pretendard를 `fonts/`에 실어 쓰고(SIL OFL 1.1), 설명 · 문서 본문 같은 읽는 글은 기기의 명조로 보입니다. 띠의 색(위의 파스텔)과 둥근 네모는 자료라 그대로이고, 기기가 어두운 화면이면 바탕과 잉크가 뒤집힙니다. 토큰은 `css/common.css` 맨 위에, 모양 규칙은 `css/common.css` · `css/viewer.css` · `css/maker.css` 끝의 'HistoryArchive 통일' 절에 있습니다.

**소속**이 지정된 정권(연맹의 구성국, 종속국, 절도사·막부 같은 조직체)은 평소 상위 띠 아래 숨어 있고, 상위 띠 첫 글줄 왼쪽의 작은 단추(`▸ 3`)를 누르면 바로 아래 줄로 펼쳐집니다. 펼친 정권은 세로 점선(**소속선**)으로 상위 정권과 이어지고, 상세 패널에 "소속"이 나옵니다. `소속선` 체크로 선을 켜고 끕니다.
옥저처럼 **차례로 여러 나라에 예속**된 정권(고조선 → 현도군 → 낙랑 → 고구려)은 소속을 여러 줄로 적으면 제 줄에 놓이고, 섬긴 상위 정권마다 그 띠 아래에 이 정권의 **이름표**가 섬긴 기간만큼 매달립니다(아래).
상위 띠 아래에 펼쳐진 정권의 민족이 상위 정권의 민족과 다르면(자리는 소속이 정하므로 왼쪽 민족 칸에는 상위의 민족이 보임), 그 줄 높이만큼의 작은 **민족 딱지**가 민족 칸 자리 오른쪽 끝에 끼워져 제 민족을 알립니다. 딱지를 누르면 그 민족의 문서가 열리고, 상세 패널의 민족 줄에 "(상위 〈나라〉는 〈민족〉)"이 붙습니다.

**자율성이 다른 나라와 소속 관계** — 종류에는 위 다섯 가지 말고도 **종속 갈래**(조공·책봉국 · 봉국·제후국 · 자치령 · 군벌·할거 세력 · 종속국 · 보호국 · 위성국 · 괴뢰국 · 위임·신탁 통치령 · 식민지·속령 · 점령지·군정)와 **망명 정부** · **부흥·저항 세력**이 있습니다. 종속 갈래의 제 띠는 옅은 띠 하나이고(테두리는 실선 — 점선은 추정 · 미정 연대의 몫), 누구를 어떻게 섬겼는지는 글자 딱지가 아니라 **상국(섬긴 나라)의 띠에 달린 속국 이름표**가 말합니다. 부흥·저항 세력은 옅은 띠의 왼쪽 끝에 **깃대**가 섭니다. 소속 줄마다 **소속 관계**(조공 · 보호 · 괴뢰 · 식민 · 명목상 · 구성국 · 동군연합 …)를 고를 수 있고, 관계가 이름표의 자리를 정합니다(2026-09-20 감독 결정 '뒤집기' — 속국 띠 안에 상국을 그리지 않고 상국 띠가 속국을 품음). **스스로 다스린 관계는 상국 띠 아래에 매달리고** — 빈 이름표는 조공·책봉 · 봉국 · 자치령, 칠한 이름표는 종속 · 보호 · 위성, 점선은 명목상 소속, 파선은 종속이 아닌 소속(구성국 · 동군연합 · 관계를 적지 않은 소속) — **상국이 다스린 관계는 상국 띠 안 맨 아래로 들어옵니다** — 옅은 칸은 괴뢰 · 위임 통치, 짙은 칸은 식민지 · 속령, 빗금 칸은 점령지. 같은 상국 아래에서 관계가 깊어지면(조공 → 보호 → 식민) 이름표가 하나의 긴 칸으로 이어지다가, 안으로 들어가는 때에 **세로 끈**으로 이어집니다. 이름표는 속국의 빛깔 · 이름이고 길이는 섬긴 기간이며, 기간이 겹치는 속국은 줄을 나눠 쌓습니다(그만큼 상국 줄이 넓어져 사건 글줄과 겹치지 않음). 누르면 그 속국이 골라지고, 올리면 같은 트랙의 그 속국 띠도 함께 진해집니다. 상국이 다른 트랙에 있어도(조선과 명처럼) 상국 띠에 달리므로, 속국 트랙만 보면 누구를 섬겼는지는 설명글 · 상세 창에서 봅니다. 관계를 적은 소속은 기본으로 **제 줄**에 서고, 소속 줄의 `상위 띠 아래에 접기`를 켜면 예전처럼 상위 띠 아래에 접힙니다(접힌 구성국처럼 예속이 아닌 소속에는 이름표를 달지 않지만, 예속 관계를 적은 소속은 접혀 있어도 이름표로 관계를 보여 줌 · 상위 정권이 다른 트랙에 있으면 접지 않고 제 줄에 서서 이름표로). 그림 내보내기에도 이름표가 같은 자리 · 같은 모양으로 들어가고, 탭에는 화면과 같은 딱지가 같은 차례 · 같은 수로 붙습니다(옛 종류인 연맹 · 조직체 · 시대 이름의 딱지와 지위 딱지도 — 자리가 모자라면 화면처럼 이름의 첫 글자만). 멸망한 나라를 되살리려는 세력은 승계 종류 **부흥**으로 옛 나라를 가리키면 **작은 고리**(뒤 나라 띠 바로 앞 — 같은 줄에서 맞닿으면 이음매 위)가 붙은 점선 승계선으로 이어집니다. 범례는 지금 자료에 쓰인 종류만 보여 줍니다. 자세한 형식은 `DLC-형식.md`의 "종류와 소속 관계", 예시는 견본 `samples/sample-lantern.json`(조공한 갈대 공국 · 산호 섬나라, 군현인 하연 총관부, 종속국 · 보호국이던 적석 왕국, 접어 둔 구성국 새물섬, 부흥·저항 세력 검은물 의병 · 망명 정부 남강 임시정부와 하연 부흥국의 부흥 승계선).

### 인물

장군 · 재상 · 학자처럼 **나라에서 활동한 사람**은 활동한 정권의 띠 안, **기간 막대 아래의 인물 단**에 **활동 막대**(둥근 칸)로 나옵니다. 이름은 막대에 들어갈 때만 적히고(좁으면 첫 글자), 중요도가 높은 사람은 굵게 · 윗단에 놓입니다. 막대에 올리거나 고르면 **생몰을 잇는 가는 수명선**이 나타나고, 고르면 **활동한 띠마다 그 활동 기록의 기간이 밝아집니다**(두 나라에서 활동한 사람은 두 띠에). 인물 단은 줄마다 두 단까지(보기 밀도 `넉넉하게` 세 단 · `빽빽하게` 한 단 · `조감`은 없음)이고, 넘친 사람은 그 나라 상세의 **인물** 목록에서 봅니다. 많이 축소해 막대가 너무 좁아지면 `인물 n명` 한 칸으로 모이고, 누르면 그 목록으로 갑니다. 인물이 없는 줄은 예전 높이 그대로입니다.

* **인물 상세**: 이름 · 다른 이름 · 역할 · 생몰(향년) · 가문 · **활동 기록**(정권 · 직함 · 기간 — 누르면 그 정권) · 관련 사건 · **서명한 조약**(조약의 서명자와 이름이 같은 인물 — 누르면 그 조약 창, 조약 창의 서명자를 누르면 다시 인물 창) · 같은 시기의 지도자 · 설명 · 문서. 활동 시기를 적지 않았으면 활동 기록이나 생몰에서 짐작한 것임을 밝힙니다. 활동 시기나 활동 기록의 시작 · 끝을 모르면 "미정"으로 적을 수 있고(아래 "칸의 미정"), 인물 창에 `미정 ~ 575년`과 연표에 놓인 자리가 함께 나옵니다.
* **이어지는 곳**: 정권 상세의 "인물" 목록, 지도자 · 내각 칸 상세의 "이 시기의 인물", 지도자와 이름이 같고 시기가 겹치는 인물은 **같은 이름의 인물 ↔ 같은 이름의 지도자**로 저절로 이어짐, 사건 상세의 **관련 인물** 칩, 같은 해 보기의 "그때 활동한 인물".
* **찾기**: 검색창이 이름 · 다른 이름 · 역할 · 직함 · 활동한 정권으로 찾고(연도를 넣으면 그때 산 사람도), 표로 보기에서 `시대 · 인물도 포함`을 켜면 구분 "인물"로 나옵니다. 문서의 `[[이름]]`은 같은 이름의 항목 · 칸이 먼저이고, 인물을 꼭 가리키려면 `[[인물:이름]]`.
* 필터의 `띠 안` 묶음에 **인물** 체크(기본 켬)가 있고, 중요도 필터를 따릅니다. 그림 내보내기에도 활동 막대가 들어갑니다.
* 인물은 DLC 메이커의 편집 창에서 고치고(활동 기록은 줄마다 트랙 · 정권 · 직함 · 기간 · 메모), 새 인물은 메이커의 `＋ 추가` 메뉴나 `Shift+F`로 넣습니다. 사건 폼의 `묶기` 안에 **관련 인물** 칸이 있습니다. 형식은 `DLC-형식.md`의 "figures (인물)", 예시는 견본 `samples/sample-lantern.json`(사관 서린 · 장군 단오 · 상인 바울 미르 …).

## 1-2. 큰 사건과 공동 사건

* **큰 사건 안의 사건** — 임진왜란 안의 명량 해전, 청일 전쟁 안의 황해 해전처럼 묶여 있습니다. 평소에는 큰 사건에 <b>개수 배지</b>만 붙고, 확대하면 안의 사건이 저절로 펼쳐집니다. 상세 패널에서 목록으로도 볼 수 있습니다.
* **여러 나라가 함께 겪은 사건** — 임진왜란은 조선·일본·명 줄에 함께 찍힙니다. 대표 자리에만 이름이 붙고 나머지는 같은 자리에 <b>속 빈 점</b>으로 표시되며, 하나를 고르면 모두 함께 빛납니다.
* **조약** — 사건에 **조약 규격**(정식 명칭 · 종류 · 당사국 · 서명자 · 비준 · 발효 · 조항 …)을 적으면 그 사건이 조약이 되어 점 대신 **마름모 인장**으로 찍힙니다. 제 줄은 채운 마름모, 다른 당사국의 줄은 속 빈 마름모이고, 기간(체결 ~ 실효)이 있으면 **겹줄 가는 선**, 발효가 체결과 다르면 그 선 위에 작은 마름모 눈금이 섭니다. 상세 패널은 **조약문 양식**으로 바뀝니다 — 정식 명칭, 당사국(편이 둘이면 좌우로 맞서고, 그 밖에는 목록 · 서명자와 직함), 날짜 진행 표(체결 → 비준 → 발효 → 실효와 사이 간격 · 끝난 까닭), 조항(누르면 본문), 관련(끝낸 전쟁 · 대체한 옛/새 조약 · 장소 · 언어). 전쟁 쪽 상세에도 그 전쟁을 끝낸 조약이 나옵니다. 검색은 정식 명칭 · 장소 · 당사국 · 서명자 · 조항 제목으로도 찾고, 표 보기의 구분은 `조약`입니다.
* **나라마다 다른 이름·인식** — 같은 임진왜란을 일본은 "분로쿠·게이초의 역", 중국은 "만력 조선 전쟁"이라 부릅니다. 필터 바의 `관점`에서 **나라마다 제 이름**을 고르면 각 나라 줄에 그 나라의 이름이 붙고, 특정 나라를 고르면 모든 줄이 그 나라의 이름으로 바뀝니다. 상세 패널의 **기본 · 일본 · 중국** 탭으로 나라별 서술을 나란히 볼 수 있습니다.

## 2. 연표 보는 법

연표가 화면 전체를 차지하고, 왼쪽 위에 검색창과 `☰ 필터` · `⋯` 버튼이 든 작은 알약 창(독)이 떠 있습니다. `☰ 필터`를 누르면 필터·표시 설정 시트가 독 아래로 내려오고, 바깥을 누르면 접힙니다. 나머지 기능은 **`⋯`나 연표 위 오른쪽 클릭**으로 열리는 메뉴에 있고, 항목마다 단축키가 적혀 있습니다. 띠나 사건 위에서 오른쪽 클릭하면 그 항목의 자세히 보기·문서가 맨 위에 붙습니다(메이커에서는 수정·숨기기·추가도). 왼쪽 아래 알약에는 지금 보는 기간이, `Z`(집중 모드)를 누르면 독까지 사라지고 연표만 남습니다.

## 2-1. 지도 (보류)

역사 지도는 유지보수를 위해 연표에서 떼어 `지도/` 폴더에 부품으로 두었습니다. 지금 연표·메이커에는 지도 단추·탭이 없습니다. 무엇이 들어 있고 어떻게 다시 붙이는지는 `지도/README.md`에 적혀 있습니다.

## 3. 학자마다 연대가 다른 사건, 그리고 모르는 연대

역사 연대는 사료와 학설에 따라 갈립니다. 이 프로그램은 그것을 숨기지 않고 함께 보여 줍니다.

* **확실성 등급** — 확실 / 통설 / 추정 / 전승. 추정·전승 연대는 점이 비어 있고 이름이 기울어져 표시되며, 시대 막대는 빗금·점선이 됩니다.
* **연대 폭** — "기원전 1000~300년 사이"처럼 폭이 있는 연대는 흐린 띠로 그려집니다. 시대 막대는 시작·끝이 흐려집니다. (예: 야요이 시대, 고조선)
* **다른 견해(이설)** — 하나의 사건에 여러 연대를 함께 담습니다. 기간이 있는 사건은 이설의 시점이 **점선 세로바**로 찍히고 본래 시점(실선 세로바)과 점선으로 이어집니다. 끝 연도 없는 사건(과거제 시행처럼 한 시점의 일)은 기간처럼 보이지 않게 **점선 실에 꿴 구슬**로 그립니다 — 채운 구슬 = 통설, 빈 고리 = 다른 견해, 작은 눈금 = 연대 폭의 끝. 실선은 기간에만 쓰고, 연도는 사건에 마우스를 올리거나 고르면 구슬 위에 뜹니다. 상세 패널의 `다른 견해`에서 연대를 누르면 그 위치로 이동합니다. (예: 일본 불교 전래 538/552년, 수의 과거제 587/598/605년)
* **쟁점** — 왜 견해가 갈리는지 설명이 상세 패널에 붙습니다.
* **연도 미정** — 아예 모르는 연대는 "미정"으로 적습니다. 시대는 그쪽 끝이 크게 둥글고 희미하게 사라지는 띠가 되고, 건국·멸망 네모 대신 점선 동그라미가 찍힙니다. 사건은 점선으로 그린 빈 점이 됩니다. 연표 어디에 놓을지는 **배치용 연도**로 정합니다(상세 패널에 "540년 무렵에 자리를 잡았습니다"처럼 표시).
* **칸의 미정** — 지도자·내각·연호·도읍 칸과 소속(예속) 기간, 지위 변천의 칸, 인물의 활동 기록과 활동 시기의 시작이나 끝도 "미정"으로 적을 수 있습니다(인물의 활동 막대도 미정인 끝이 옅어짐). 그쪽 끝이 칸 안에서 옅어지며 사라지고 칸 사이 구분선이 점선이 되며(이어지는 긴 칸은 끊기지 않음), 도읍 노선도 카드에서는 그 역 사이 본선이 점선입니다. 배치용 연도가 없으면 앞 칸의 끝이나 다음 칸의 시작에 맞춰 놓이고, 칸 창에 "미정 ~ 538년"과 놓인 자리가 함께 나옵니다. 메이커 편집 창의 줄 입력에서는 시작·끝 칸에 `미정`이라고 치고, 여러 줄 붙여넣기는 `이름 미정~538`처럼 적습니다.
* **칸 · 시대 구분 · 인물의 이설과 모호한 칸** — 지도자 · 내각 · 연호 · 도읍 · 시기 · 지위 칸, 소속(예속) 줄 · 왕조 구간 · 인물의 활동 기록, 시대 구분, 인물의 생몰 · 활동 시기에도 다른 견해를 적을 수 있습니다. 칸의 이설은 시작이나 끝 하나만 달라도 되고(비운 쪽은 이 연표가 쓰는 연대 — 채웠더니 앞뒤가 뒤집히면 읽을 때 알리고 빼거나, 연표에 그리지 않고 상세에 까닭을 적음), 날짜 없이 근거만 적은 견해도 됩니다(연표에는 표시 없이 상세에만). 이설이 아니라 칸의 연대 자체가 흐리면 확실성 · 시작 폭 · 끝 폭을 적습니다. 칸 창 · 시기 창 · 지위 창 · 시대 구분 창 · 인물 창에 `다른 견해` 상자(첫 줄은 이 연표가 쓰는 연대 · 누르면 그 해로)와 `시작 — 이르면 …, 늦으면 …` 줄이 나오고, 나라 상세의 칸 목록에는 `이설 n` 딱지가 붙습니다. 연표에서는 칸의 이설이 **유령 구분선**(이설이 말하는 경계 해에 칸 높이만 한 옅은 점선 — 진짜 구분선은 실선 그대로, 너무 가까우면 칸 이름 밑 옅은 점선)으로 보이고(기관 · 구역 · 왕조 항목 자신의 이설도 그 칸에 — 바탕 문화의 이설은 상세에만), 칸을 누르면 그 이설 기간이 띠 바탕에 좌우 점선과 옅은 칠로 함께 보입니다. 연대가 모호한 칸(추정 · 전승 · 연대 폭 — '확실'은 흐림이 아니라 무늬 없음)은 그 구간의 칸 바탕에 띠의 연대 폭과 같은 무늬(추정 = 세로 줄, 전승 = 빗금)가 깔리고 그 구간의 경계가 점선이 됩니다(미정처럼 옅어지며 사라지지 않음). 메이커에서는 칸 줄 끝의 `[이설]` 단추를 누르면 그 줄 아래에 상자가 펼쳐집니다. 연습용 파일은 견본 `samples/sample-lantern.json`(무진왕 · 등화의 411년설, 안개 시대 · 헌정 시대의 견해, 서린 · 단오의 생몰 이설, 전설인 하윤 여왕).
* 이설 표시가 번거로우면 위쪽 `이설` 체크를 끄면 됩니다.
* **실재성 — 나라가 있었는가** — 연대가 얼마나 확실한가와는 따로, 나라 자체가 있었는지가 갈리는 경우입니다. 선 모양 · 빗금은 연대의 몫이라 띠의 바탕과 이름 글꼴로 말합니다: **전설**(전승 · 신화에만 전함)은 띠가 위에서 아래로 안개처럼 옅어지고 책갈피 탭의 이름이 기울어지며, **반전설**(실재는 인정되나 기록이 전설에 기댐)은 띠의 아래쪽 1/3만 안개처럼 사라지고, **부정됨**(한때 인정되었으나 부정됨)은 지운 자국처럼 색을 뺀 회색 띠에 이름 취소선 · 이어진 승계선과 소속선도 옅게, **실재 논쟁**은 보통 띠입니다. 넷 모두 탭 이름 옆에 작은 딱지(`반전설` · `전설` · `논쟁` · `부정`)가 붙고, 상세 패널에 배지와 근거 글(`실재성` 상자)이 나옵니다. 자료에 실재성이 쓰이면 필터 바에 `실재성` 칩 줄이 생겨 켜고 끌 수 있고, 같은 해 보기에서 전설 · 부정된 나라는 옅은 글씨로 나옵니다. 메이커의 편집 창에서 시대를 고칠 때 `연대가 갈리거나 실재가 의심될 때` 칸에서 고릅니다.

메이커에서 사건·시대를 추가·수정할 때도 `연대가 갈리는 경우` 칸을 펼치면 같은 정보를 넣을 수 있고, 연도 칸 옆의 `미정`에 체크하면 숫자 칸이 배치용 연도가 됩니다.

* **날짜까지** — 연도 칸 옆의 `월·일`을 누르면 달력(양력 · 음력 · 중국 음력 · 이슬람력 · 페르시아력 · 율리우스력 …)과 월·윤달·일·시각을 고르는 줄이 열리고, 아래에 양력 환산·요일·일진이 보입니다. 연도 칸에 `1592-05-23`이나 `음력 1592.4.13`을 통째로 적어도 칸에서 나오면 나눠 채워집니다. 지도자·내각·연호·도읍·소속·이설·연대 폭 칸도 `1418-09-09`처럼 날짜를 받습니다. 연도만 적은 항목은 그 해 전체를 뜻하고, 확대하면 옅은 괄호가 그 해를 감쌉니다.

## 4. 고치기는 DLC 메이커에서 — 연표는 보기 전용

연표(`index.html`)는 **보기만** 합니다 — 수정 단추도, 메이커로 가는 메뉴 · 단축키 · 단추도 없습니다. 고치려면 **DLC 메이커를 따로 엽니다**(연표와 따로 여는 프로그램 — 6절). 메이커에서 고친 뒤 `반영`을 누르면 연표에 나타나고, 그 전까지 연표는 예전 모습을 보여 줍니다(Windows 프로그램처럼 연표와 메이커를 따로 설치했으면 `반영`은 메이커 안의 연표 미리보기에만 보이고, 연표 프로그램으로는 DLC 파일로 옮깁니다 — 7-1절).

두 프로그램 사이는 **일방통행**입니다: 메이커에서 연표로는 도구 줄의 `연표로 ↗`(파일 메뉴에도)로 갈 수 있지만, 연표에서 메이커로 가거나 항목을 메이커로 넘기는 길은 없습니다.

> **예전의 "내 수정"은 어디로?** 옛 판의 수정 모드에서 이 브라우저에 쌓아 두던 추가·고침·숨김·문서는, 새 판이 처음 뜰 때 DLC **«내 수정»**(id `my-edits`)으로 한 번 옮겨져 설치됩니다(고친 항목은 바뀐 칸만 패치로, 숨긴 항목은 숨김 패치로, 문서는 문서로). 이미 «내 수정»이 있으면 거기에 합쳐집니다. 원본은 브라우저 저장소의 `ht.user.backup`에 남고, 만들지 못하면 아무것도 지우지 않습니다. 옮겨진 뒤에는 `DLC 관리`에서 켜고 끄고, 메이커에서 고칩니다.

### 문서 — 모든 것에, 문서 안의 문서까지

상세 패널의 `📄 문서`를 누르면 그 항목의 **문서 창**이 열립니다(연표에서는 읽기만 — 문서가 있는 항목에만 단추가 보이고, 쓰고 고치는 것은 메이커에서). 시대·사건·기관·문화·시대 구분·인물뿐 아니라 **민족·트랙·분류 배지**, 가문 창, 그리고 **지도자·내각·연호·도읍·시기 칸 하나하나**(목록 옆 📄)에도 문서가 있습니다. 메이커에서는 문서 창 위쪽의 `＋ 하위 문서`로 **조선/역사, 조선/개요**처럼 문서 안의 문서를 만들고, 하위 문서 안에 또 하위 문서를 둘 수 있습니다.
나무위키처럼 `== 제목 ==`, `'''굵게'''`, `[[다른 시대]]`, `[[조선/역사]]`, `[[/역사]]`, `[* 각주]`, `|| 표 ||`, `{{{#!folding 접기}}}` 같은 문법으로 쓰고, 목차·각주·역링크가 자동으로 붙습니다.

메이커에서 `✎ 편집`을 누르면 왼쪽에 원문, 오른쪽에 실시간 미리보기가 나옵니다. 저장한 글은 고치는 DLC의 문서(`documents`)로 담깁니다 — 다른 DLC·기본팩 항목의 문서도 쓸 수 있습니다. 문법 단추 줄과 단축키로 쉽게 씁니다.

| 단축키 | 동작 |
| --- | --- |
| `Ctrl+B` · `Ctrl+I` · `Ctrl+U` · `Ctrl+D` | 굵게 · 기울임 · 밑줄 · 취소선 |
| `Ctrl+K` · `[[` | 링크 — 연표의 이름이 자동 완성됩니다 (↑↓ Enter) |
| `Ctrl+1` · `2` · `3` | 제목 단계 |
| `Ctrl+L` · `Ctrl+Shift+L` · `Ctrl+Q` | 목록 · 번호 목록 · 인용 (목록 줄에서 Enter는 다음 항목, Tab은 들여쓰기) |
| `Ctrl+Shift+F` · `Ctrl+Shift+T` · `Ctrl+Shift+D` · `Ctrl+E` | 각주 · 표 · 접기 · 코드 |
| `Ctrl+S` | 저장 |

> 설치한 DLC와 메이커의 작업본은 브라우저 저장소에 보관됩니다. 다른 컴퓨터로 옮기거나 보관하려면 `DLC 관리 → 백업 저장`(설치한 DLC 모두)이나 DLC 카드 자세히의 `파일로 저장`(팩 파일 .htpack), 메이커의 `파일로`(팩 파일)를 이용하세요.

## 5. DLC 설치하기

외부 파일은 **전용 `.htpack`만** 씁니다. 팩 내용 수정은 DLC 메이커에서 합니다. 일반 텍스트 편집기와 ZIP 프로그램으로 직접 고치는 방식은 폐쇄했습니다. 다만 인터넷 인증 없이 동작하는 프로그램이므로, 파일과 프로그램을 분석하는 외부 도구의 우회까지 불가능하게 만드는 보안 잠금은 아닙니다. 자세한 범위는 [DLC 형식](DLC-형식.md#팩-파일htpack)에 적었습니다.

1. `🧩 DLC 관리` 를 누릅니다. 설치한 DLC가 **표지 카드**로 보입니다(분류 딱지 · 태그 · 담긴 것 · 켜기 스위치). 카드를 누르면 오른쪽에 **자세히**(설명 · 볼거리 · 관계 · 판 기록).
2. 위의 `＋ DLC 설치`를 누르거나, **창 아무 데나 DLC 파일(.htpack)을 끌어다 놓습니다.**
3. 위 칸의 분류(기본팩 · 확장팩 · 지역팩 · 나라팩 · 학설팩 · 세계관팩 · 문서팩)로 거르고 이름 · 태그로 찾습니다. 카드의 스위치로 켜고 끄고, 자세히에서 `파일로 저장`(팩 파일) · `지우기`. **필요한 팩**이 없거나 꺼져 있으면 카드에 ⚠와 `켜기`가, 함께 못 쓰는 팩이 둘 다 켜져 있으면 ⚠가 뜹니다. 메이커에는 DLC 관리 창 대신 왼쪽 **`불러온 팩`** 탭이 있습니다(켜고 끄기 대신 이 DLC와 함께 볼 팩을 불러옴 — 6절). 설치본을 지우는 일은 연표의 DLC 관리에서 합니다.

배포 폴더의 `samples/`에는 전용 견본 팩이 하나 들어 있습니다. `npm run web`으로 만든 `dist/web/samples/`나 `dist/maker/samples/`의 `.htpack`을 끌어다 놓으세요(큰 판의 릴리즈에도 `HistoryTimeline-<판>-sample-lantern.htpack`으로 올라갑니다). 원본 `samples/sample-lantern.json`은 프로그램에서 열지 않습니다.

* `dist/web/samples/sample-lantern.htpack` — **등불 연대기 — 아홉 불씨의 대륙**(세계관팩 · 지어낸 나라와 사람). 빛돌이 화약과 쇠의 자리를 대신한 대체역사 세계 하나로 연표의 기능을 거의 모두 보여 줍니다 — 네 땅(설령 · 하연 · 적석 · 산호해)의 나라 21개, 정권 종류와 소속 관계(조공 · 명목상 · 종속 · 보호 · 군현 · 구성국 · 동군연합), 직접 · 간접 · 부흥 · 부분 승계와 합류, 시기 구분 · 지위 변천, 가문 · 파 · 계보(승계표 · 세계표), 인물, 조약 · 법 · 선거, 단체와 집권, 렌즈 · 제도, 대범위 · 모아 보기 판, 칸 · 시대 구분 · 인물의 이설 · 미정 · 모호한 연대, 실재성(전설 · 부정된 나라), 아홉 이름의 해 순환(불씨해), 문서와 그림. 패치형 DLC와 지도는 담지 않았습니다. 이 세계만 보려면 DLC 관리에서 기본팩을 끕니다.

## 6. DLC 만들기 · 고치기 (DLC 메이커)

> **저장은 형식 4**(0.0.4부터 — 리메이크 5단계). 메이커가 저장하는 `.htpack`은 객체 · 그릇 · 섬김 · 직위 줄 · 사람 객체 · 문화권 줄을 담는 형식 4입니다(`DLC-형식.md` '형식 4'). 옛 파일(형식 1 · 2 · 3)도 그대로 열리고, 옛 판의 연표 앱 · 다른 프로그램에 줄 파일은 `파일 ▸ 옛 형식(3)으로 내보내기`로 만듭니다(그 형식에 없는 칸은 저장 전에 목록으로 알림). 칸 채우기 답(`docs/프롬프트-DLC-메이커-칸-채우기.md` — 칸 블록 `#HT칸 2`)은 `통째 붙여넣기`(Ctrl+V)로 한 번에 넣습니다.

DLC 메이커는 연표와 **따로 여는 프로그램**입니다(브라우저로 쓸 때는 `dlc-maker.html`을 엶 — 연표에서 메이커로 가는 메뉴는 없습니다). 메이커는 **연표와 같은 화면**(연표 · 상세 · 문서 · 검색 · 필터 · 표)을 가운데에 **늘 수정 모드**로 두고, 둘레에 **작업실**을 두른 프로그램입니다.

* **처음 화면** — 고치던 작업본이 있으면 곧장 작업실로, 없으면 처음 화면으로 뜹니다(작업 중에는 `파일 ▸ 처음 화면`).
  * **새로 만들기** — 이름 · id(겹치지 않게 저절로) · 분류 · 시작 방법: `빈 DLC`(아무것도 없이) · `기본팩에 덧붙이기`(기본팩의 트랙 · 민족을 가져다 씀) · `가상 세계`(이 DLC의 트랙 하나를 만들고 시작).
  * **열기** — `📂 DLC 파일 열기 (.htpack)` 또는 화면에 끌어다 놓기(작업실에 끌어다 놓아도 엶). 파일의 id가 이미 설치된 DLC와 같으면 `새 id로 열기 / 그대로 열기 / 취소`를 묻습니다 — 그대로 열어 반영하면 설치된 것을 덮어씁니다. id가 없는 파일은 겹치지 않는 새 id로 엽니다.
  * **이어서 고치기** — 표지 · 담긴 것 · 반영하지 않은 고침 · 마지막으로 고친 때 · `이어서 고치기` · `반영하고 닫기`(고침이 없으면 `닫기`) · 고침이 있으면 `↺ 설치된 판으로 되돌리기`.
  * **설치된 DLC에서 고치기** — 표지 카드를 누르면 그 DLC를 고칩니다. 반영하지 않은 고침이 있으면 `반영하고 바꾸기 / 버리고 바꾸기 / 취소`를 묻습니다. 기본팩은 직접 고치지 않습니다 — 내 DLC에서 덮어쓰거나 숨깁니다.
* **작업실** — 맨 위 **메뉴 줄**(`파일` `편집` `보기` `넣기` `도구` `도움말` · 오른쪽에 고치는 DLC의 이름 · 판 · 저장됨), 그 아래 **도구 줄**(`↶` `↷` · `＋ 시대` `＋ 사건` `＋ 인물` `＋ 더 ▾` · `복제` `한꺼번에 고치기` `붙여넣기` · 항목 찾기 칸 · `검사` · `고친 것 n` · **`반영`** · `파일로` · `연표로 ↗`), 왼쪽 **구조** · **불러온 팩** 탭, 가운데 **연표 · 표 · 문서** 탭, 오른쪽 **속성**(편집 창이 붙박이로 — 아무것도 고르지 않았으면 자동으로 접혀 연표가 넓어짐), **아래 창**(`문제` · `고친 것` · `작업 기록` · `자동 저장 기록`), 맨 아래 **상태 줄**(저장 · 검사 · 이 DLC에 든 것 · 고친 것 · 반영하면 붙을 판 · 단축키). 흐리게 보이는 표 대량 입력·찾아 바꾸기 명령은 다음 단계에서 만듭니다.
  * 창 폭 · 높이는 가장자리를 끌어 바꾸고(두 번 누르면 기본), `Ctrl+B`(왼쪽) · `Ctrl+Alt+B`(오른쪽) · `Ctrl+J`(아래)로 접고 폅니다. 폭 · 접힘 · 구조의 펼침 · 가운데 탭은 기억됩니다. 화면이 1100px보다 좁으면 왼쪽이 접힌 채 뜨고, 860px 이하에서는 왼쪽 · 아래 · 편집 창이 화면을 덮는 판으로 열립니다. 집중 모드(`Z`)는 둘레를 모두 숨기고 연표만(편집 창이 열려 있으면 오른쪽은 남김).
  * **구조** — 고치는 DLC에 든 것을 나무로: 📦 DLC(누르면 팩 정보) · 바탕(트랙 · 분류 · 민족 · 지위 · 가문 — 누르면 바탕 자료 창의 그 표) · 역사(트랙별 시대 · 왕조 · 기관 · 문화) · 사건(트랙별) · 인물 · 구분(시대 구분 · 대범위) · 덮어쓰기 · 문서 · 그림. 항목을 누르면 오른쪽에서 고치고, 보이는 기간 밖이면 연표가 그리로 갑니다(이미 보이면 그대로). 두 번 누르면 이름 칸, 오른쪽 클릭은 `고치기` · `연표에서 보기` · `문서` · `지우기`(남의 항목은 `숨기기`). 맨 위 칸에 이름 · 연도를 치면 나무가 걸러집니다. 검사 오류가 있는 항목엔 붉은 점. 연표에서 고른 항목은 나무에서도 표시되고, `↑` `↓`로 줄을 옮깁니다.
  * **놓아서 채우기**(10건 4(나)) — 구조 위의 `보기`로 같은 나라들을 다르게 묶습니다: `종류별`(위의 나무) · `민족으로`(트랙 → 민족 나무 → 나라) · `소속으로`(트랙 → 나라 줄 아래 소속 나라) · `가문(국성)으로`(트랙 → 본가 → 분가 → 나라) · `대범위로`(트랙 → 대범위 → 구성 정권). **나라 줄을 끌어 다른 가지에 놓으면 그 칸이 채워집니다** — 민족 가지 = 민족(위 단계 가지면 그 단계) · 나라 줄 = 소속(놓을 때 관계를 고름 — 관계 없음(구성) · 조공 · 종속 · 괴뢰 …, 같은 트랙의 나라만) · 가문 가지 = 국성 · 대범위 = 구성 정권(이 DLC의 대범위만 — 다른 대범위에서 끌어 오면 거기서 빠지고, `Ctrl`을 누른 채 놓으면 남음) · `민족 없음` · `소속 없음` · `가문 없음` · `대범위 없음` = 비움 · 트랙 머리 = 트랙 옮기기(딸린 사건 · 섬긴 인물 · 아래에 접힌 나라를 함께 옮길지 물음). 트랙 머리끼리 · 같은 부모 아래 민족 머리끼리 끌면 차례(`order`)가 바뀝니다(`Alt+↑↓`도). 여러 줄을 고른 채 끌면 함께, 한 번 놓기가 되돌리기 한 걸음이고, 끄는 동안 놓을 곳에 `놓으면: 민족 → ○○ (3개)`처럼 미리 글이, 놓을 수 없는 곳에는 까닭(같은 트랙이 아님 · 남의 대범위 · 제 아래 나라 …)이 나옵니다. 가지 머리의 `＋ 민족` · `＋ 가문`은 이름만 치면 사전에 더하고 그 가지 아래에 만듭니다. `불러온 팩도`를 켜면 불러온 팩의 나라도 보이고, 놓으면 지금 규칙대로 바뀐 칸만 덮어쓰기로 들어갑니다(잠긴 팩은 건너뜀). 키보드로는 줄을 고르고 오른쪽 클릭 · `편집` 메뉴의 `옮기기…`에서 갈 곳을 고릅니다. 보기 갈래는 작업실 설정이라 파일에 들어가지 않습니다.
  * **가운데 탭** — `연표` · `표`(4단계에서 표 탭 — 지금은 `📋 표 보기` 단추) · `문서`(고른 항목의 문서, 고른 것이 없으면 이 DLC의 문서 목록).
  * **단축키** — `Ctrl+E` 반영 · `Ctrl+Shift+E` 팩 파일로 · `Ctrl+O` 열기 · `Ctrl+K`(또는 `/`) 항목 찾기 · `Ctrl+1` `2` `3` 연표 · 표 · 문서 탭 · `Delete` 지우기(남의 항목은 숨기기) · `F2` 이름 칸 · `?` 단축키 목록 · `N` · `Shift+N/O/C/Y/F` 새 항목 · `F` 필터 · `L` 범례 · `Z` 집중 모드 · `0` 전체 보기 · `Y` 같은 해 · `R` 기간 재기. 글 칸 · 편집 창 안에서는 `Delete` · `F2` · `?`와 글자 단축키가 글 칸의 것입니다(`Ctrl` 조합만 어디서나).
* **고치는 DLC(작업본)** — 메이커는 늘 DLC 하나를 고칩니다. 마지막에 고치던 것은 기억됩니다. **처음에는 이 DLC만** 보이고, 다른 DLC · 기본팩은 **불러온 팩**으로 불러와 흐리게 함께 봅니다(아래).
* **불러온 팩**(왼쪽 탭 · `D`) — 맨 위는 고치는 DLC, 그 아래 불러온 팩 줄마다 `👁`(연표에 보이기 · 숨기기) · `🔒`(자물쇠) · `✕`(빼기). `＋ 팩 불러오기`로 설치된 팩(기본팩 포함)을 고르거나 파일(.htpack)에서 불러옵니다(메이커 저장소에 설치하고 곧 불러옴). 불러온 팩은 **DLC마다 기억**됩니다.
  * **저절로 드는 팩** — 이 DLC의 덮어쓰기(패치)가 가리키는 팩(`덮어쓰기 대상`)과 팩 정보의 `필요한 팩`은 저절로 들어오고 뺄 수 없습니다(눈 · 자물쇠는 바꿀 수 있음). 새로 만들기의 `기본팩에 덧붙이기`는 기본팩을 잠긴 채 불러 두고 시작합니다.
  * **흐리게** — 불러온 팩의 띠 · 점 · 줄 이름은 옅게(보기 메뉴의 `불러온 팩 흐리기`: 옅게 30% · 보통 45% · 진하게 65%, 자물쇠를 풀면 조금 덜 흐리게) 보입니다. 눈을 끈 팩은 연표에서 사라지고 그 팩만 쓰던 트랙도 빠집니다(덮어쓰기는 그대로 풀림).
  * **자물쇠** — 잠긴 팩의 항목을 누르면 편집 창 대신 **읽기 전용 상세**가 열리고 맨 위에 `🔓 자물쇠 풀기` · `내 DLC로 복사`가 있습니다. 잠긴 항목은 지우기 · 숨기기 · 저장이 막힙니다. 자물쇠를 풀면 그 팩의 항목도 고칠 수 있고 **고친 칸만 이 DLC의 덮어쓰기**로 들어갑니다.
  * 설치되어 있지 않은 팩(연표 쪽에서 지웠거나 다른 컴퓨터의 팩)은 줄에 `설치되어 있지 않음`으로 남고 `✕`로 뺍니다.
* **덧씌움 없이 바로 고칩니다** — 띠나 사건(또는 구조의 줄)을 누르면 **오른쪽 속성 창에 편집 창**이 열립니다(시대는 이름·연도·종류·소속·민족·승계·지도자·내각·연호·도읍·문서까지, 사건은 제목·연도·분류·설명·문서까지). 가운데를 막는 대화상자가 아니라 오른쪽에 붙은 창이라, 연표를 보며 고칩니다.
  * `저장`(`Ctrl+S`)하면 연표에 바로 보이고, 창은 그 항목을 계속 엽니다. 한 줄 칸에서 Enter는 저장이 아닙니다.
  * **키보드로 칸 옮기기**(입력 칸 길잡이 — `js/form-keys.js`) — 지도자 · 내각 · 연호 · 도읍 · 소속 · 승계 · 이설 같은 **줄 목록** 안에서 `↑` `↓`는 **같은 열**(지도자 줄의 `시작`에서 `↓` = 아래 지도자의 `시작` — 표와 같은 감각), `Enter`는 아래 줄의 같은 칸(마지막 줄이면 그 목록의 `＋`로 새 줄을 만들고 그 칸으로 — 마지막 줄이 텅 비었으면 새 줄을 또 만들지 않고 목록 뒤의 칸으로), `Shift+Enter`는 위 줄입니다. 첫 줄에서 `↑` · 끝 줄에서 `↓`는 목록을 벗어나 그 앞 · 뒤 칸으로 갑니다.
    * 줄 목록 밖에서는 `↑` `↓` · `Enter` · `Shift+Enter`가 **화면에 보이는 앞 · 뒤 글 칸**으로 갑니다(닫힌 접는 구역 · 접힌 이설 상자 · 숨은 칸 · 잠긴 칸은 건너뜀). 한 줄 칸의 Enter는 여전히 저장이 아닙니다.
    * `Alt+↑` `↓` 줄 옮기기(저장하면 칸은 예전처럼 시작 순으로 다시 놓이므로, 시작이 같거나 미정인 줄의 차례에 뜻이 있습니다) · `Ctrl+D` 줄 복제(바로 아래에) · `Ctrl+Shift+Delete` 줄 지우기(그 줄의 `✕`와 같음). 줄을 바꾸면 저장하지 않은 고침이 됩니다.
    * 예외: **한글을 조합하는 중**에는 아무것도 하지 않습니다. 여러 줄 글 칸(설명 · 쟁점 · 조항 본문 · 문서)은 커서가 **첫 줄에서 `↑` · 끝 줄에서 `↓`** 일 때만 칸을 옮깁니다(길어서 접힌 줄도 한 줄로 셈 · `Enter`는 줄바꿈). 고르기(`기원후`/`기원전` · 역할 …) · 숫자 칸은 화살표가 값을 바꾸는 칸이라 가로채지 않고, 화살표로 옮겨 다닐 때 고르기 · 체크 상자에는 멈추지 않습니다(고르기는 `Tab`으로). 자동 완성 목록(국성 · 가문 · 지위 · 정권 칸에서 글을 치면 뜨는 목록 · 문서 칸의 `[[` 상자)이 떠 있으면 `↑` `↓` · `Enter`는 그 목록의 것입니다 — 목록이 닫혀 있을 때의 `↓`는 칸 옮기기라, 빈 칸에서 `↓`로 목록 전체를 펼치지는 않습니다(글자를 치면 맞는 것이 뜸). 큰 입력 창이 열려 있으면 쉽니다.
    * 옮겨 간 칸이 편집 창의 보이는 곳 밖이면 부드럽게 스크롤해 보여 줍니다(움직임 줄이기 설정이면 곧장).
  * 다른 띠 · 사건을 누르면 창이 그 항목으로 바뀝니다 — 저장하지 않은 고침이 있으면 `저장하고 이동 / 버리고 이동 / 취소`를 묻습니다. `Esc`나 `✕` · `닫기`로 닫을 때도 같습니다.
  * **선택 해제** — 편집 창 닫기·연표의 빈 곳 누르기·마지막 항목을 Ctrl로 빼기로 선택을 해제하면 오른쪽 창이 접힙니다. 항목이나 팩 정보를 열면 다시 펼쳐집니다. 작성 중인 칸이 있으면 기존의 저장·버리기·취소를 먼저 거치며, 아무것도 없을 때 오른쪽 창 단축키로 빈 공간을 펼치지는 않습니다.

  * **떼어 내기** — 제목 줄을 끌면 창이 떨어져 떠 있는 창이 됩니다(아무 데로나 옮기고, 오른쪽 아래 모서리로 크기 조절). `다시 붙이기`로 오른쪽 창에 붙입니다. 폭 · 자리 · 크기는 새로고침 뒤에도 기억됩니다.
  * 좁은 화면(폭 860px 이하)에서는 편집 창이 화면 전체를 덮는 시트로 열립니다.
  * **크게 쓰기** — 긴 글 칸(설명 · 쟁점 · 문서 본문 …)의 이름표 줄 오른쪽 끝에 있는 작은 `크게`를 누르거나, 칸에서 `Alt+Enter`를 누르면 화면 위에 **큰 입력 창**이 떠서 넓게 씁니다. 메모 · 출처 같은 한 줄 칸과 이름표 줄이 없는 칸(붙여넣기의 표 칸 · 문서 편집기)은 `Alt+Enter`로 엽니다.
    * 창의 글은 원래 칸과 늘 같습니다(치는 대로 원래 칸에 들어가고, 원래 칸에 직접 쳐도 창에 보임). `Ctrl+S`는 편집 창의 저장, `Esc`나 `Alt+Enter`는 이 창만 닫고 원래 칸으로 돌아갑니다. 한 줄 칸이면 `Enter`로 닫히고 줄바꿈은 빈칸이 됩니다.
    * 제목 줄에 어느 칸인지(예: `사건 수정 › «제목» › 설명`)와 아래에 글자 수가 보입니다. 제목 줄을 끌어 옮기고 오른쪽 아래 모서리로 크기를 바꿉니다(자리 · 크기는 기억). 문서 칸이면 문법 단추와 `[[` 자동 완성도 창 안에서 됩니다.
    * 창은 하나뿐이라, 다른 칸에서 열면 같은 창이 그 칸으로 옮겨 옵니다. 저장한 뒤에도 같은 칸이면 그대로 이어 씁니다.
    * 원래 칸이 닫히면(다른 항목으로 가기 · 편집 창 닫기 · 그 줄을 지우기 · 다른 DLC로 바꾸기) 창에 `원래 칸이 닫혔습니다`가 뜨고 글은 **복사만** 됩니다 — 엉뚱한 칸이나 새로 연 DLC에 옮겨 쓰지 않습니다. 알림에는 창의 글이 닫히기 전에 원래 칸에 모두 들어갔는지가 함께 적힙니다(저장했는지는 그 칸의 창에서 한 대로입니다). 창에서 `Ctrl+S`로 문서를 저장해 문서 편집기가 닫히면 알림 없이 창도 함께 닫힙니다. 대화상자(붙여넣기) 안의 칸이면 대화상자를 닫을 때 창도 함께 닫힙니다.
    * **`↗ 새 창`**(PC 브라우저에서만 — 앱 · 모바일 · 설치형 웹앱에는 없음): 큰 입력 창의 글 칸을 브라우저의 새 창으로 꺼내 다른 모니터에 두고 씁니다. 글은 똑같이 원래 칸과 함께 바뀌고 `Ctrl+S` · `Esc`도 같지만, 문법 단추와 `[[` 자동 완성은 없습니다. 새 창을 닫으면 원래 칸으로 돌아오고, 메이커를 닫으면 새 창도 함께 닫힙니다. 브라우저가 팝업을 막으면 알림만 뜨고 큰 입력 창은 그대로입니다.
  * **시대 폼**에는 종류(자율성이 다른 나라의 종속 갈래 · 망명 정부 · 부흥·저항 세력까지) · 소속 줄의 **소속 관계**와 `상위 띠 아래에 접기` · 접는 구역 **시기 구분**(체계마다 시기 줄 — 여러 줄 붙여넣기도) · **지위 변천**(지위 줄) · **국성** · 지도자 줄의 **지위 · 가문** 칸이 있고, 지도자 · 내각 · 연호 · 도읍 · 소속 · 지위 변천 줄의 시작 · 끝 칸에 `미정`을 칠 수 있습니다. **사건 폼**에는 **관련 인물** 칸과 접는 구역 **조약 규격**이 있습니다 — 정식 명칭 · 종류 · 불평등 · 비준 · 발효 · 끝난 까닭 · 장소 · 언어 · 당사국 줄(트랙 · 정권 · 편 · 역할 · 서명자 "이름(직함); 이름(직함)") · 조항 줄(번호 · 제목 · 분류 · 본문) · 끝낸 전쟁 · 대체한 조약. 조약문을 통째로 `조항 한꺼번에 붙여넣기`에 넣으면 "제1조" · "제1관" · "Article 1"로 시작하는 줄마다 조항이 나뉩니다. 구역에 무엇이든 적으면 시작 · 끝 칸의 이름이 `체결` · `실효`로 바뀌고, 구역을 모두 비우면 보통 사건으로 돌아갑니다(기본팩의 사건도 이렇게 조약으로 만들 수 있고, 반영하면 패치로 담깁니다). **인물 폼**은 이름 · 다른 이름 · 역할 · 트랙 · 중요도 · 생몰 · 활동 시기(비우면 활동 기록이나 생몰에서 짐작 · 모르면 `미정` 체크) · 활동 기록 줄(시작 · 끝 칸에 `미정`) · 가문 · 설명 · 태그 · 출처입니다.
  * **줄 묶음 붙여넣기** — 지도자 · 내각 · 연호 · 도읍 · 지위 변천 줄의 `여러 줄 한꺼번에 붙여넣기` 글 칸에 엑셀 · 표 계산 프로그램에서 복사한 여러 열(탭으로 나뉜 표)을 넣고 `줄을 칸으로 추가`를 누르면 **열 맞추기 미리 보기**가 뜹니다. 첫 줄이 칸 이름(대표 이름 · 대수 · 묘호 · 시호 · 이름 · 시작 · 끝 · 기간 · 왕조 · 지위 · 가문 · 메모 · 도시 · 역할 …)이면 머리글로 알아보고, 아니면 열의 내용(제n대 · 날짜 · `시작~끝` · 정도/배도)으로 짐작합니다. 열마다 받을 칸을 고를 수 있고, 날짜는 연도 · 날짜(음력 · 기원전 · 세기) · `미정`을 읽습니다. 읽지 못한 줄은 빨갛게 표시하고 까닭을 적으며 넣지 않고 글 칸에 남겨 둡니다. 넣은 줄은 폼의 줄이 되고 편집 창의 `저장`으로 저장합니다. 탭이 없는 예전 한 줄 글 꼴(`이름 시작~끝 메모`)은 미리 보기 없이 예전처럼 줄이 됩니다.
  * **자동 완성** — 이름을 적는 칸은 목록에서 고를 수 있습니다: 국성 · 가문 칸(시대 · 지도자 · 내각 · 왕조 · 인물 폼)은 가문 목록, 지위 칸은 지위 사전, 사건 폼 조약 규격의 `끝낸 전쟁`은 사건 제목, `대체한 조약`은 조약인 사건의 제목(고치는 사건 자신은 빠짐). 목록에 없는 글을 적어도 됩니다.

  * 고치는 DLC의 **제 항목**은 그 자리에서 고치고, `🗑 삭제`로 지웁니다.

* **설치된 판이 따로 바뀌면** — 작업본은 가져온 판(또는 마지막으로 반영한 판)을 기억합니다. 그 뒤에 DLC 관리의 설치 · 백업 복원 · 다른 탭의 반영으로 설치된 같은 DLC가 바뀌면: 작업본에 고친 것이 없으면 새 판으로 저절로 다시 불러오고(알림), 고친 것이 있으면 그대로 두고 도구 줄에 `⚠ 설치된 판이 바뀌었습니다`를 띄웁니다. 누르면 사정을 알려 주고 `고침을 버리고 설치된 판 불러오기`를 고를 수 있으며, 그대로 `반영`하면 이때만 "설치된 판을 덮어쓸까요"를 한 번 묻습니다(설치된 판에만 있는 것은 사라지므로).
* **`파일로`** — 지금 작업본을 같은 판 번호의 **전용 팩 파일(`.htpack`)**로 내려받습니다. JSON 열기·내보내기는 없으며, 옛 ZIP 팩이나 확장자만 바꾼 JSON도 열 수 없습니다. 연표 설치·다른 팩 불러오기·전체 백업도 `.htpack` 하나로 통일했습니다. 이미 저장된 작업본과 설치본은 그대로 이어서 쓰고 새 규격으로 저장할 수 있습니다.
* **편집 기본기** — `Ctrl+Z` 되돌리기, `Ctrl+Y` 또는 `Ctrl+Shift+Z` 다시 하기. 항목 저장·삭제·숨김·문서·팩 정보·바탕 자료와 반영도 한 걸음으로 남습니다. 글 칸 안에서는 그 칸의 글자만 되돌립니다. 도구 메뉴 또는 아래 창의 **작업 기록**에서 누른 시점까지 돌아갈 수 있고, 뒤의 걸음은 다시 하기로 남습니다. 최대 200걸음 또는 64MB이며 창을 닫으면 없어집니다. 반영을 되돌리면 작업본만 바뀌고 설치된 판은 그대로입니다.
  * **복제·복사** — `Ctrl+D`는 내 항목을 새 id와 ` (사본)` 이름으로 복제합니다. 불러온 팩에서는 이름 그대로 내 DLC로 복사하며 자물쇠는 그대로 둡니다. `Ctrl+C`·`Ctrl+X`·`Ctrl+V`로 복사·잘라내기·붙여넣기를 하고, 필요한 트랙·분류·민족·지위·가문과 항목의 문서·하위 문서가 함께 갑니다. 같은 id의 바탕 정의가 이미 있으면 내 것을 씁니다. 시스템 복사에는 메이커용 묶음과 표 계산 프로그램용 글이 함께 들어갑니다. 시스템 권한이 없으면 이 창 안의 복사본을 씁니다. 잘라내기는 내 항목에만 적용합니다.
  * **여러 개 고르기** — 구조에서 `Ctrl+누르기`로 더하거나 빼고, `Shift+누르기`로 보이는 줄 사이를 고릅니다. 연표에서도 `Ctrl+누르기`, 작업실에서 `Ctrl+A`로 내 항목 모두를 고릅니다. 복제·복사·삭제는 고른 묶음에 한 번에 적용됩니다.
  * **자동 저장 기록** — 고친 작업본을 10분마다(바뀐 경우만), 붙여넣기·반영·다른 DLC로 전환·설치본 불러오기·저장 시점 복원 전에 보관합니다. 도구 메뉴 또는 아래 창에서 시간·까닭·항목 수·지금과 다른 곳 수를 보고 복원할 수 있습니다. 복원도 되돌리기로 취소됩니다. DLC마다 최근 30개 시점을 이 컴퓨터의 브라우저에 보관하며, 일반 작업본과 별도로 앱의 `state.json` 거울에는 담지 않습니다.
* **`고친 것 n`**(도구 줄 · 상태 줄 — 아래 창의 `고친 것` 탭) — 반영하지 않은 고침의 목록과, 남의 항목에 건 패치(고침 · 숨김)의 목록. 패치마다 `보기` · `↩ 되돌리기`. 문서의 고침은 이름과 무엇의 문서인지(인물 · 가문 · 지도자 칸 · 분류 …)로 보입니다.
* **팩 정보**(구조 맨 위 📦 · 메뉴 줄의 이름) — 오른쪽 창에 위에서부터: 카드 미리보기(`DLC 관리에서 이렇게 보입니다`) · **표지**(`그림 고르기…`(png · jpg · webp) · `📷 지금 연표를 표지로` · `자동 표지로` — 16:9 · 1600×900 이하로 줄여 넣음) · 이름 · id · 판 · 분류 · 만든 사람 · 태그(5개까지 · 20자까지, 치고 Enter) · 짧은 소개(120자) · 설명 · 볼거리(10줄 — `⋮⋮`를 끌거나 `Alt+↑↓`로 차례) · **관계**(필요한 팩 — 덮어쓰기 대상은 잠긴 칩 · 함께 쓰면 좋음 · 함께 못 씀 · 뒤에 불러오기 — 설치된 팩을 고르거나 id를 적고 Enter) · **판 기록**(다음 반영 때 남길 말 · 지난 줄 고쳐 쓰기 · 빼기) · 담긴 것. 저장 단추 없이 **치는 대로 저장**됩니다(잠깐 쉬었다 한 번에 — 이름을 비우면 문제 글만 뜨고 옛 이름 그대로). **id는 칸을 떠날 때** 바뀌고, 반영할 때 새 DLC로 설치되며 설치돼 있던 옛 id의 DLC는 그대로 남는다고 알려 줍니다(연표에 둘 다 켜 두면 둘 다 보이니 DLC 관리에서 끄거나 지우세요). 이 DLC 안의 항목 · 문서 · 패치 · 불러온 팩은 새 id를 따라갑니다. 판은 반영할 때마다 저절로 오르지만 여기서 손으로 적어도 됩니다.
* **`바탕 자료`**(구조의 `바탕` 줄 · 넣기 메뉴) — 가운데 편집 표에서 고칩니다. 표의 **바탕 가져오기·문서**는 기존의 떠 있는 도구 창을 열어, 다른 DLC의 정의 가져오기·바탕 문서·연결된 곳 확인을 제공합니다. 칸 일곱:
  * **트랙 · 분류 · 민족** — 표에서 바로 고칩니다(색 · id · 이름 · 순서, 민족은 상위 민족 · 설명까지). `쓰는 곳`에 이 줄을 쓰는 항목 수가 보이고, **id를 바꾸면 그것을 가리키던 곳이 모두 따라 바뀝니다**(항목의 트랙 · 사건의 "함께 겪은 쪽" · 나라별 명칭 · 인물의 활동 기록 · 조약 당사국(`트랙:이름` 글도) · 패치 · 그 줄의 문서 — 민족은 이름을 바꿔도 이름으로 적은 곳이 따라감). 이 DLC에 든 것만 고칠 수 있고, 다른 DLC · 기본팩의 트랙 · 분류 · 민족은 아래 `가져오기`로 **같은 id로 실어** 함께 씁니다.
  * **시대 구분** — 목록에서 누르면 오른쪽 편집 창에서 고칩니다(이름 · 기간 · 트랙(비우면 모든 나라 공통 줄) · 색 · 메모 · 설명 · 문서). `＋ 시대 구분 추가`로 새로. 연표에서 제 시대 구분을 눌러도 편집 창이 열립니다. `쓰는 곳`에 이 시대 구분을 가리키는 대범위 수가 보이고, **이름을 바꿔 저장하면 그 이름으로 적은 이 DLC의 대범위도 따라 바뀝니다**(지울 때는 쓰는 곳을 알립니다).
  * **지위** — 지위 사전(id · 이름 · 서열 · 별칭 · 설명). 서열은 클수록 높고, 비우면 서열 밖(중립 색)입니다. 별칭은 쉼표로 나눠 적습니다. 프로그램에 든 기본 지위는 만들지 않아도 쓰이고, 고쳐 쓰려면 아래 `가져오기`(하나씩 또는 `모두 가져오기`)로 같은 id로 싣습니다. **id나 이름을 바꾸면** 그렇게 적은 지위 변천 · 지도자의 지위 칸(패치 안도)이 따라 바뀝니다 — 별칭으로 적은 칸은 그대로이고 `쓰는 곳`에만 셈해집니다. 이름이 없는 줄은 연표에 쓰이지 않고 반영 · 파일로에서 빠지므로, 이름 칸에 옅은 빨간 테가 둘러지고 `검사`에 경고로 나옵니다(누르면 그 줄로).
  * **가문** — 가문 목록(색 · id · 이름 · 성 · 본관 · 시조 · 본가 · 설명 · 📄 문서). **id나 이름을 바꾸면** 시대의 국성 · 지도자와 내각 칸 · 왕조 · 인물의 가문 · 다른 가문의 본가 · 패치에 적은 것이 따라 바뀌고, id를 바꾸면 그 가문의 문서도 따라갑니다. 칸이 여덟이라 창이 좁으면 표가 옆으로 밀립니다(창을 넓히거나 옆으로 넘겨 봄).
  * **대범위** — 이 DLC의 대범위 목록(색 · 이름 · 기간 · 트랙). 꺼 둔 대범위는 연표에 테두리가 없어 찾기 어려우니 여기서 누르면 오른쪽 편집 창에서 고칩니다. `＋ 대범위 추가`로 새로, 📄 문서 · 🗑 삭제. 트랙 id를 바꾸면 대범위의 트랙과 `트랙:이름`으로 적은 구성 정권 · 본국도 따라 바뀝니다.
  * 쓰는 곳이 있는 줄을 지우면 몇 곳에서 쓰는지와 지운 뒤 어떻게 되는지를 묻습니다(지위 · 가문은 사전에 없는 이름으로 남음).
  * **다른 DLC 우선** — 같은 id의 트랙 · 분류 · 민족 · 지위 · 가문은 연표에서 하나로 합쳐지고 먼저 놓인 정의가 쓰이는데, 메이커는 불러온 팩(기본팩 포함) 뒤에 작업본을 얹습니다. 그래서 다른 DLC에서 가져온 민족 · 지위 · 가문은 표에 `다른 DLC 우선`이 붙고(풍선 도움말에 그 DLC와 쓰이는 이름), 그 DLC를 불러와 둔 동안 여기서 고친 것은 연표에 나오지 않습니다. 이름을 바꿔도 그 이름으로 적은 곳을 따라 바꾸지 않고 알리기만 합니다(따라 바꾸면 그곳들이 쓰이는 정의에서 떨어짐) — 이 DLC만의 것으로 쓰려면 id를 바꿉니다. 프로그램에 든 기본 지위는 가져와 고치면 이 DLC의 것이 쓰입니다.
* **`표` (`Ctrl+2`)** — 내 DLC의 시대·사건·인물·기관·문화·왕조·시대 구분·대범위·바탕 자료와 덮어쓰기를 고칩니다. 칸을 고르고 글자를 치거나 Enter·F2·두 번 누르기로 편집하며, Enter·Tab은 저장하고 다음 칸으로, Esc는 취소합니다. 열 머리로 정렬하고 찾기로 거르며 열 표시·폭·차례를 기억합니다. 맨 아래 `+` 줄에 쓰면 새 항목이 됩니다. 많은 자료는 보이는 줄만 그립니다.
  * **표 붙여넣기** — `Ctrl+V` 또는 도구 줄·넣기 메뉴에서 탭으로 나뉜 표나 CSV를 넣습니다. 첫 줄이 열 이름이면 이름에 맞춰 넣습니다. 새 줄이나 잘못된 값이 있으면 미리보기에서 수와 까닭을 확인하며, 잘못된 칸은 원래 값을 유지합니다. 한 번에 되돌릴 수 있고 새 줄을 더하기 전에는 저장 시점도 남깁니다.
  * **선택·채우기** — 칸을 끌거나 Shift로 범위를 고릅니다. `Ctrl+D`는 맨 위 값으로 아래를 채우고, 입력 중 `Ctrl+Enter`는 고른 칸을 같은 값으로 채웁니다. 줄 머리·Ctrl·Shift는 줄을 고르며, 줄 선택에서 `Ctrl+D`는 복제, Delete는 삭제입니다. 칸 선택의 Delete는 비우기입니다.
  * **하위 표** — 시대 한 줄을 고르면 아래에서 지도자·내각·연호·도읍·시기·지위를 함께 고칩니다. 아래 표도 붙여넣기·채우기·정렬이 되고 높이 조절과 접기를 제공합니다. 칸에 딸린 문서는 이름·날짜 변경을 따라갑니다.
  * **여러 항목 고침** — 두 개 이상 고르면 오른쪽에서 트랙·종류·분류·중요도·민족·색·실재성·확실성 또는 날짜를 함께 고칩니다. 그리고 **국성 · 가문**(시대 · 인물 · 왕조), **태그 더하기/빼기**(사건), **대범위에 넣기/빼기**(고치는 DLC의 대범위만 — 대범위와 같은 트랙의 나라만 들어가고, 불러온 나라를 넣어도 그 나라는 고치지 않음), **소속 정하기**(상위 정권 하나 · 기간 없음 · 소속 관계 고르기 · 비우면 소속을 지움 — 소속이 여럿이거나 기간이 적힌 나라가 있으면 덮어쓰기 전에 알리고 `적용`을 한 번 더 눌러야 바꿈)도 됩니다. 고른 항목 가운데 하나도 받을 수 없는 칸(사건만 골랐는데 국성 …)은 목록에서 감춥니다. 해당 칸이 없는 항목과 잠긴 팩은 까닭과 함께 건너뛰고, 불러온 팩의 항목은 바뀐 칸만 덮어쓰기로 적습니다. 한 번 적용이 되돌리기 한 걸음이고, 20개를 넘는 변경 전에는 저장 시점을 남깁니다.
* **연표 위 편집** — 고른 띠의 양 끝 손잡이로 기간을 바꾸고, 고른 사건 점을 끌어 날짜를 옮깁니다. Alt+끌기 또는 Alt+←/→는 안의 날짜까지 함께 옮깁니다(Shift+방향키를 더하면 열 단위). 붙는 단위는 화면 폭에 따라 해·달·날이며, 끄는 중 Shift는 한 단계 가늘게 합니다. 이어진 칸의 경계는 앞뒤 두 날짜를 함께 바꿉니다. 빈 곳의 Ctrl+끌기는 새 시대, Ctrl+누르기는 새 사건입니다. 끄는 동안 그림자만 움직이고 놓을 때 저장하며 Esc로 취소합니다.
* **명령·항목 찾기 (`Ctrl+K` · `/`)** — 명령과 단축키·내 항목·불러온 항목·바탕 자료·문서를 한곳에서 찾고, 연도·날짜·간지로 이동합니다. ↑↓와 Enter로 고르며 결과가 많으면 더 보기를 누릅니다.
* **찾아 바꾸기 (`Ctrl+H`)** — 아래 창에서 내 DLC의 이름·설명·메모·문서·출처·칸 이름을 한 곳씩 또는 한꺼번에 바꿉니다. 대소문자·낱말·정규식을 고를 수 있고, 기본으로 이름 참조도 따라 바꿉니다. 전체 바꾸기 전에는 저장 시점을 남깁니다. **빈 칸 점검**은 오류와 별도로 설명·문서·출처·지도자·연대·색·트랙 순서의 할 일을 보여 주며 필요한 묶음만 기억해서 표시합니다.
* **`검사 n`** — 작업본의 오류 · 경고 수(오류가 있으면 붉게). 누르면 **아래 창의 `문제`**에 목록이 나오고, 한 줄을 누르면 그 항목으로 가서 편집 창이 열립니다 — **검사에 걸려 연표에 나오지 않는 항목(트랙이 없는 것 같은)도** 여기서 열어 고칠 수 있습니다(트랙 · 분류 · 민족의 문제는 바탕 자료의 그 줄로, DLC 전체의 문제는 팩 정보로). 대범위는 연표에서 찾지 못한 구성 정권 · 본국 · 시대 구분과 기간을 정할 것이 없어 그려지지 않는 것도 경고로 나오고, 켜면 구성 정권이 승계으로 한 줄을 쓰던 정권에게서 떠나 그 줄이 나뉘는 곳은 **알림**(옅은 글씨 — 고칠 것이 아니라 알아 둘 것이라 검사 수에는 세지 않음)으로 나옵니다.
* 작업본에 치명적인 오류가 생기면(이름이 빈 DLC 같은) 도구 줄에 알림이 뜨고, 연표는 마지막으로 성한 모습을 보여 줍니다.
* 연표의 기존 `T` 목록 보기도 유지합니다. 값을 직접 여러 개 고칠 때는 가운데 `표` 탭을 씁니다.
* **일방통행** — 메이커에서 연표로는 도구 줄의 `연표로 ↗`(파일 메뉴에도)로 가고, 연표에서 메이커로 오거나 항목을 넘겨받는 길은 없습니다. 메이커는 늘 마지막에 고치던 DLC로 뜹니다.
* **새 앱(아카이브)으로 보내기** — 메이커는 줄 배치를 따로 내보내지 않습니다. `파일 → 팩 파일로 내보내기 (.htpack)`로 저장한 파일을 새 연표 앱이 그대로 받아 배치를 스스로 셈합니다. 옛 메이커가 만든 `.htlayout`(팩 파일 종류 3)은 DLC가 아니라서 연표 · 메이커에서 열리지 않습니다(형식: `DLC-형식.md`의 '팩 파일').

옛 메이커의 종류별 표 · 드로어 · 빠른 추가 · 패치 탭 · 문서 탭 · 미리보기 탭은 없어졌습니다(화면이 곧 미리보기이고, 패치는 저절로 만들어집니다).

* **지도·영토**는 지도와 함께 `지도/` 폴더로 떼어 두었습니다(보류). 형식(`DLC-형식.md`의 `territory` 절)은 그대로라 영토가 든 DLC를 열어도 오류는 나지 않습니다.

## 7-1. 앱으로 쓰기 — PWA · Windows 설치 파일

웹 폴더 하나가 원본이고, 앱은 그것을 그대로 감싼 것입니다. 원본 하나에서 **프로그램 두 개를 따로** 포장합니다 — 길은 메이커 → 연표 한 방향뿐이고, 연표 프로그램에는 메이커 파일이 아예 들어 있지 않습니다.

| 프로그램 | 들어 있는 것 | 웹 폴더 | Windows 파일 (`배포/`) |
| --- | --- | --- | --- |
| **역사 연표** | 연표(보기 전용) · DLC 관리 | `dist/web` | `역사연표-<버전>.exe` · `역사연표-설치-<버전>.exe` |
| **DLC 메이커** | 메이커 + 반영한 모습을 보는 연표 미리보기(도구 줄의 `연표로 ↗`) | `dist/maker` | `DLC메이커-<버전>.exe` · `DLC메이커-설치-<버전>.exe` |

**메이커에서 만든 DLC를 연표 프로그램으로 옮기기** — 두 프로그램은 저장소가 따로입니다(따로 설치되고, 저장한 것이 섞이지 않음). 그래서 메이커의 `반영`은 메이커 안의 연표 미리보기에만 보이고, 연표 프로그램으로는 파일로 옮깁니다.

1. 메이커에서 `반영`하고 미리보기(`연표로 ↗`)에서 확인한 뒤 `파일로`를 눌러 팩 파일(.htpack)을 저장합니다.
2. 연표 프로그램의 `DLC 관리`에서 그 파일을 설치합니다(창에 끌어다 놓아도 됨). 같은 id의 DLC가 이미 있으면 두 판을 보여 주며 바꿀지 한 번 묻고, 확인하면 새 파일로 덮어쓰고 켭니다. 판이 더 낮은 파일도 확인하면 덮어쓰므로 물음에 적힌 판을 보고 고르세요.
3. 연표에 설치해 둔 DLC를 메이커에서 고치려면 연표의 `DLC 관리`에서 그 DLC를 `내보내기`로 파일로 받아, 메이커의 처음 화면에서 그 파일을 엽니다(끌어다 놓아도 됨).

**연표와 메이커가 한 프로그램이던 옛 Windows 판에서 넘어올 때** — 새 연표 프로그램은 옛 판과 같은 프로그램으로 여겨져 그 위에 설치되고 저장한 것도 이어받지만, 새 연표에는 메이커가 없고 새 메이커 프로그램은 저장소가 따로입니다. 그래서 옛 판의 메이커에서 `반영`하지 않고 고치던 것이 있으면 **새 판을 설치하기 전에** 옛 판의 메이커에서 `반영`하거나 `파일로` 저장해 두세요(저장한 파일은 새 메이커의 처음 화면에서 엽니다). 반영해 둔 DLC는 새 연표에 그대로 남습니다.

같은 프로그램을 브라우저와 앱처럼 두 곳에서 쓸 때도 저장소가 따로이므로, 옮길 때는 `DLC 관리 → 백업 파일 저장`으로 받은 파일을 다른 쪽의 설치 칸에 놓습니다.

| 하고 싶은 것 | 방법 |
| --- | --- |
| 웹 폴더 만들기 | `npm run web` → `dist/web`(연표)과 `dist/maker`(메이커) 두 폴더. 폴더마다 화면이 읽는 파일이 다 있는지 · 연표 폴더에 메이커 파일이 없는지 검사하고, 오프라인 캐시 목록(`sw.js`)을 그 폴더의 파일에 맞춰 씁니다 |
| 폰·PC 홈 화면에 설치 (PWA) | `dist/web`과 `dist/maker`를 https 주소(예: GitHub Pages)의 **서로 다른 폴더에 따로** 올린 뒤, 크롬·엣지·사파리에서 "앱 설치 / 홈 화면에 추가". 연표와 메이커가 두 앱으로 따로 설치되고 오프라인에서도 열립니다. 메이커는 `…/dlc-maker.html` 주소로 엽니다(폴더 주소만 치면 미리보기 연표가 열림). 두 폴더를 같은 사이트(같은 주소 앞부분)에 올리면 브라우저 저장소를 함께 써서 메이커의 `반영`이 연표에도 바로 보이고, 다른 사이트에 올리면 위처럼 파일로 옮깁니다 |
| 로컬에서 PWA 확인 | 연표 `npm run pwa:serve` → `http://localhost:8766` · 메이커 `npm run pwa:serve:maker` → `http://localhost:8767/dlc-maker.html` |
| Windows 설치 파일 | `npm install` 한 번 → 연표 `npm run desktop:build` · 메이커 `npm run desktop:build:maker` · 둘 다 `npm run desktop:build:all` → **`배포/` 폴더**에 위 표의 설치 파일(`…-설치-<버전>.exe`)과 설치 없이 바로 실행하는 파일(`…-<버전>.exe`)이 생깁니다 (Rust 필요). 두 프로그램은 빌드 폴더를 함께 쓰므로 하나씩 차례로 만듭니다(`:all`이 그렇게 함) |
| Windows 앱을 창으로 바로 실행 | 연표 `npm run desktop:dev` · 메이커 `npm run desktop:dev:maker` |
| 버전 올리기 | `npm version patch` — package.json · sw.js · tauri.conf.json · Cargo.toml이 함께 맞춰집니다(메이커 설정은 판을 따로 적지 않고 연표 설정의 판을 씁니다). 독립형 연표 앱의 판(`prototype/app/pubspec.yaml`의 `version: <판>+<번호>`)도 같은 판으로 손으로 올립니다(번호는 하나씩 — 안드로이드 versionCode) |
| 자동 빌드 · 게시 | 아래 7-3절 — `.github/workflows/release.yml`이 독립형 연표 앱(exe · apk)과 두 프로그램 · 웹 zip을 한 번에 지어 시험판 Release로 올립니다 |

앱 아이콘을 바꾸려면 `icons/app-1024.png`(1024×1024 PNG)를 바꿔 넣고 `npm run icons`와 `npm run desktop:icons`를 실행합니다.

## 7-3. 릴리즈 — GitHub Actions

`.github/workflows/release.yml`이 한 번에 짓고 GitHub Release(**시험판**)로 게시합니다. 부르는 법: GitHub의 **Actions → release → Run workflow**(입력 없음 — 부르면 곧 게시) 또는 태그 `v<판>`을 밀기. 판은 `package.json`의 version이고 `prototype/app/pubspec.yaml`도 같아야 하며(어긋나면 첫 작업에서 멈춤), 이미 있는 태그 · 릴리즈는 덮어쓰지 않으므로 새로 내려면 판을 올립니다.

| 올라가는 것 | 무엇 · 어디서 짓나 |
| --- | --- |
| `HistoryTimeline-<판>-windows-x64-setup.exe` · `…-portable.zip` | 독립형 연표 앱(새 엔진 `prototype/engine` + Flutter `prototype/app`) Windows판 — 사용자 폴더 설치(관리자 권한 없음) · 설치 없이 쓰는 zip. 동아시아 · 등불 연대기(견본) 저장소(엔진 `archive-tool build`로 지어 달력 표가 듦 — 앱에서 DLC를 넣고 뺌)와 엔진 도구가 들어 있음(Node.js 없음) |
| `HistoryTimeline-<판>-arm64.apk` | 독립형 연표 앱 안드로이드판(`release.yml`의 `ANDROID_SEED`가 고른 저장소 포함 — 지금은 등불 연대기(판타지 판) · 디버그 키 서명) |
| `HistoryTimeline-Web-<판>-…exe` · `HistoryTimelineMaker-<판>-…exe` | 지금 연표 · DLC 메이커의 Windows 프로그램(위 7-1의 두 설치 파일과 단일 실행 파일 — 이 빌드가 실패해도 게시는 막지 않음) |
| `HistoryTimeline-<판>-web.zip` · `HistoryTimelineMaker-<판>-web.zip` | 웹 폴더 둘(`npm run web`) |
| `HistoryTimeline-<판>-sample-lantern.htpack` | 견본 DLC 등불 연대기(`samples/sample-lantern.json`을 전용 팩으로 — 큰 판에서) |
| `SHA256SUMS.txt` | 위 파일들의 SHA-256 |

독립형 앱의 **저장소**는 둘입니다 — **동아시아**(동아시아 기본팩 · 독립형 앱이 기본으로 엶)와 **등불 연대기**(견본 `samples/sample-lantern.json` — 기본팩 없이 따로 세계 하나 · 기능을 다 보이게). 안드로이드 APK에는 `.github/workflows/release.yml`의 `ANDROID_SEED`가 고른 저장소 하나가 들어갑니다(0.0.2부터 `lantern` — 등불 연대기만 든 판타지 판). `node prototype/scripts/build-showcase.mjs <출력 폴더>`가 짓고(먼저 `cargo build --locked --release --manifest-path prototype/engine/Cargo.toml`), 견본 목록은 적어 두지 않고 규칙으로 고르므로 `samples/`에 새 견본이 들어오면 저절로 따라옵니다(분류가 `world`면 제 저장소, 아니면 동아시아 기본팩 위에 얹음 — 뺄 것과 까닭은 그 파일 머리말). 같은 출력(저장소 + 기본팩 원본 + `showcase.json`)을 HistoryArchive 연표 모듈의 seed로도 씁니다. 포장은 `prototype/scripts/bundle-app.mjs`(꾸러미) · `prototype/scripts/release/`(Inno Setup · 연기 검사 · 안드로이드 빌드 · 릴리즈 글)입니다.

저장소는 엔진이 짓습니다(`build-showcase.mjs` → `archive-tool build` — 배치도 엔진이 셈하고 보조 달력 표를 저장소 안에 넣음 · 한 벌 P3). 독립형 앱의 DLC 넣기 · 빼기 · 끄기 · 켜기는 Windows · 안드로이드 모두 앱 안의 엔진(`add_pack` · `remove_pack` — 계약 2-7-1)이 하고, 꾸러미의 `도구/`에는 엔진 도구 `archive-tool.exe`와 기본팩 원본만 있습니다(Node.js · `DLC-추가.cmd` 없음 — `prototype/scripts/add-dlc.mjs`는 정답지 · 비교용이라 사용자 저장소에 쓰지 않음). 컴퓨터에서 손으로 넣고 빼는 길 · 짓는 명령은 `prototype/README.md`의 '한 벌 P3 · P4' 절, **휴대폰에서 DLC를 넣는 차례(실기기에서는 아직 돌려 보지 않음)**는 같은 문서의 '휴대폰에서 DLC 넣기' 절입니다. 앱을 띄우는 검사는 늘 `--memory-dir=<폴더>`로 띄워 사용자의 앱 기억을 건드리지 않습니다.

## 7-2. 별도로 보존한 모바일 포팅

2026-09-20 감독 결정에 따라 안드로이드 앱 포팅은 **`codex/mobile-port` 가지 · 원래 저장소의 `.claude/worktrees/mobile-port` 폴더**에서 따로 관리합니다. 이 PC·웹 작업본(`codex/desktop-next`)에서는 안드로이드 앱을 빌드하거나 배포하지 않습니다. 일반 휴대폰 브라우저에서 웹 연표를 열고 터치로 조작하는 기능은 계속 유지합니다.
