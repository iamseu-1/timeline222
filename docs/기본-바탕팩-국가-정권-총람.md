# 연표 프로그램 기본 바탕팩(Base Pack) — 국가·정권 총람

## 0. 기본 바탕팩 설계 원칙

1. **선정 기준 (고등학교 역사 교과서 + 학계 표준 개설서)**
   - 대한민국 고등학교 『한국사』·『동아시아사』·『세계사』 교육과정 및 학계 표준 개설서에서 **단원 본문·연표·지도에 필수적으로 등장하는 메이저 국가·왕조·정권**만 기본 바탕팩(Base Pack)에 수록합니다.
   - 전공 연구 수준의 소국·방국(方國)·단명 반란 정권·지방 번진·개별 군벌·수백 개 봉건 제후국은 기본 바탕팩에서 제외하여 초기 연표의 가독성을 확보하고, **추후 지역팩·시대팩 DLC로 빈자리를 촘촘히 채우는 구조**로 설계합니다.
2. **분열기·시대의 처리 (개별 핵심 정권 + 시대 구분/대범위 그릇)**
   - 기존의 ‘춘추 시대’, ‘전국 시대’, ‘삼국 시대’, ‘5호 16국’, ‘남북조’, ‘5대 10국’처럼 **시대를 하나의 가상 국가처럼 뭉뚱그리지 않습니다.**
   - 분열기 명칭은 **시대 구분(`epochs`) 및 대범위(`scopes`) 그릇**으로 두고, 연표의 실제 띠(`periods`)에는 교과서에 등장하는 **핵심 개별 국가**(예: 춘추 5패·전국 7웅, 위·촉·오, 전조·후조·전진·북위, 송·제·양·진, 후량~후주 등)를 **1행 1정권**으로 독립 배치합니다.
   - 일본사 역시 ‘가마쿠라 시대’ 같은 시대 이름을 정권 띠로 쓰지 않고, **시대 구분은 날짜 칸**에 두며 실제 정권은 **조정(야마토 왕권 → 일본 천황 조정)**과 **실권 정권(가마쿠라 막부 · 무로마치 막부 · 에도 막부)**으로 명확히 분리합니다.
   - 서양사처럼 한 국가가 정체를 여러 번 바꾼 경우(로마 왕정→공화정→제정, 프랑스 왕국→제1~5공화국·제1~2제정 등)는 **나라 서류철(상위 그릇)** 안에 정체별 정권을 차례로 담습니다.
3. **표기 원칙 (학계 표준 용어 + 중국어 한국 한자음 일원화)**
   - 모든 국가명·시대명·인명·지명·제도명은 **한국 역사학계 표준 용어**를 따릅니다.
   - **중국사 표기**: 전근대는 물론 **근현대 인명·지명·정권명까지 모두 한국 한자음**으로 통일합니다(예: 북경·남경·장안·낙양·개봉·임안·광동·무한·중경·대북 / 손문·원세개·장개석·모택동·주은래·등소평·습근평). 단, 흉노·선비·돌궐·위구르·거란·여진·몽골·칭기즈 칸·쿠빌라이·누르하치·홍타이지 등 학계 표준이 알타이계 원음 표기인 북방 유목 고유명사는 학계 관례를 따릅니다.
   - 2026-10-23 손질(`docs/점검-세계사-확장-전수조사.md` 3-9): 한 줄에 정체 여럿을 적었던 줄(프랑스 제2공화국 → 제2제정, 베네치아 · 피렌체, 팔레비 → 이란 이슬람 공화국 …)을 **정체마다 한 줄**로 가르고, 종류 칸의 둘짜리 값(교회 · 국가, 연방 · 국가)을 **하나**로 했습니다 — 객체의 `type`은 하나이고 교단(로마 가톨릭교회)은 나라와 따로 둡니다. 이름 괄호 안의 → 는 같은 정체의 이름 · 지위 변천입니다.
4. **권역 분할**
   - 동아시아: **한국사** · **중국사(중원 및 북방·초원)** · **일본사**
   - 서양사 및 세계사 세분화: **서아시아사(오리엔트·페르시아·이슬람)** · **아프리카사(이집트·북아프리카·사하라 이남)** · **유럽사(고대 지중해·서유럽·중부유럽·동유럽·러시아)** · **아메리카사(고대 문명 및 근현대 미주)**

# 제2부. 중국사 및 북방·초원사 (트랙: `중국` · `초원` / 문화권: `동아시아` · `초원`)

> **표기 주의**: 모든 중국 인명·지명·정권명은 근현대를 포함해 **한국 한자음**(예: 북경·남경·장안·낙양·개봉·임안·대북 / 손문·원세개·장개석·모택동·등소평·습근평)으로 표기합니다. 분열기(춘추·전국·삼국·5호16국·남북조·5대10국)는 시대 구분/대범위로 묶고 교과서 핵심 국가들을 개별 행으로 배치합니다.

# 제3부. 일본사 (트랙: `일본` / 문화권: `동아시아`)

> **구성 원칙**: 기존의 ‘가마쿠라 시대’, ‘무로마치 시대’, ‘에도 시대’처럼 시대 구분 이름을 그대로 국가 띠로 쓰지 않습니다.
> - **시대 구분(`epochs`)**: 조몬 → 야요이 → 고분 → 아스카 → 나라 → 헤이안 → 가마쿠라 → 남북조·무로마치·전국 → 아즈치·모모야마 → 에도 → 메이지·다이쇼·쇼와·헤이세이·레이와를 연표 상단 시대 구분으로 둡니다.
> - **실제 정권 띠(`periods`)**: 명목상 주권자인 **조정(야마타이국 → 야마토 정권 → 일본 천황 조정 → 대일본 제국 → 일본국)** 줄과, 실제 통치권을 행사한 **실권 정권(가마쿠라 막부 · 무로마치 막부 · 오다·도요토미 정권 · 에도 막부)** 및 **류큐 왕국**을 분리해 배치합니다.

# 제5부. 아프리카사 (트랙: `고대 근동` · `이슬람` · `사하라 이남 아프리카` / 문화권 분담)

> **구성 원칙**: 감독 지시에 따라 아프리카 대륙의 역사를 독립된 부로 체계화합니다.
> - **고대 이집트 및 북아프리카**: 나일강 문명(고왕국·중왕국·신왕국·프톨레마이오스 왕조), 카르타고, 북아프리카 이슬람 왕조(파티마·무라비트·무와히드·맘루크·근현대 이집트).
> - **사하라 이남 아프리카**: 교과서 세계사 단원에 나오는 동부 아프리카(쿠시·악숨·에티오피아), 서부 아프리카 황금·소금 교역 제국(가나·말리·송가이), 남부·중부 아프리카(그레이트 짐바브웨·콩고·줄루·남아프리카 공화국).
