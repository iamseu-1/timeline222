# 리메이크 6단계 — 자료와 세계사 확장

> **에이전트 작업자에게:** 과제를 하나씩, 걸음은 체크 상자(`- [ ]`)로. 과제 끝마다 `인수인계.md` 5절에 다섯 줄 안으로. 감독 확인 전에는 main에 합치지 않습니다. 전체 지도는 `docs/계획-리메이크-전체.md`.

**목표:** 둘이다. ① **자료** — 기본팩(동아시아) · 견본(등불 연대기)이 새 문법(시대 객체 · 나라 그릇 · 실권 정권 · 섬김 · 사람 · 빌림 · 문화권 줄)을 쓴다(설계 2절 6단계 · 6절). ② **세계사 확장** — 전수조사가 남긴 결정 일곱(이름 번호 · 지도자 이름 낱말 · 유럽 트랙 · 민족 묶음 · 북방 유목 · 종교 칸 · 달력 다섯)을 형식 · 메이커 · 앱에 넣어, 세계 각 문화권을 적을 칸을 갖춘다(`docs/점검-세계사-확장-전수조사.md` 6절). 끝의 모습: 기본팩 · 견본이 새 장치를 쓰고 저장소를 다시 지어 앱이 그리며, 감독의 실자료(KoreanTimeLine)가 새 판에서 바르게 보인다.

**짜임:** ②는 형식에 칸을 더하는 일이라 3 · 4 · 5단계의 작은 되풀이다 — 칸마다 `DLC-형식.md` → 정규화(`core.js` + 엔진 거울) → 메이커 편집 → 내보내기 · 저장소(계약) → 앱 그림. ①은 그 칸이 갖춰진 뒤 자료만 고친다. **`packs/` · `samples/`를 바꾸는 일이라 감독 승인 뒤**에만 한다(인수인계 4절 5 · 설계 6절).

## 전체 제약

* **`packs/`는 감독 승인(전체 지도 G8) 뒤에만** 고친다. 승인이 없으면 이음 층의 **손질 표**(읽을 때만 바꿈 — 설계 6절)로 대신한다.
* 자료를 채울 때는 역사 자료 채우기 방침 — 근거 · 확실성 표시. 실제 역사 이름은 기본팩에만, 견본 · 검사 자료의 이름은 가상.
* 형식에 칸을 더하면 **형식 문서 · 메이커 편집 · 연표 표시를 함께**(인수인계 4절 5). 옛 파일은 그대로 열린다.
* 저장소를 다시 지으면 dev-smoke의 모델 지문 · 정답지 · 골든이 바뀐다 — 바뀐 까닭을 커밋 글에.
* 작업은 main에서 가지 `remake-6`(+ 결정마다 작은 가지) · 작업 폴더 `.claude/worktrees/remake-6`.

* **기본팩 손질은 규칙("`packs/`는 바꾸지 않음")과 부딪힌다** — 승인 범위를 과제 0에서 줄 단위로 받는다. 승인이 없으면 손질 표로만.
