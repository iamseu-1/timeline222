## 2. 팩 — 묶음 파일 `.htpack`

### 2-1. 파일 안

압축(zip) 파일 하나. 확장자 `.htpack`, 파일 이름은 `<id>-v<판>.htpack`.

```
<id>-v<판>.htpack
├─ pack.json          팩 정보 (2-2)
├─ images/
│   └─ cover.webp     표지 (있을 때만 — png · jpg · webp 가운데 하나)
└─ content/
    ├─ base.json       바탕: tracks · categories · peoples · rankDefs · houses
    ├─ history.json    역사: periods(지도자 · 내각 · 연호 · 도읍 · 시기 · 지위 칸 포함) · dynasties · organs · cultures
    ├─ events.json     사건: events (조약 포함)
    ├─ figures.json    인물: figures
    ├─ divisions.json  구분: epochs · scopes
    ├─ overrides.json  덮어쓰기: patches
    └─ documents.json  문서: documents
```

* 부분 파일은 목록이 비었으면 넣지 않습니다. 부분 파일 하나는 `{ "<목록 이름>": [...] }` 꼴(문서는 `{ "documents": { 키: 글 } }`)이라, 모두 합치면 옛 DLC JSON과 같은 모양이 됩니다.
* 읽을 때는 `pack.json` + 부분 파일들을 합쳐 지금의 `HT.normalizePack`에 넘깁니다 — 그 뒤(모델 · 연표)는 바뀌지 않습니다.
* 압축은 deflate(브라우저의 `CompressionStream('deflate-raw')`), 쓸 수 없는 환경이면 압축 없이(store). 읽기는 둘 다. 암호 · zip64 · 여러 조각 압축은 받지 않습니다(알림).
* 한 파일 64MB, 부분 파일 하나 32MB를 넘으면 받지 않습니다(알림).
* `images/`에는 이번에는 표지만 넣습니다. 깃발 · 초상 · 문서 그림은 자리만(11절).

### 2-2. `pack.json` — 팩 정보

지금 DLC 파일의 맨 위 칸에 아래를 더합니다(★ = 새 칸). `.json` 한 파일로 내보낼 때도 같은 칸이 맨 위에 들어갑니다(표지는 그림 대신 data URL).

| 열쇠 | 뜻 | 비우면 |
|---|---|---|
| `format` · `formatVersion` | 지금처럼 (`history-timeline-dlc`) | — |
| `id` · `name` · `version` · `author` · `description` | 지금처럼 | — |
| ★ `category` | 분류: `expansion`(확장팩) · `region`(지역팩) · `nation`(나라팩) · `theory`(학설팩) · `world`(세계관팩) · `docs`(문서팩) | 없음(분류 없음) |
| ★ `tags` | 태그 글 목록, 5개까지 · 하나에 20자까지 | 없음 |
| ★ `summary` | 짧은 소개, 120자까지 — 카드에 두 줄 | 설명의 첫 줄 |
| ★ `highlights` | 볼거리 글머리 목록, 10줄까지 | 없음 |
| ★ `cover` | 표지 — `.htpack` 안에서는 그림 파일 길(`images/cover.webp`), 설치본 · `.json`에서는 `data:image/…;base64,…` | 자동 표지(2-6) |
| ★ `relations` | `[{ "type": "needs" \| "conflicts" \| "after", "id": "…", "name": "…" }]` (2-4) | 없음 |
| ★ `changelog` | `[{ "version": "1.0.3", "date": "2026-09-20", "note": "…" }]` 새것이 앞 | 없음 |
| ★ `created` · `updated` | 처음 만든 날 · 마지막 반영한 날 (`YYYY-MM-DD`) | 없음 |
| `requires` (있던 칸) | **함께 쓰면 좋은 팩**(recommends) — 지금 그대로 씁니다(관계 목록으로 옮기지 않음: 옮기면 기존 DLC 파일이 모두 한 글자씩 바뀜) | `[]` |

* 새 칸(★)은 **적은 것만** 파일에 나갑니다 — 새 칸을 쓰지 않은 DLC는 읽고 다시 써도 한 글자도 달라지지 않습니다(옛 견본 해시 그대로).
* 새 칸(★)을 하나라도 쓴 파일은 `formatVersion` 2로 적습니다(`HT.NEW_FORMAT_KEYS`에 더함) — 옛 프로그램은 "더 새로운 형식" 경고를 띄우고 모르는 칸만 버립니다.
* 검사: 모르는 `category`는 경고하고 없는 것으로, 태그 · 글머리 개수 초과는 앞의 것만 남기고 경고, `cover`가 그림 data URL이 아니거나 1.5MB를 넘으면 경고하고 버림, 관계의 `type`이 모르는 것이면 그 줄만 버림(경고).

### 2-3. 분류

| 분류 | 무엇 | 패러독스에서 |
|---|---|---|
| 확장팩 | 여러 지역 · 시대를 크게 더함 | Expansion |
| 지역팩 | 한 지역을 깊이 | Immersion Pack |
| 나라팩 | 한두 나라 | Chronicle Pack |
| 학설팩 | 다른 팩의 연대 · 이름을 다른 학설로 덮어씀 | (모드의 overhaul) |
| 세계관팩 | 가상 세계 (소설 · 게임) | total conversion |
| 문서팩 | 문서(위키) 위주 | E-book |

기본 내장 팩은 분류 대신 '기본팩' 딱지. 분류 이름 · 차례는 `HT.PACK_CATEGORIES` 한 표에서 옵니다.

### 2-4. 관계

| `type` | 뜻 | 연표가 하는 일 | 메이커가 하는 일 |
|---|---|---|---|
| `needs` 필요 | 이 팩이 있어야 제대로 보임 | 없거나 꺼져 있으면 카드에 ⚠ + (설치돼 있으면) [켜기]. 이 팩보다 먼저 불러옴 | 내 DLC에 **덮어쓰기가 있으면 그 대상 팩을 저절로 넣음**(지울 수 없고 '덮어쓰기 때문'으로 표시) |
| (`requires`) 함께 쓰면 좋음 | 참고용 — 있던 칸 `requires` 그대로 | 자세히에 목록만 | — |
| `conflicts` 함께 못 씀 | 함께 켜면 문제 | 둘 다 켜져 있으면 두 카드에 ⚠ | — |
| `after` 뒤에 불러오기 | 같은 항목을 덮어쓰면 이 팩이 이김 | 그 팩보다 뒤에 불러옴 | — |

**불러오는 차례**: 기본팩 → 나머지는 설치한 차례를 기본으로 하되 `needs` · `after`가 가리키는 팩보다 뒤로(차례를 지키는 가장 작은 옮김). 서로 뒤를 요구하는 고리가 생기면 설치한 차례대로 두고, 고리를 이룬 줄은 무시한 채 카드에 알림(덜 옮기는 쪽). 차례를 손으로 바꾸는 창은 두지 않습니다(11절).

### 2-5. 연표(보기 전용) 쪽

* **설치**: DLC 관리의 [＋ DLC 설치] · 창에 끌어다 놓기 · PWA 파일 연결(`file_handlers`에 `.htpack`) · 안드로이드 연결 프로그램(`.htpack`을 여는 인텐트, 파일을 바이트로 읽어 넘김) 모두 `.htpack`과 `.json`을 받습니다. 설치 기록 글에 `.htpack`이면 '팩 파일'로.
* **DLC 관리**: 표지 카드 모눈(3열) + 고른 팩의 자세히(오른쪽). 카드: 표지 · 분류 딱지 · 이름 · 판 · 켜기 스위치 · 짧은 소개(두 줄) · 태그 · 담긴 것(저절로: 시대 n · 사건 n · 인물 n · 덮어쓰기 n …) · 관계 줄(✓ 필요한 팩 켜짐 / ⚠ 없음 · 꺼짐 [켜기] / ⚠ 함께 못 씀). 위 칸: 분류 거르기(전체 · 기본팩 · 분류 여섯) · 이름 · 태그로 찾기 · [백업 저장] · [＋ DLC 설치]. 자세히: 큰 표지 · 이름 · 판 · 만든 사람 · 설명 · 볼거리 · 담긴 것 · 관계 · 판 기록 · [파일로 저장(.htpack)] · [지우기]. 아래 줄: 켜 둔 팩 수 · 불러오는 차례 한 줄.
* **내보내기**: DLC 관리의 [파일로 저장]은 `.htpack`. 기본팩도 같은 모양으로.
* 설치본은 지금처럼 브라우저 저장소(`ht.packs.installed`)에 JSON으로 둡니다 — 표지는 2-6의 크기로 줄인 data URL을 팩 안에. 그래서 PC · 안드로이드 앱의 저장소 거울(`state.json`)도 그대로 표지까지 지킵니다.

### 2-6. 표지

* 16:9. 메이커에서 넣는 길 셋: **그림 파일 고르기**(png · jpg · webp) · **📷 지금 연표를 표지로**(지금 보이는 연표를 그림 내보내기 엔진으로 1600×900에 그림) · **자동 표지로**(지움).
* 넣을 때 가운데를 16:9로 자르고 1600×900 이하 webp(안 되면 jpeg, 품질 0.85)로 줄입니다. 설치본에는 960×540 이하로 한 번 더 줄여 넣습니다(한 장 대개 60~150KB).
* **자동 표지**: 표지가 없으면 그 팩의 시대를 가는 둥근 막대(제 색 · 제 기간)로 그린 그림 — 겹치지 않게 줄을 나눠 세로 가운데. 시대가 없는 팩(학설팩 등)은 옅은 줄무늬. 카드 · 처음 화면 · 팩 정보가 같은 함수(`HT.autoCover`)를 씁니다.

## 3. 메이커 작업실 (A안)

### 3-1. 배치

```
┌ 메뉴 줄 30px: DLC 메이커 · 파일 편집 보기 넣기 도구 도움말 ··········· 고치는 DLC 이름 v판 · ● 저장됨 ┐
├ 도구 줄 42px: ↶ ↷ │ ＋시대 ＋사건 ＋인물 ＋더▾ │ 복제 · 한꺼번에 고치기 · 붙여넣기 │ [찾기 Ctrl K] ··· 검사 ✓ · 고친 것 n · [반영] · 파일로 · 연표로 ↗ ┤
├ 왼쪽 280px ─────┬ 가운데: [연표] [표] [문서] 탭 ─────────────────────────────┬ 오른쪽 380px ─┤
│ [구조] [불러온 팩] │  연표 (지금의 연표 그대로 — 내 DLC만, 불러온 팩은 흐리게)   │ 속성            │
│  찾기 · 걸러 보기  │                                                          │ (편집 창을      │
│  팩 부분 목록      │                                                          │  붙박이로)      │
│                    ├ 아래 창(접힘): [문제] [빈 칸] [찾아 바꾸기 결과] ────────┤                 │
└ 상태 줄 24px: 저장 · 검사 오류 n 경고 n · 담긴 것 · 불러온 팩 · 고른 것 n ··· 고친 것 n · 반영하면 v판 · 단축키 도움 ┘
```

* 왼쪽 · 오른쪽 창은 가장자리를 끌어 폭을 바꾸고(왼쪽 200~480px, 오른쪽 320px~화면의 60%), 접을 수 있습니다(왼쪽 Ctrl+B · 오른쪽 Ctrl+Alt+B · 아래 Ctrl+J). 폭 · 접힘 · 아래 창 높이 · 가운데 탭은 기억(`ht.maker.ui`).
* 오른쪽 속성 창 = 지금의 편집 창을 붙박이로(떼어 내 띄우기는 그대로 둠). 아무것도 고르지 않았으면 "고른 것 없음 — 연표나 목록에서 항목을 누르세요"와 자주 쓰는 추가 단추.
* 화면 폭이 1100px보다 좁으면 왼쪽 창이 접힌 채로 시작하고, 860px보다 좁으면 지금처럼 속성 창이 화면을 덮는 시트.
* **움직임**: 창 접기 · 탭 바꾸기 · 아래 창 열기는 `docs/움직임-원칙.md`의 토큰(`--t-move` · `--spring` …)만. 접히는 동안 연표는 한 번만 다시 잽니다.

### 3-3. 처음 화면

프로그램을 열었을 때 고치던 작업본이 있으면 **곧장 작업실**(지금처럼 마지막 모습), 없으면 처음 화면. 작업 중에는 파일 ▸ 처음 화면. 처음 화면이 지금의 '어느 DLC를 고칠까요' 창을 대신합니다.

* **이어서 고치기**(작업본이 있을 때): 표지 · 이름 · 판 · 담긴 것 · 불러온 팩 · 반영하지 않은 고침 n · 마지막으로 고친 때 · [이어서 고치기] [반영하고 닫기].
* **새로 만들기**: 이름 · id(겹치지 않게 저절로) · 분류 · 시작 방법 셋 — **빈 DLC**(아무것도 없이) / **기본팩에 덧붙이기**(기본팩을 불러온 채로(잠김) 시작 — 기본팩의 트랙 · 민족을 씀) / **가상 세계**(이 DLC의 트랙 하나를 만들고 시작) · [만들기].
* **열기**: [📂 DLC 파일 열기 (.htpack · .json)] · 화면에 끌어다 놓기.
* **설치된 DLC에서 고치기**: 표지 카드(연표의 DLC 관리와 같은 카드, 스위치 없음). 기본팩은 없음 — "기본팩은 직접 고치지 않습니다 — 내 DLC에 불러와 자물쇠를 풀고 덮어쓰거나, 항목을 내 DLC로 복사해 고칩니다".
* 다른 DLC로 바꿀 때 반영하지 않은 고침이 있으면 지금처럼 '반영하고 바꾸기 / 버리고 바꾸기 / 취소'(바꾸기 직전에 자동 저장 기록 한 장).

### 3-4. 왼쪽 '구조' 탭

팩 파일 안의 부분을 그대로 보여 주는 나무:

```
📦 DLC 이름                 v판      ← 누르면 오른쪽이 '팩 정보'
▸ 바탕     트랙 · 분류 · 민족 · 지위 · 가문
▾ 역사     시대(트랙별로 묶음) · 왕조 · 기관 · 문화
▸ 사건     (트랙별로 묶음, 조약 포함)
▸ 인물
▸ 구분     시대 구분 · 대범위
▸ 덮어쓰기  남의 항목에 건 고침 · 숨김 (지금의 '고친 것' 창의 패치 목록)
▸ 문서
▸ 그림     표지
```

* 항목을 누르면: 고름 → 연표가 그 항목으로(필요할 때만 움직임 — 움직임 원칙) → 오른쪽 속성. 두 번 누르면 속성 창의 이름 칸.
* 부분 이름(예: '사건')을 누르면 가운데가 **표 탭의 그 목록**으로. 바탕의 줄(트랙 · 분류 …)도 표 탭(지금의 '바탕 자료' 창을 대신).
* 맨 위 찾기 칸: 이 DLC 안에서 이름 · 연도로 걸러 보기(나무가 줄어듦).
* 여러 개 고르기: Ctrl+누르기 · Shift+누르기. 오른쪽 누르기 메뉴: 복제 · 복사 · 지우기 · 문서 · 연표에서 보기.
* 검사 오류가 있는 항목은 이름 옆에 붉은 점.

### 3-5. 왼쪽 '불러온 팩' 탭

* 맨 위: **고치는 DLC**(강조 테두리 · '편집 중').
* 아래: **불러온 팩** 줄마다 👁(보이기) · 🔒(자물쇠) · 이름 · 판 · 담긴 것. 맨 아래 [＋ 팩 불러오기] — 설치된 팩(기본팩 포함) 목록에서 고르거나, 파일(.htpack · .json)에서(메이커 저장소에 설치하고 불러옴).
* **처음에는 없음**(이 DLC만). 예외: 내 DLC의 덮어쓰기가 가리키는 팩과 `needs`의 팩은 저절로 들어오고(잠긴 채) 빼지 못합니다 — 줄에 '덮어쓰기 대상' · '필요한 팩'.
* 불러온 팩은 **DLC마다 기억**(`ht.maker.refs` = `{ DLC id: [{ id, show, locked }] }`).
* **흐리게**: 불러온 팩의 띠 · 점 · 이름 칸은 옅게(보기 메뉴에서 옅게 30% · 보통 45% · 진하게 65%, 기본 보통) + 채도를 낮춤. 자물쇠를 풀면 조금 덜 흐리게(+15%).
* **잠긴 항목을 누르면**: 속성 창이 읽기 전용 상세 + [🔓 자물쇠 풀기(이 팩)] [내 DLC로 복사]. 잠긴 항목은 끌기 손잡이가 없고, 지우기는 막힘(알림).
* **자물쇠를 풀면**: 지금 메이커와 똑같이 — 고친 칸만 내 DLC의 덮어쓰기(패치), 지우기는 숨김. 자물쇠 상태도 DLC마다 기억. 덮어쓰기를 하나라도 만들면 그 팩은 '필요한 팩'이 됨(2-4).
* 불러온 팩은 **반영 · 파일로에 들어가지 않습니다**(작업본만 나감 — 지금과 같음).

### 3-6. 팩 정보 (구조의 📦을 누르면 오른쪽에)

위에서부터: DLC 관리 카드 미리보기('DLC 관리에서 이렇게 보입니다') · 표지(그림 고르기… · 📷 지금 연표를 표지로 · 자동 표지로) · 이름* · id* · 판(반영하면 저절로) · 분류 · 만든 사람 · 태그(5개까지, 칩) · 짧은 소개 · 설명 · 볼거리(줄 더하기 · 빼기 · 끌어 차례) · 관계(필요한 팩 — 덮어쓰기 대상은 잠긴 칩 / 함께 쓰면 좋음 / 함께 못 씀 / 뒤에 불러오기 — 설치된 팩에서 고르거나 id를 적음) · 판 기록(다음 반영 줄은 저절로, 지난 줄은 고쳐 쓸 수 있음) · 담긴 것.
지금의 'DLC 정보' 대화상자는 이것으로 대신합니다(id 바꿈 경고 · 쓰는 곳 따라 고치기는 그대로).

### 3-7. 반영 · 파일로

* **반영**(Ctrl+E): 지금 규칙 그대로(묻지 않고 판을 올려 덮어씀 — 설치본이 따로 바뀐 경우만 물음) + **판 기록 한 줄을 저절로**: `{ version: 새 판, date: 오늘, note: 고친 것 요약 }` — 요약은 '시대 2 더함 · 사건 5 고침 · 덮어쓰기 1 더함'처럼 종류별 개수(`HT.draft.changes`에서). 그 줄은 팩 정보에서 고쳐 쓸 수 있고, 고치면 다음 반영이 덮지 않습니다. `updated`도 오늘로.
* **파일로**(도구 줄) = 팩 파일로 내보내기(.htpack). JSON 한 파일은 파일 메뉴.

## 4. 편집 기본기

### 4-1. 되돌리기 · 다시 하기
* 작업본을 바꾸는 **모든 일**이 한 걸음: 속성 창 저장 · 지우기 · 숨기기 · 덮어쓰기 되돌리기 · 표 칸 고치기 · 붙여넣기 · 한꺼번에 고치기 · 끌어서 고치기 · 복제 · 팩 정보 · 표지 · 문서 저장 · 찾아 바꾸기 · 바탕 자료의 id · 이름 바꾸기 · 설치된 판 불러오기. 불러온 팩 목록 · 흐리기 · 창 배치 같은 **보기 설정은 걸음이 아님**.
* Ctrl+Z / Ctrl+Y(Ctrl+Shift+Z). 글 칸 · 표 칸을 고치는 중에는 그 칸의 글자 되돌리기(브라우저 것).
* 걸음마다 이름: '시대 «…» 고침' · '사건 3개 붙여넣음' · '띠 끝 끌기 — «…» 끝 700 → 720' …
* **작업 기록**(도구 메뉴 · 아래 창에도): 걸음 목록, 누르면 그 걸음까지 한 번에(그 뒤는 다시 하기로 남음).
* 최대 200걸음 또는 64MB — 넘으면 오래된 것부터 버림. **창을 닫으면 사라짐**(더 오래된 시점은 자동 저장 기록).
* 되돌리면 연표 · 목록 · 표 · 열린 속성 창이 따라옴(속성 창에서 손대고 저장하지 않은 칸은 그대로 — 지금의 `syncEditor` 규칙).
* 반영한 뒤에도 되돌릴 수 있습니다(작업본만 — '고친 것'이 다시 생김).

### 4-2. 복제 (Ctrl+D)
* 내 항목: 같은 자리 · 같은 값 · 새 id · 이름 뒤에 ' (사본)'(문서도 함께), 복제한 것이 고른 것이 되고 속성 창의 이름 칸이 열림. 여러 개면 모두.
* 불러온 팩의 항목: **내 DLC로 복사**(아래 4-3과 같은 규칙, 이름은 그대로).
* 표 탭에서 칸을 여러 개 골랐을 때의 Ctrl+D는 '아래로 채우기'(5-3).

### 4-3. 복사 · 잘라내기 · 붙여넣기 (Ctrl+C / X / V)
* 고른 항목(내 것 · 불러온 팩의 것)을 복사: 시스템 클립보드에 두 가지로 — 이 프로그램용 묶음(항목 + 쓰는 트랙 · 분류 · 민족 · 지위 · 가문 정의 + 문서)과 표 글(탭으로 나눈 칸 — 엑셀에 붙음). 클립보드를 못 쓰면 프로그램 안 클립보드.
* 붙여넣기(연표 · 구조 · 표 탭에서): 내 DLC에 새 항목으로. id가 겹치면 새 id, 없는 트랙 · 분류 · 민족 · 지위 · 가문 정의는 함께 들어옴(같은 id가 이미 있으면 내 것을 씀), 문서도. 다른 DLC로 바꾼 뒤에도 됨. 한 걸음.
* 잘라내기 = 복사 + 지우기(내 항목만).
* 붙여넣은 글이 표 글(탭 · 여러 줄)이면 표 붙여넣기(5-2)로.

### 4-4. 자동 저장 기록
* 작업본은 지금처럼 고칠 때마다 저장됩니다. 그와 따로 **시점 사진**을 남깁니다: 고치는 중이면 10분마다(그 사이 바뀐 것이 있을 때만) + 큰 작업 직전(붙여넣기 넣기 · 한꺼번에 고치기(20개 넘을 때) · 모두 바꾸기 · 반영 · 다른 DLC로 바꾸기 · 파일 열기 · 설치된 판 불러오기 · 자동 저장 기록 되살리기).
* DLC마다 최근 30장. 도구 ▸ 자동 저장 기록: 때 · 까닭 · 담긴 것 · 지금과 다른 곳 수 → [이 시점으로 되돌리기](한 걸음 — 되돌리기로 취소됨).
* 이 컴퓨터의 브라우저 저장소(IndexedDB `ht-maker`)에만 — 앱의 `state.json` 거울에는 들어가지 않습니다(작업본 자체는 거울에 있음).

## 5. 대량 입력

### 5-1. 표 탭
* 구조에서 고른 목록의 표(기본: 시대). 목록 바꾸기는 표 위의 목록 칸에서도.
* **열**(목록마다, 열 고르기 · 폭 · 차례 기억):
  * 시대: 색 · 이름 · 시작 · 끝 · 트랙 · 종류 · 민족 · 소속(상위) · 실재성 · 지도자 n · 연호 n · 도읍 n · 설명 · 메모 · 문서
  * 사건: 날짜 · 끝 · 제목 · 트랙 · 분류 · 중요도 · 나라(polity) · 설명 · 출처 · 메모 · 문서
  * 인물: 이름 · 생몰 · 활동 · 트랙 · 섬긴 나라 · 역할 · 중요도 · 가문 · 설명 · 문서
  * 기관 · 문화 · 왕조 · 시대 구분 · 대범위: 이름 · 시작 · 끝 · 트랙 · (종류별 칸) · 설명
  * 바탕(트랙 · 분류 · 민족 · 지위 · 가문): 지금 바탕 자료 창의 열 그대로(`HT.makerKit.BASE_TABLES`) + 쓰는 곳
  * 덮어쓰기: 대상 · 대상 팩 · 고친 칸 · 숨김 · [보기] [되돌리기]
* **고치기**: 칸을 누르면 고름, 글자를 치거나 Enter · F2 · 두 번 누르기면 그 자리에서 고침, Enter · Tab으로 저장하고 옮김, Esc 취소. 날짜 칸은 연표의 날짜 글(기원전 · 월 · 일 · 미정 · 현재까지)을 그대로 읽음. 고를 칸(트랙 · 종류 · 분류 · 중요도 · 실재성)은 목록, 색은 견본.
* **목록 칸**(지도자 n …): 개수만, 두 번 누르면 속성 창의 그 칸으로(시대면 아래 하위 표가 열림 — 5-4).
* **고르기**: 칸 · 칸 범위(끌기 · Shift) · 줄(줄 머리 누르기 · Ctrl · Shift) · 모두(Ctrl+A). 줄을 고르면 연표 · 구조도 같이 고름.
* **정렬**: 열 머리 누르기(오름 · 내림 · 원래). **거르기**: 표 위 찾기 칸.
* **새 줄**: 맨 아래 빈 줄에 치면 새 항목(트랙은 위 줄 또는 첫 트랙).
* **지우기**: 줄을 고르고 Delete = 항목 지우기(한 걸음), 칸을 고르고 Delete = 칸 비우기.
* 표에는 **내 DLC 항목만**.
* 오류가 되는 값은 그 칸에 붉은 테두리 + 까닭(칸에 마우스)과 함께 **넣지 않음**(칸은 옛 값으로).
* 줄이 많아도 느리지 않게 보이는 줄만 그림(가상 목록). 줄 높이 28px.

### 5-2. 표 붙여넣기 (엑셀 · 구글 시트)
* 표 탭에서 Ctrl+V: 고른 칸부터 오른쪽 · 아래로 덮어씀, 줄이 모자라면 새 줄(새 항목). 첫 줄이 열 이름과 맞으면(지금 붙여넣기의 머리글 별칭 — `PASTE_HEAD` · `KIND_WORDS` · 확실성 별칭) 머리글로 보고 열을 이름으로 맞춤.
* 새 줄이 생기거나 걸린 칸이 있으면 넣기 전에 미리보기 줄(더할 것 n · 고칠 것 n · 걸린 칸 n) → [넣기] · Esc(걸린 칸은 빼고 넣음). 있는 칸만 덮어쓰고 걸린 칸도 없으면 곧바로 넣음. 어느 쪽이든 한 걸음(되돌리기로 취소), 새 줄이 생긴 붙여넣기는 자동 저장 기록 한 장.
* 넣기 ▸ 표 붙여넣기 창(지금의 붙여넣기)은 **모든 종류**로: 사건 · 시대 · 인물 · 기관 · 문화 · 왕조 · 시대 구분 · 트랙 · 분류 · 민족 · 지위 · 가문. 같은 읽기(`HT.makerKit.analyzePaste`를 넓힘).

### 5-3. 채우기
* 칸 여러 개를 고르고 값을 친 뒤 **Ctrl+Enter** = 고른 칸 모두에.
* 한 열에서 칸 범위를 고르고 **Ctrl+D** = 맨 위 칸 값으로 아래를 채움(엑셀과 같음). 줄 · 항목을 골랐을 때의 Ctrl+D는 복제.

### 5-4. 하위 표 (지도자 · 내각 · 연호 · 도읍 · 시기 · 지위 줄)
* 표 탭에서 시대 한 줄을 고르면 아래에 그 시대의 줄 표(탭: 지도자 · 내각 · 연호 · 도읍 · 시기 · 지위 — 있는 칸만). 높이 조절 · 접기.
* 열: 지도자 — 이름 · 시작 · 끝 · 대수 · 묘호 · 시호 · 가문 · 지위 · 미정 · 메모(지금 폼의 지도자 줄 칸 그대로), 나머지도 폼의 줄 칸 그대로.
* 고치기 · 붙여넣기 · 채우기 · 정렬 규칙은 5-1~5-3과 같음 — 왕 서른 명을 엑셀에서 한 번에.
* 속성 창의 '여러 줄 한꺼번에 붙여넣기'(글 줄)는 그대로 둠.

### 5-5. 한꺼번에 고치기
* 두 개 이상 고르면(연표 Ctrl+누르기 · 구조 · 표 줄) 속성 창이 **'n개 고름'**:
  * 같이 가진 칸: 트랙 · 종류(시대) · 분류(사건) · 중요도 · 민족 · 색 · 실재성 · 확실성 — 값이 같으면 그 값, 다르면 '여러 값'. 바꾸면 해당하는 항목 모두에(그 칸이 없는 항목은 건너뜀, 건너뛴 수 알림).
  * **연도 밀기**: ±N년(또는 월 · 일) — 시작 · 끝과 안의 줄(지도자 · 내각 · 연호 · 도읍 · 시기 · 지위 · 소속 기간 · 이설)을 함께.
  * [복제] [지우기] [내 DLC로 복사](불러온 팩의 것이 섞였을 때).
* 누를 때마다 한 걸음 + (항목 20개 넘으면) 자동 저장 기록 한 장.
* 잠긴 팩의 항목이 섞여 있으면 그 항목은 건너뜀(알림 — '자물쇠를 풀거나 내 DLC로 복사').

## 6. 연표 위 조작

공통: **고른 항목만** 손잡이가 생깁니다(한 번 눌러 고르면). 화면을 끌어 옮기는 것과 섞이지 않게. 잠긴 팩의 항목은 끌 수 없음. 끄는 동안 그 항목만 반투명한 그림자로 움직이고 날짜 풍선이 따라다니며, **나머지 연표는 가만히**(놓을 때 한 번 다시 배치 — 움직임 원칙 '움직이는 동안 고요'). Esc = 취소. 놓으면 한 걸음.

* **붙는 단위**: 보이는 폭이 2년 이상이면 해, 2개월~2년이면 달, 그보다 좁으면 날(지금의 새 항목 시작 규칙 `presetAt`과 같은 경계). 끄는 동안 **Shift**를 누르면 한 단계 가늘게(해 → 달 → 날).
* **띠 끝 끌기**(시대 · 기관 · 문화 · 왕조 · 시대 구분 · 대범위 · 인물 활동): 고른 띠의 왼끝 · 오른끝에 손잡이(마우스를 대면 ↔). 끝이 시작보다 앞으로 가지 않음. 날짜 글(월 · 일)은 붙는 단위로 다시 적음, '미정' 끝은 끌면 정해진 값이 됨(알림).
* **사건 점 끌기**: 고른 사건의 점을 좌우로 — 기간 사건이면 길이는 그대로 함께.
* **띠 통째로 옮기기**: 고른 띠의 몸통을 **Alt+끌기**, 또는 **Alt+←/→**(한 단위) · **Alt+Shift+←/→**(열 단위). 안의 줄(지도자 · 내각 · 연호 · 도읍 · 시기 · 지위 · 소속 기간 · 이설)도 함께 밀림. 그냥 ←/→는 지금처럼 화면 옮기기.
* **칸 경계 끌기**: 고른 시대 안에서 이어진 두 칸(앞 칸의 끝 = 뒤 칸의 시작)의 경계 — 지도자 · 내각 · 연호 · 도읍 줄. 두 값이 함께 움직이고 앞뒤 칸을 넘지 못함.
* **새로 만들기**: 트랙의 **빈 곳**을 **Ctrl+끌기** = 그 기간의 새 시대(그 트랙) → 속성 창 이름 칸. 빈 곳을 **Ctrl+누르기** = 그 날짜의 새 사건. (그냥 끌기는 지금처럼 화면 옮기기 · **항목**을 Ctrl+누르기는 여러 개 고르기.)
* **여러 개 함께 옮기기**: Ctrl+누르기로 여러 개 고른 뒤 그중 하나를 Alt+끌기 또는 Alt+←/→ — 모두 같은 만큼(5-5의 연도 밀기와 같은 계산).
* 덮어쓰기(자물쇠 푼 팩의 항목)도 같은 규칙 — 결과는 패치.

## 7. 찾기 · 점검

### 7-1. 명령 찾기 (Ctrl+K · /)
* 가운데 위에 뜨는 찾기 칸. 결과를 묶음으로: **명령**(메뉴의 모든 명령 + 단축키) · **내 항목** · **불러온 팩 항목**(흐리게) · **바탕 자료** · **문서**. 연도 · 날짜 · 간지를 치면 맨 위에 '그 해로 가기'(지금 검색과 같은 읽기).
* ↑↓로 고르고 Enter: 명령은 실행, 항목은 고름 + 연표에서 보기 + 속성 창. 결과는 한 묶음에 8개까지('더 보기').
* 독의 검색 칸을 대신합니다.

### 7-2. 찾아 바꾸기 (Ctrl+H)
* 아래 창의 한 탭: 찾을 글 · 바꿀 글 · 찾을 칸(이름 · 제목 / 설명 / 메모 / 문서 / 출처 / 칸 이름(지도자 · 연호 …) / 모두) · 대소문자 가림 · 낱말 단위 · (고급) 정규식.
* 대상은 **내 DLC만**. 결과: 항목 · 칸 · 앞뒤 글(찾은 곳 강조) — 누르면 그 항목으로. [바꾸기](하나) · [모두 바꾸기](한 걸음 + 자동 저장 기록 한 장).
* **'이름으로 가리키는 곳도 함께 바꾸기'**(기본 켬): 바꾼 것이 다른 항목이 이름으로 가리키는 이름(정권 이름 → 소속 · 승계 · 대범위 구성 · 상징적 본국 · 인물의 섬긴 나라 · 조약 당사국, 민족 · 가문 · 지위 · 시대 구분 이름 …)이면 그 참조도 같이 — 결과 줄에 '참조 n곳도'.

### 7-3. 문제 창 (아래 창 [문제])
* 지금의 검사 창을 아래 창으로. 작업본이 바뀔 때마다 새로(지금 검사와 같은 계산 — `HT.normalizePack` + 대범위 검사). 오류 · 경고 · 알림을 묶음으로, 누르면 그 항목으로(지금의 `gotoIssue`).
* 상태 줄의 '검사 오류 n · 경고 n'을 누르면 열림. 오류가 새로 생기면 상태 줄 숫자만 바뀜(창이 저절로 열리지는 않음).

### 7-4. 빈 칸 점검 (아래 창 [빈 칸])
* 오류가 아니라 **할 일 목록**: 설명 없음 · 문서 없음 · 출처 없는 사건 · 지도자 없는 나라 · 연대 미정(시작 · 끝) · 색이 자동인 시대 · 트랙 순서 없음. 묶음마다 개수, 묶음을 켜고 끔(기억), 줄을 누르면 그 항목으로.
* 내 DLC만.

### 8-2. 되돌리기의 짜임
* 작업본을 바꾸는 길은 모두 `maker.js`의 `commit()`을 지남(지금도 그러함 — 저장 · 지우기 · 되돌리기 · 문서 · 바탕 자료 · 붙여넣기 · DLC 정보). `commit(이름)`이 **바꾸기 전 작업본의 글(JSON 글)**을 기록에 넣음. 바탕 자료 타자처럼 잇따르는 고침(`commitSoon`)은 한 번 몰아 저장할 때 한 걸음.
* 되돌리기 = 기록의 글로 작업본을 바꾸고 `D.save` → `ctx.refresh()` → `ctx.syncEditor()`.
* 한 작업이 여러 번 commit하면(붙여넣기 · 한꺼번에 고치기) `history.group(이름, fn)`으로 묶어 한 걸음.

### 8-3. 끌기 걸이
* `timeline.js`는 고른 항목(옵션 `editable(item)`이 참인 것)에만 손잡이 요소를 그리고, 포인터를 붙잡아 그림자 · 풍선만 움직입니다. 놓으면 `onEditDrag({ uid, part: 'start'|'end'|'move'|'seam', seam, t0, t1, alt })`, Ctrl+끌기는 `onCreateDrag({ track, t0, t1 })`. 날짜 계산 · 붙는 단위 · 저장은 `maker-drag.js`(순수 계산은 `HT.snapTime` · `HT.draft.shiftItem`).
* 연표(index.html)는 `editable`을 주지 않으므로 손잡이가 없음.

## 9. 검사

### 9-1. dev-smoke (노드 — 새 절)
* **팩 파일**: 견본 14개 + 기본팩을 `.htpack`으로 쓰고 읽으면 `HT.packToJSON`이 한 글자도 다르지 않음(표지 포함 · 없는 것 모두) · deflate/store 둘 다 · 우리가 쓴 zip을 노드 `zlib.inflateRawSync`로 풀어 같은지 · 윈도우 '압축 폴더'로 만든 zip(고정 견본 파일)을 읽음 · 깨진 파일(CRC 틀림 · 잘림 · 암호)은 알림으로 거절 · 64MB/32MB 한도.
* **새 칸**: 분류 · 태그 · 요약 · 볼거리 · 표지 · 관계 · 판 기록의 읽기 · 검사 · 쓰기 왕복, `requires`는 그대로, 새 칸을 쓴 파일만 형식 2 · 새 칸을 쓰지 않은 파일은 한 글자도 다르지 않음(옛 견본 해시 그대로).
* **불러오는 차례**: needs · after 정렬 · 고리 무시 · 기본팩 먼저.
* **편집 계산**: 복제(새 id · 이름 · 문서) · 붙여넣기 묶음(id 겹침 · 정의 따라옴) · 연도 밀기(안의 줄 · 날짜 글 · 미정) · 한꺼번에 고치기(칸이 없는 항목 건너뜀) · 찾기 · 바꾸기(+참조) · 판 기록 요약 · `HT.snapTime`.
* **되돌리기**: 무작위 작업 N개 → 모두 되돌리면 처음 작업본과 글자까지 같음 · 다시 하기로 끝과 같음.
* **표 붙여넣기 읽기**: 모든 종류의 머리글 별칭 · 걸린 칸 표시.
* **파일 짜임**: 새 파일이 메이커에만(연표는 packfile만) · 읽는 차례 · sw.js · build-web.
* 고치기 전 코드로 돌리면 걸리는지(지금까지처럼) 확인.

### 9-2. 브라우저 (내 미리보기 서버 — launch.json `maker-pro` 8775를 작업 트리로)
* 단계마다 실제 화면을 찍어 목업과 견줌. 창이 숨으면 그리기가 멈추는 함정은 `requestAnimationFrame` 대체 하네스로(메모 참고).
* 되돌리기 · 표 · 끌기는 실제 마우스(computer 도구)로 — 합성 포인터는 `setPointerCapture`에서 막힘.
* 콘솔 오류 0 · 연표(index.html)는 설치 · DLC 관리 말고 바뀐 것 없음.

### 9-3. 안드로이드 (1단계 끝에)
* `npm run android:build` → 에뮬레이터: 파일 앱에서 `.htpack` 누르기 → 설치 · 표지 카드 · 자세히 · 켜고 끄기. `.json`도 그대로.
