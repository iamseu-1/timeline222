# 목업 판 — 쓰는 법

자바스크립트 목업을 Flutter 앱 안에서 Dart로 그려 고르기 판을 만든다. 글자는 앱의 글자 그리기 그대로(켜면 앱의 ClearType) — 목업의 글자가 곧 앱의 글자.
설계: `docs/설계-한벌-체제-목업판-ClearType.md` 3-1절.

## 1. 자리

| 무엇 | 자리 |
| --- | --- |
| 틀 | `prototype/app/lib/mock/` — `kit.dart`(부품) · `svg_lite.dart`(그리기) · `js.dart`(JS 셈) · `scene.dart`(장면) · `render.dart`(기준 방향 · 고리) · `themes/`(판 공통) · `boards.dart`(판 목록 · 자를 자리) |
| 검사 | `prototype/app/test/mock/` — `board_test`(판 찍기) · `tree_dump_test`(나무 덤프) · `parity_test`(크롬 기준 대조) · `goldens/`(기준 그림) |
| 원본 사본 | `prototype/app/test/mock/source/` — 옮긴 자바스크립트 목업 그대로(바이트 같음 · 지문 `mock-sha.txt` · `.gitattributes`로 줄 끝 고정). 고치지 않음 |
| 도구 | `prototype/scripts/` — `mock-board.mjs`(판 묶기) · `mock-tree.mjs`(나무 대조) · `mock-build-board.mjs`(크롬 판 다시 짓기) · `mock-golden.mjs`(크롬 기준 뽑기) · `mock-oracle.mjs`(정답지) |
| 결과 | `prototype/results/mock/board/<판>/`(판) · `results/mock/source/`(다시 지은 크롬 판) · `results/mock/tree/`(덤프) — git 밖 |

## 2. 새 판

1. 갈래 = `BaseTheme`(또는 판 공통 — 예: `S4Theme`)을 잇는 클래스. 고리(`frame` · `object` · `lanes` · `link` · `extra` …)를 덮어쓴다. 토큰 · 치수는 바꿀 열쇠만 `tokOverride` · `mOverride`로.
2. `boards.dart` — 판 목록 `'<판>': [갈래, …]` · 2배로 볼 자리 `boardCrops['<판>']`.
3. `test/mock/board_test.dart`의 `heads` — 판 이름 · 한 줄 설명.
4. 지킬 것: 갈래 객체에 그리기 상태를 남기지 않음(같은 갈래로 여러 번 그림) · 맵 글자는 `<String, dynamic>{}` · 원본을 옮긴 파일은 머리말에 원본 파일 이름과 SHA-256 앞 12자.
5. `svg_lite`가 모르는 요소 · 속성 · 색 · 글꼴은 실패한다(말없이 빼먹지 않게). 새 장치는 그리게 만든 뒤 허락 목록에 더한다.
6. 원본 대조에 넣기(자바스크립트 원본을 옮긴 판): 원본 파일을 `test/mock/source`에 바이트 그대로(지문은 `mock-sha.txt` · Dart 머리말) · `tree_dump_test.dart`의 갈래 목록(지금 `boards['s4']`)에 그 판 · 크롬 기준이 필요하면 `parity_test.dart`의 `ids`(7절).

## 3. 찍기 · 묶기

```
# app 폴더(한글 경로를 피한 연결 폴더 — 예: %USERPROFILE%/AppData/Local/Temp/ht-onebeol/app)에서
D:/flutter-sdk/flutter/bin/flutter test --no-pub test/mock/board_test.dart --dart-define=BOARD=s4 --dart-define=CLEARTYPE=on
# 저장소 뿌리에서
node prototype/scripts/mock-board.mjs prototype/results/mock/board/s4
```

* 나오는 것: `full/<id>.png`(1920×1080 1배) · `parts/<id>.png`(부품 판 1800×300) · `crop/<id>-<n>.png`(1배) · `crop/<id>-<n>-2배.png`(최근접 확대) · `board.json` → `s4.html`(고르기 판) · `fonts/`.
* 판: 카드(코드 · 이름 · 추천 · 지은이 · 착상 · 장단점 · 1배 그림 · 부품 판 · 그 아래 2배 조각) · 그림을 누르면 1배(아래에 부품 판 · 조각) · ← → · Esc · 주소 `#v-<id>`. 꼴은 자바스크립트 판과 같은 CSS · 부품 판도 같은 자리.
* 판 폴더째 옮겨도 열림(그림 · 글꼴이 상대 경로).
* `CLEARTYPE=on` — Windows · 자료 처리부 DLL(`prototype/engine/target/release/archive_engine.dll`)이 있어야 함. 없으면 실패. 빼면 회색 글자.
* ClearType이어도 회색인 글줄: 프리텐다드가 아닌 글꼴 · 글꼴에 없는 글자(▸ · 한자)가 든 글줄 · 옅은 글자 · 반투명 층 안(앱과 같음).
* 시간: s4 열넷 3초쯤(켬 · 끔 비슷). 30초를 넘으면 실패. 기본 자리 `results/mock/board` · `OUT`으로 바꿈(`--dart-define=OUT=../results/mock/gray`).
* `BOARD`가 없으면 건너뜀 — 보통의 검사 돌림에서 판을 찍지 않음.

## 4. HTML 스케치 · Dart 판

* 처음 방향 잡기: 크롬 HTML 스케치(빠른 낙서)도 됨.
* 마지막 후보: 반드시 Dart 판. 앱 글자 · 앱 셈 그대로라 고른 뒤 다시 번역하지 않음.

## 5. 고른 뒤

* 자유 장면 판: 고른 갈래의 고리를 제품 그림판으로 베껴 잇기(같은 언어 · 같은 `kit.dart` 함수) → 이은 뒤 실제 장면으로 한 번 찍어 기준 그림과 대조.
* 실제 장면 판(실제 장면 스위치가 생긴 뒤): 다른 갈래의 스위치만 걷기 — 고른 갈래는 이미 제품 코드.

## 6. 갈래를 고친 뒤 — 원본과 같음 확인

1. `flutter test --no-pub test/mock/tree_dump_test.dart` 통과(덤프를 새로 뜸 · 지난 덤프는 지움).
2. `node prototype/scripts/mock-tree.mjs` → `diffs 0` · 종료 0(기본: 원본 사본 `test/mock/source` · 덤프 `results/mock/tree`).

* 이 관문은 flutter test 밖(노드). 둘째를 빼먹으면 원본과 갈려도 모름.
* 빠진 글 폭(`missing`)이 나오면 `--rerun "<1의 명령>"`을 붙임 — 물음을 `queries.json`에 모아 덤프를 다시 떠 다섯 번까지 다시 견줌.
* 원본 사본과 Dart 머리말의 지문이 다르면 견주지 않고 실패.
* 원본에 없는 연습 갈래 둘은 `tree_dump_test.dart` · `mock-tree.mjs` 두 쪽을 함께 고침.

원본(연구 폴더)이 바뀐 판을 옮길 때 — 다섯을 함께 갱신: 원본 사본 · `mock-sha.txt` · Dart 머리말의 지문 · 정답지 둘(`fixtures/kit.json` · `layout.json`) · 크롬 기준 넷(`goldens/`). 하나라도 옛것이면 아래 검사가 지문으로 실패.

```
# 1. 사본 바꿈(바이트 그대로) → mock-sha.txt를 새 지문으로 → Dart 옮김 · 머리말의 지문
# 2. 정답지 다시 뽑기 (저장소 뿌리에서)
node prototype/scripts/mock-oracle.mjs prototype/app/test/mock/source prototype/app/test/mock/fixtures/kit.json prototype/app/test/mock/fixtures/layout.json
# 3. 나무 대조 — 이 절 위의 1(tree_dump_test) → 2(mock-tree)
# 4. 판 다시 짓기 → 기준 다시 뽑기 → parity_test
node prototype/scripts/mock-build-board.mjs
node prototype/scripts/mock-golden.mjs s4-2-ga,s4-2-na,s4-5-a,s4-6-flag-open
```

* 정답지의 `source` 지문은 `kit_test` · `layout_test`가 `mock-sha.txt`와 견줌. 기준 넷은 `parity_test`의 `ids`.

## 7. 크롬 기준 그림 늘리기

```
node prototype/scripts/mock-build-board.mjs
node prototype/scripts/mock-golden.mjs <갈래 id,…>
```

* 첫째: 원본 사본의 판 틀에 앱 `assets/fonts`의 Pretendard · 스크립트를 품어 `results/mock/source/board-s4.html`(4MB · git 밖) + 옆에 `mock-sha.txt`. 사본의 `build.mjs`와 같은 짜임.
* 둘째: 그 판에서 `app/test/mock/goldens`에 `<id>.png`(크롬 1배) · `<id>.text.json`(글줄 자리). `parity_test.dart`의 `ids`에 더함. 다른 판은 `<판 html> <갈래 id,…> <출력 폴더>`.
* 판의 지문(판 옆 `mock-sha.txt`)이 옮긴 판과 같아야 함.
* 판이 품은 글꼴 = Pretendard 400 · 700뿐. 600 · 명조 · 굵은 명조 글줄이 든 갈래는 기준으로 못 씀.
* 대체 글꼴 허락 = `mock-golden.mjs`의 `ALLOW`(지금 ▸ → Cambria Math)뿐. ▾가 든 `-open` 갈래를 넣으려면 그 글자도 Dart 대체 줄(`svg_lite.dart` `mockFallback`)이 같은 글꼴로 그리는지 확인한 뒤 `ALLOW`에 더함.
* 지금 기준은 msedge 155로 찍힘(크로미움 없음). 브라우저가 바뀌면 다시 뽑아 견줌.
* 기준을 고쳐 맞추지 않음 — 다르면 옮긴 쪽을 고침.

## 8. 옮기는 규칙

| 자바스크립트 | Dart | 함정 |
| --- | --- | --- |
| 객체 `o.n` · `{...a, k: v}` · `Object.assign({}, a, b)` | `Map<String, dynamic>` — `o['n']` · `{...a, 'k': v}` · `{...a, ...b}` | 열쇠 이름은 그대로 |
| 배열 `a.map(f)` · `a.filter(f)` · `a.find(f)` | `a.map(f).toList()` · `a.where(f).toList()` · `a.firstWhereOrNull(f)`(`package:collection`) | `map`은 늘 `toList()` |
| `Math.round(v)` | `jsRound(v)` = `(v + .5).floorToDouble()` | Dart `round()`는 −2.5 → −3, JS는 −2 |
| `String(n)` · 경로 글의 수 | `jsNum(n)` | Dart `10.0.toString()`은 `'10.0'` |
| `a ?? b` · `a \|\| b`(수 · 글) | `a ?? b` · `jsOr(a, b)`(0 · 빈 글 · null · false면 b) | JS `\|\|`는 0도 거짓 |
| `x / y`(늘 실수) | `x / y` | 정수 나눗셈 `~/`을 쓰지 않는다 |
| 방향 객체 · `this.k(a)` · 고리 덮어쓰기 | 클래스 상속 — `class TE extends TC`, 고리는 메서드, `this.`은 생략 | `Object.assign({}, TC, {...})` = `extends TC` |
| `E('path', {d, fill}, p.frame)` | `E('path', {'d': d, 'fill': fill}, p.frame)` | 값이 null · false인 속성은 빠진다(`kit.js`와 같음) |
| `el.style.fontFamily = v` · `el.setAttribute(k, v)` | `el.setAttribute('font-family', v)` · 같음 | 모양 속성으로 |
| `el.innerHTML = '<path …/>'` | `setInnerSvg(el, '<path …/>')` | 아이콘 글만 |
| `window.S4.register({...})` | `S4Theme(id: …, code: …, opt: {...})`를 판 목록에 | 등록 = 목록에 더함 |

* 표의 식은 뜻 — 실제 셈은 `js.dart`(`jsRound`는 0.49999999999999994 때문에 바닥과의 차로 셈).

## 9. 원본 목업에서 본 것

* 접힌 초원의 뒤 탭(몽골 제국 · 차가타이 · 금장 칸국)이 서로 겹침 — 원본 `render.js` 121줄 언저리(`closedCulture`가 해마다 탭을 놓기만 함)의 모습 그대로. 감독 원칙(겹침 금지)과 어긋남 → 목업(원본) 쪽에서 고칠 일. Dart만 고치면 나무 대조가 갈림.
