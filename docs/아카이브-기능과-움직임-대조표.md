# 아카이브 0단계 — 기능과 움직임의 대조 기준

2026-09-20. 기준은 `master`의 `36c60b9`와 작업 시작 때 읽은 최신 인수인계다. 새 작업은 `codex/archive-prototype`에만 있다. **기존 구현 보존과 새 구현 이전 완료는 서로 다르다.** 아래의 미이전 기능은 기존 프로그램에서 계속 제공한다.

기기 표기: 기존 PC·웹은 현재 코드 기준이며, 새 Android 적용은 별도 검사 대상이다. 옛 모바일 가지를 합치지 않았다. 표의 각 세부 항목은 정식 교체 때 각각 통과해야 한다.

현재 PC에서는 시제품의 실행 결과를 별도 성능 보고서로 확인한다. 갤럭시북3와 S25의 행별 통과는 실기기 확인 전까지 비워 둔다. 휴대폰 메이커는 범위 미확정이며 이 시제품은 연표 전용이다.

## 움직임 기준

| 번호 | 현재 기준·근거 | 시제품 상태 | 정식 통과 증거 |
|---|---|---|---|
| 01 | micro 120 / out 160 / in 200 / move 360, `css/common.css`·`HT.motion` | Dart 공통 값 보존 | 각 효과의 실제 지속 시간 |
| 02 | 되튐 0·도중 목표 변경은 현재 값에서 | 확대의 지수 추적·관성 일부 | 끊기·반복·역방향 녹화 |
| 03 | 누른 줄 고정·다른 트랙 출렁임 0 | 접기·펼치기 미이전 | 줄별 위치·높이 표본 |
| 04 | 휠 기준점·터치 기준점 고정 | 휠·터치 계산 구현 | 포인터 위치 오차·S25 실측 |
| 05 | 관성 250ms·최소 50px/s·정지 15px/s·거리 1.5화면·80ms 표본 | 일부 구현. 기존 끝 감속과 빠른 잡기 선택 억제까지 동등하지 않음 | 놓기 속도·경계·중단 비교 |
| 06 | 손에 잡힌 동안 배치 고요, 정착 한 번 | 고정 줄, 접힘 없음 | 기존 자동 접힘 이전 후 비교 |
| 07 | 이동 중 세부 효과 120ms 투명도 | 묶음 교체에 적용 | 글자 포함 잔상·호버 대조 |
| 08 | 320~1100ms van Wijk, 가로·세로 같은 진행 | 미이전. 검색 목적지는 즉시 이동 | 현재·새 이동 녹화 |
| 09 | 항목 좌표를 따라 나타남·퇴장, 선택 번쩍임 0 | 두 묶음을 같은 연표 좌표에서 교차 표시, 복잡한 선택 미이전 | 도중 되돌림·선택 장면 |
| 10 | 밀도·조감·대범위 360ms 동시 진행 | 미이전 | 관련 줄·선 동시 도착 |
| 11 | 확대 문턱 8% 차이 | 상세 진입 110.4일·이탈 120일. 기존 전체 표현 미이전 | 문턱 왕복·깜빡임 |
| 12 | 잘 보이는 선택은 이동 0·가려지면 최소 이동 | 연표 선택 이동 0, 검색은 별도 이동 | 상세 창 개폐·가림 |
| 13 | 도착 고리600·가장자리 안내·조명·이설·움직임 줄이기 | 줄이기만 일부 대응 | 전체 효과 대조 |
| 14 | 느리게 보기·계측 | 화면·그리기·조회·입력 재생 계측 구현, 느리게 보기 미이전 | 0.25×·0.1×·실물 입력 |

문서의 오래된 본문에는 등장 220ms라는 문장이 있으나 실제 토큰은 200ms다. 시제품은 실제 토큰과 최신 계획의 200ms를 따랐다. 현재 프로그램의 시간 값·곡선·효과는 수정하지 않았다. 시제품의 빠른 결과를 기존 복잡한 띠·선·글자·움직임 전체의 성능으로 일반화하지 않는다.
