## 과제 2: 작업본은 옛 꼴 그대로 두고, 형식 4의 뜻은 줄 덧칸으로 싣기 — 열기 · 고치기 · 저장에서 잃지 않게

> 이 절은 계획의 옛 「과제 2: 작업본 = 형식 4 JSON」을 갈음합니다. 바탕은 심사 둘이 모두 고른 **설계안 을**(옛 꼴 작업본 + 줄 덧칸 + 항목 주머니)입니다. 을에서 세 가지를 바꾸었고(아래 「을에서 바꾼 셋」), 갑과 병에서 열한 가지를 옮겨 왔습니다.

### 한 줄 결론

작업본(편집 중인 자료)은 지금처럼 옛 꼴로 둡니다. 옛 꼴은 목록 여섯(periods · epochs · scopes · organs · groups · figures)입니다. 옛 꼴에 자리가 없는 형식 4의 뜻은 **이미 있는 옛 줄에 붙는 덧칸(더 붙인 열쇠)**으로 싣습니다. 열 때는 내림(`HT.F4.down`)의 몸통을 건드리지 않고, 그 결과 위에 덧칸을 붙이는 「표지 얹기」 한 단계를 더합니다. 저장할 때는 올림(`HT.F4.up`)에 새 갈래를 두어 덧칸을 그대로 옮깁니다. 이렇게 하면 엔진 거울(Rust 사본)에 예외를 두지 않고도 과제 2가 이름 대는 여섯 가지를 편집하고 저장할 수 있습니다. 「작업본 = 형식 4」로 뒤집을지는 과제 3을 시작할 때 다시 정합니다.

### 작업본의 모양

작업본은 지금과 같은 옛 꼴 JSON입니다(formatVersion 3 · 목록 여섯). 형식 4의 뜻은 아래 자리에 실립니다.

| 형식 4의 뜻 | 작업본(옛 꼴)의 자리 | 저장할 때(up) | 열 때(표지 얹기) |
| --- | --- | --- | --- |
| 나라 그릇에 기간을 두고 듦 · 여러 그릇 · 구간 정통성 · 으뜸 | `periods[].partOf[]` 줄에 **`within: true`** + `start` · `end` · `status` · `main` | `within { of, start, end, status, main }`. 관계가 있으면 `partOf { of, relation }`도 | periodOf가 앞에 놓은 within 줄에 `within: true` |
| 그릇 하나 · 기간 없음 | 지금 그대로(nest · 관계) | 지금 그대로(`folds` 5731) | 지금 그대로 |
| 시대 그릇에 든 기간 · 정통성 · 으뜸 · 옮겨 앉기 | `scopes[].members[]`의 객체 줄 `{ polity, track?, start?, end?, status?, main?, note? }`. 같은 나라가 여러 줄일 수 있음 | 구성원 객체의 `within { of: 대범위 id, … }` 여러 줄 | 구성원의 within 줄을 members 줄로 |
| 트랙 없는 시대 그릇(공통 시대)에 듦 | `epochs[].members[]`(같은 꼴 · 새 칸) | 위와 같음 | down이 버리던 것(6172-6177)을 되붙임 |
| 칸 정통성 | 칸 객체의 `status` — leaders · cabinets · `offices[].cells`. 짧은 꼴 [이름, 시작, 끝]은 객체 꼴로 | 그대로 | 그대로(down이 실어 옴) |
| 승계 방식 | `periods[].succeeds[].how`(단체는 이미 `from[].how`) | 그대로 | 그대로 |
| 기관 · 단체 그릇의 으뜸 | `organs[].host[]` · `groups[].within[]`의 `main` | `within { of, main }` | 그대로(organOf · groupOf가 실어 옴) |
| 머리 객체가 시대일 때의 제 칸 | `scopes[]` · `epochs[]`의 `offices` · `power`(label · host · default · sphere는 이미 옛 칸) | 시대 객체의 offices · power | down이 버린 offices(6160)를 되붙임 |
| 그림자가 없는 칸(모르는 칸 · 시대 객체의 partOf …) | 항목 주머니 `f4: { 열쇠: 값 }` — `draft.f4extras`를 대신함 | applyExtras로 「없는 칸만」 되돌림 | 걸음 6 |

예:

```json
{ "id": "p-pc", "name": "기간 그릇", "track": "t", "start": 10, "end": 90,
  "partOf": [{ "polity": "A", "within": true, "relation": "tributary", "start": 10, "end": 40, "status": "claim" }],
  "leaders": [{ "name": "왕", "start": 10, "end": 20, "status": "rival" }, ["왕2", 20, 30]],
  "succeeds": [{ "from": "B", "type": "direct", "how": "rename" }] }
{ "id": "era2", "name": "뒤 시대", "track": "t", "members": ["나라A", { "polity": "mv", "start": 50 }],
  "offices": [{ "name": "지도자", "cells": [["맹주", 50, 60]] }] }
```

- **그림자 있는 칸은 주머니에 넣지 않습니다.** 그림자 있는 칸은 옛 꼴에 같은 뜻의 자리가 있는 칸입니다: within · partOf · members · offices · succeeds · track. 넣으면 지금 결함(두 번 적힘)이 되풀이됩니다.
- **바뀌지 않는 것:**
  - events · cultures · dynasties · institutions · documents · 사전 목록.
  - patches는 옛 꼴 그대로입니다. `set.partOf` · `set.leaders` · `set.succeeds`도 같은 덧칸을 실을 수 있습니다.
  - 저장소 · 시점 · 되돌리기 · 클립보드 묶음의 꼴.
