# 한 벌 P4 — 원본 + 트랙별 다시 짓기(엔진 안 넣고 빼기 · 휴대폰) 구현 계획

> **에이전트 작업자에게:** 필요한 하위 방법 — `superpowers:subagent-driven-development`(권함) 또는 `superpowers:executing-plans`로 과제를 하나씩 해 나갑니다. 걸음은 체크 상자(`- [ ]`)로 표시합니다.

**목표:** DLC를 넣고 뺄 때 저장소를 통째로 다시 지어 파일을 바꿔 넣는 대신, 엔진이 **바뀐 트랙만 한 번의 SQLite 거래로 고쳐 쓰고** 앱은 그 트랙만 흐르게 한다 — P3 뒤에는 Node 없이, 휴대폰에서도.

**짜임:** 세 걸음.
* **A(지금 · 엔진만)** — 줄의 '열쇠'(항목 표가 가리키는 `rows.id`)와 '자리'(밖으로 보이는 0부터 빈틈없는 전체 줄 번호)를 나눠, 트랙을 고쳐 써도 다른 트랙의 행은 손대지 않게 한다. 들어온 배치(지금은 Node가 낸 배치 JSON)를 **트랙 지문**으로 견주어 바뀐 트랙(+ 가리키던 uid가 생기거나 사라진 트랙)만 한 거래로 지우고 다시 넣는 `apply`. 처음 지은 저장소는 열쇠 = 자리라 답 · 타일이 지금과 같다.
* **B(A 뒤 · 앱)** — 앱이 파일 바꿔 넣기 · 닫고 다시 열기 대신 `apply`를 따로 된 일꾼에서 부르고, 바뀐 자리부터만 타일을 버린다.
* **C(P3 뒤)** — 엔진이 DLC를 직접 읽어 닿는 트랙만 Rust로 배치해 `apply`(`add_pack` · `remove_pack`). Node가 빠지고 휴대폰에서도 넣고 뺀다.

**쓰는 것:** Rust 2021 · rusqlite 0.37(bundled) · serde_json · sha2 · flate2 — **새 크레이트 없음**(계약 0절) · Flutter 3.47.7(`D:/flutter-sdk/flutter`) · Kotlin(안드로이드 고르기 창 — C).

**설계:** `docs/설계-한벌-체제-목업판-ClearType.md` 3-4절(이 계획이 그 절을 구현합니다) · 4 · 5 · 6 · 7 · 9절. P3 계획 `docs/계획-한벌-P3-Rust배치.md`(C 걸음이 그 인터페이스를 씀). 독립 점검 `Fable`(2026-10-15 — 반영함).

## 전체 제약

* 답 · 주석 · 문서 · UI는 한국어. UI 글은 명사만 · 아이콘은 흑백 선.
* **밖으로 보이는 줄 번호는 지금 그대로** — `{"op":"layout"}` 답 · 타일 · 조회의 줄은 '0부터 빈틈없는 자리', 트랙은 이어진 덩이(앱 `layout.dart`는 줄 id가 0부터 차례대로가 아니면 받지 않음). 새로 지은 저장소는 이 계획 전과 **같은 답**(열쇠 = 자리일 때는 지름길로 타일 바이트도 같음).
* 저장소 판: 새로 지은 것은 `'3'` 그대로. `apply`가 열쇠 ≠ 자리를 만들면 `meta.schema = '3.1'`(이 계획 전의 엔진은 '3'만 받아 "다시 만들어야 합니다"로 거절 — 잘못 읽지 않게). 새 엔진은 `'3'` · `'3.1'`을 받는다. 열 · 표를 더할 때는 `pragma_table_info` · `sqlite_master`로 가린다(계약 1절 규칙).
* **실패하면 저장소는 그대로** — 거래를 되돌리고, 파일 SHA-256이 넣기 전과 같아야 한다. COMMIT 전에 표본 타일 대조(`verify_store` 120)가 누락 · 중복 0이어야 한다(지금 `import_with`와 같은 문턱). 표본을 뜰 곳(판정 R29 · 과제 7c 고침): (가) 넣거나 빼는 트랙 · 트랙 차례 바뀜 · 온 판 바뀜이 있으면 저장소 전체 (나) 다시 쓰기만이면 다시 쓴 덩이와 그 덩이에 걸친 앞뒤 끝 묶음(쓰기 시간이 저장소 크기와 무관하게) (다) 기본 보기만(변형 · 이름 표는 같음 검사의 몫).

//! 줄의 열쇠(rows.id — 띠 · 사건 · 항목 · 줄 이름 · 묶음 · 변형 · 요약 · 이름 표 · R-tree가 가리키는 번호)와
//! 자리(밖으로 보이는 '전체 줄 번호' — 0부터 빈틈없이, 트랙 차례대로)를 잇는다(계획 P4 · 설계 3-4).
//! 새로 지은 저장소는 둘이 같다(열쇠 = 자리). 트랙을 고쳐 쓰면(patch) 그 트랙의 줄은 끝 번호 뒤에 새 덩이로 들어가
//! 다른 트랙의 행은 그대로이고, 열쇠와 자리가 갈린다. 약속: 트랙 하나의 줄 열쇠는 늘 이어진 덩이이고 덩이 안의 차례가 자리 차례다.
use crate::Result;
use rusqlite::Connection;

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub struct Block { pub track: i64, pub key0: i64, pub pos0: i64, pub n: i64 }

#[derive(Clone, Debug, Default)]
pub struct RowMap { blocks: Vec<Block>, by_key: Vec<usize>, total: i64, identity: bool }

impl RowMap {
    pub fn load(db: &Connection) -> Result<Self> {
        let sql = "SELECT t.id,MIN(r.id),MAX(r.id),COUNT(r.id) FROM tracks t JOIN rows r ON r.track=t.id GROUP BY t.id ORDER BY t.ord,t.id";
        let (mut blocks, mut pos) = (Vec::new(), 0);
        let mut stmt = db.prepare(sql)?;
        let mut rows = stmt.query([])?;
        while let Some(r) = rows.next()? {
            let (track, k0, k1, n): (i64, i64, i64, i64) = (r.get(0)?, r.get(1)?, r.get(2)?, r.get(3)?);
            if k1 - k0 + 1 != n {
                return Err(format!("트랙 {track}의 줄 열쇠가 이어지지 않습니다({k0}~{k1} · {n}줄)").into());
            }
            blocks.push(Block { track, key0: k0, pos0: pos, n });
            pos += n;
        }
        let identity = blocks.iter().all(|b| b.key0 == b.pos0);
        let mut by_key: Vec<usize> = (0..blocks.len()).collect();
        by_key.sort_by_key(|&i| blocks[i].key0);
        Ok(Self { blocks, by_key, total: pos, identity })
    }
    pub fn is_identity(&self) -> bool { self.identity }
    pub fn total(&self) -> i64 { self.total }
    pub fn blocks(&self) -> &[Block] { &self.blocks }
    pub fn pos(&self, key: i64) -> i64 {
        if self.identity { return if (0..self.total).contains(&key) { key } else { -1 }; }
        let i = self.by_key.partition_point(|&i| self.blocks[i].key0 <= key);
        match i.checked_sub(1).map(|j| self.blocks[self.by_key[j]]) {
            Some(b) if key < b.key0 + b.n => b.pos0 + (key - b.key0),
            _ => -1,
        }
    }
    pub fn key(&self, pos: i64) -> i64 {
        if self.identity { return if (0..self.total).contains(&pos) { pos } else { -1 }; }
        let i = self.blocks.partition_point(|b| b.pos0 <= pos);
        match i.checked_sub(1).map(|j| self.blocks[j]) {
            Some(b) if pos < b.pos0 + b.n => b.key0 + (pos - b.pos0),
            _ => -1,
        }
    }
    pub fn key_ranges(&self, pos0: i64, pos1: i64) -> Vec<(i64, i64)> {
        self.blocks.iter().filter(|b| b.pos0 <= pos1 && b.pos0 + b.n - 1 >= pos0)
            .map(|b| (b.key0 + pos0.max(b.pos0) - b.pos0, b.key0 + pos1.min(b.pos0 + b.n - 1) - b.pos0)).collect()
    }
}
