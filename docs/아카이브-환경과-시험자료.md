생성 규칙은 `archive-tool generate`에 고정했다. seed 20260920, 32줄, 1개 자료집, 1개 가상 출처다. 사건은 한꺼번에 메모리에 만들지 않고 순서대로 기록한다. 생성 단계의 요약 계산은 별도 메모리를 사용하며 열람 메모리와 구분한다. **관계 밀도·다수 자료집 조합·여러 필터·실제 원문 수만 권은 이 시험에 포함하지 않는다.** 1,000만 사건은 2단계로 남긴다.

- 시간 저장: 1970-01-01 UTC부터의 부호 있는 정수 분, 범위 양 끝 포함. R-tree에는 정밀도를 보존한 정수 날짜의 거친 일 단위 경계를 넣고 실제 분으로 다시 거른다. 긴 기간·이설 외곽을 포함한다. 새 달력 체계 전체의 호환은 아직 아니다.
- 요약: 30·365·3,650·36,500·365,000일의 칸에 **그 칸과 겹치는 사건 수**를 저장한다. 긴 기간은 여러 칸에 포함되므로 칸의 수를 더해 전체 사건 수라고 하지 않는다. 목록은 정밀 범위를 다시 조회하며 50개씩 다음 묶음을 받는다.
- 검색: SQLite FTS5에 한 글자·두 글자 조각을 저장하고 원문 부분 문자열로 최종 검증한다. 해솔·星河·여울·은빛 나루·고유 숫자 등 고정 검색어로 재현한다. 분해 한글·옛 표기·복잡한 순위 품질은 후속 과제다.
