### 낱말 풀이

| 낱말 | 뜻 |
| --- | --- |
| 띠 | 연표에 그려지는 정권 한 줄. 지금 기본팩 `periods`의 한 줄 |
| 객체 | 형식 4의 기본 단위. 종류(`type`) 열아홉 가운데 하나를 가짐 |
| 그릇 (`within`) | 구성원 띠를 제 안에 모아 그리는 시대 · 나라 객체. 구성원 쪽이 `within`으로 그릇을 가리킴 |
| 이름표 시대 | 가리키는 구성원이 없는 시대. 그릇 밖에 있으면 날짜 칸의 이름표가 되고, 그릇 안에 있으면 그릇 윗변의 둘째 탭이 됨 |
| 포갠 그릇 | 다른 그릇 안에 든 그릇 |
| 옮겨 앉기 | 기간 중에 그릇이 바뀌면 띠가 그해에 끊기고 새 그릇에서 다시 시작함. 두 토막은 이어짐 표시로 이음 |
| 섬김 (`partOf`) | 다른 객체에 매인 관계. 관계 값(봉국 · 명목상 · 식민 · 점령 · 괴뢰 · 직할 · 보호 …)과 기간을 함께 적음 |
| 실권 (`power` · `over`) | 실제 권력을 쥔 쪽. `over`가 있으면 남의 실권을 쥔 것이고, 없으면 제 안의 실권자 |
| 직위 줄 (`offices`) | 지도자 · 내각 같은 자리의 줄. 첫 줄이 지금의 지도자 줄 |
| 승계 (`succeeds`) · 방식 (`how`) | 앞 정권과의 이음과 그 방식. 이음은 직접 · 간접 · 부흥 · 부분, 방식은 개명 · 정복 · 갈라짐 · 합쳐짐 · 주장 … |
| id | 띠마다 붙는 고유 이름표. 남의 DLC 패치 · 정답지 · 검사가 이것으로 띠를 가리킴 |
| 덧칸 | 띠 배열의 다섯째 칸(옵션 묶음) |
| 시기 구분 (`phases`) | 한 띠 안을 시기로 나눠 표시하는 칸 |
| 시작 폭 · 끝 폭 (`startRange` · `endRange`) | 연대가 흐릴 때 적는 '이르면 ~ 늦으면' |
| 손질 표 | `packs/`를 고치지 않고 읽을 때만 바꾸는 이음 층의 표(설계 6절) |
