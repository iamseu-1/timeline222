# 아카이브 3단계 명세 01 — 띠의 표현 (정권 띠 · 책갈피 탭 · 띠 안의 단)

지금 연표(`js/timeline.js` · `css/common.css`)가 정권 띠와 그 안의 단을 그리는 방식을, 새 엔진(Flutter 캔버스)이 그대로 옮길 수 있을 만큼의 숫자와 식으로 적는다.
계약 `docs/계약-아카이브-3단계.md` · 설계 `docs/설계-아카이브-3단계-연표-기능-이전.md` 2절 · 4.5절과 함께 읽는다.

- 줄 번호는 `js/timeline.js`는 `T:`, `css/common.css`는 `C:`, `js/core.js`는 `K:`로 적는다(2026-09-21 `master` `bb79f5c` 기준의 작업 가지 `next-timeline`).
- **CSS는 같은 파일 안에서 v9 · v10 · v11 · 파일 끝 블록이 앞 규칙을 여러 번 덮어쓴다.** 여기 적은 값은 모두 **마지막에 이기는 값**이고, 다툼이 있었던 자리는 그 자리에 까닭(특이도 · 차례)을 적었다.
- 픽셀 값의 근거는 기준 덤프다. 기존 세 장면은 `prototype/results/dom/`, 이 명세를 위해 새로 뜬 여섯 장면은 `prototype/results/dom-r1/`에 있다(6절 실측 표).
- 밝은 화면(`prefers-color-scheme: light`) 기준. 어두운 화면에서 달라지는 토큰은 1-2절에 함께 적었다.

## 1. 띠 `.tl-band`

## 1-1. 자리와 크기 (T:6762~6800 · T:6888)

```
bandStart(p) = p.startRange ? p.startRange[0] : p.start          (T:304)
bandEnd(p)   = p.endRange   ? p.endRange[1]   : p.endY           (T:305)

x1 = X(bandStart(p));   if (p.startUnknown) x1 -= 44
x2 = X(bandEnd(p));     if (p.endUnknown)   x2 += 44

그리지 않음: x2 < -2 또는 x1 > W + 2
left  = max(x1, -1)
width = max(3, min(x2, W + 1) - left)
```

- 세로: `top: 0`, `height: max(0px, 줄 높이 - cut)` (C:618). `cut`은 계약 3절 — `(zones ? zones*14 + 3 : 0) + (hem ? 12 : 0)`.
- 테두리 `1px` · `box-sizing: border-box`이므로 **테두리는 width 안쪽**이다. 안쪽 상자 = `[left+1, left+width-1]`, 높이는 위아래 1px씩 뺀 값.
- 잘림 딱지: `clip-l`은 `x1 < -1 && !startUnknown`, `clip-r`은 `x2 > W+1 && !endUnknown` (T:6781).
- 미정 딱지: `unk-s`(startUnknown) · `unk-e`(endUnknown) (T:6783). `cut-l`은 `x1 < -1 && startUnknown` (T:6786).
- 꼬리 길이:
  ```
  fadeL = startUnknown ? max(0, 44 - max(0, -1 - x1)) : 0      (T:6787)
  fadeR = endUnknown   ? max(0, 44 - max(0, x2 - (W+1))) : 0   (T:6788)
  ```
  화면 밖으로 밀려 나간 만큼 꼬리를 줄여, 화면 가장자리에서 갑자기 끊기지 않게 한다.

## 1-3. 종류별 모양 (`kind-*`)

종류는 `p.polityKind`이고 `state`가 아니면 `kind-<id>`가 붙는다(T:6888). 종속 갈래(`HT.kindFamily(kind) === 'dependent'`)는 `fam-dep`도 함께 붙는다(T:6887 · K:296). 종류 표는 K:265~290.

| 종류 | 바탕 | 테두리 | 모서리 | 그 밖 |
| --- | --- | --- | --- | --- |
| `state`(기본) | `c 24% + paper` | `1 solid edge` | 10 | — |
| `vassal` | `c 9% + paper` (C:680) | 보통과 같음 | 10 | 종속 갈래는 딱지 없음 |
| `fam-dep` (종속 갈래 전부) | `c 9% + paper` (C:1270) | 보통과 같음(실선) | 10 | 누구를 어떻게 섬겼는지는 **상국 띠의 속국 이름표**가 말한다 |
| `federation` (연맹) | `c 6% + paper` (C:787) | `1px solid edge` + **겹줄**: `inset 0 0 0 2px var(--paper), inset 0 0 0 3px mixSrgb(edge, 투명, 55%)` | 10 | v4의 `3px double`(C:446)은 v10 C:787이 이긴다. 미정 · 추정 · 전승이면 테두리 `dashed`(C:940) |
| `org` (조직체) | `c 10% + paper` (C:682) | `1px dotted edge` (C:785) | **10** (v4의 3px는 C:785가 이김) | — |
| `era` (시대 이름) | `c 10% + paper` (C:683) | `1px solid mixSrgb(edge-soft, 투명, 60%)` (C:786) | 10 | 그늘 `none` (C:448) |
| `culture` (문화) | `radial-gradient(circle at 20% 40%, mixSrgb(c,투명,22%) 0 1.5px, 투명 2px) 0 0 / 9px 9px` 위에 `mixSrgb(c, paper, 9%)` (C:548) | `1px dashed mixSrgb(edge-soft, 투명, 70%)` (C:789) | **12** | 좌우 끝이 옅어짐(아래) · 그늘 `none` |

**문화 띠의 옅어지는 두 끝** (C:549~552):
```

clip-l  → linear-gradient(to right, #000 88%, 투명)
clip-r  → linear-gradient(to right, 투명, #000 12%)
clip-l + clip-r → 가림 없음
```

## 1-4. 연대의 확실성

확실성은 `p.certainty` — `certain · accepted · estimated · legend` (K:118~121). 기본은 `accepted`.

### (가) 띠 전체의 무늬 — `cert-*`

`whole = cert !== 'accepted' && !zones.length` 일 때만 `cert-<id>`가 띠에 붙는다(T:6791, 6888).
`zones = [p.startRange, p.endRange]` 가운데 있는 것 — **연대 폭을 적었으면 띠 전체가 아니라 그 구간에만 무늬**가 간다.

| 딱지 | 모양 |
| --- | --- |
| `cert-estimated` | 테두리 `dashed` (C:291) |
| `cert-legend` | 테두리 `dashed` + 빗금 바탕 `repeating-linear-gradient(135deg, mixSrgb(c,paper,14%) 0 6px, mixSrgb(c,paper,5%) 6px 12px)` (C:292) |
| `cert-certain` | 규칙 없음 — 보통 띠와 같다 |

빗금이 붙지 **않는** 종류(바탕이 이미 옅은 것 · C:1569 · C:1579의 목록): `kind-vassal` · `fam-dep` · `kind-exile` · `kind-movement` · `kind-federation` · `kind-org` · `kind-era` · `unk-s` · `unk-e`. 이 목록은 전설 · 반전설 · 부정됨에서도 같게 쓰인다.

### (나) 연대 폭 구간 `.tl-zone` (T:6801~6809)

`p.startRange = [a, b]` · `p.endRange = [a, b]`마다 하나씩, 띠 **안쪽** 좌표로:
```
za = X(a) - ox ;  zb = X(b) - ox
건너뜀: zb < 0 || za > iw
zl = max(za, 0) ;  zw = min(zb, iw) - zl ;  zw > 0.5 일 때만 그림
at-s : zl <= 0.5     at-e : zl + zw >= iw - 0.5
z-<kind> : cert === 'accepted' ? 'estimated' : cert
```
모양(C:348~351 · C:805~810):

| 딱지 | 무늬 |
| --- | --- |
| `z-estimated` (추정 · 세로 줄) | `repeating-linear-gradient(90deg, mixSrgb(c,paper,14%) 0 2px, var(--paper) 2px 6px)` |
| `z-legend` (전승 · 빗금) | `repeating-linear-gradient(135deg, mixSrgb(c,paper,18%) 0 5px, mixSrgb(c,paper,4%) 5px 10px)` |
| 양옆 경계(`::after`) | `border-left/right: 1px dashed var(--edge-soft)` — 띠 끝에 닿은 쪽(`at-s`/`at-e`)은 그 변을 긋지 않음 |
| 모서리 | 기본 `0`. `at-s` → 왼쪽 반지름 `9px`, `at-e` → 오른쪽 `9px` (띠 안쪽 모서리 = 10 − 1) |

세로로는 `top: 0; bottom: 0` — 띠 안쪽 높이 전부.

### (다) 할거기 칠 `.tl-zone.z-hollow` (T:8251~8265 · C:1652~1653)

상징적 본국 띠에서, 대범위(할거)가 있던 구간만 띠 바탕의 가운데가 종이빛으로 빈다.
```
background: linear-gradient(to bottom,
  투명 0 2px,
  mixSrgb(paper, 투명, 92%) 7px calc(100% - 7px),
  투명 calc(100% - 2px))
::after 의 좌우 점선 색 = mixSrgb(그 대범위 색 --sc, paper-ink, 70%), 불투명도 .6
```
자리 셈은 (나)와 같다(`at-s` · `at-e`도 같음). 대범위를 꺼 두어도 보인다.

## 1-5. 미정 끝 `unk-s` · `unk-e` (C:455~459 · C:792~793 · C:1677)

```
background: mixSrgb(c, paper, 6%)        // .tl-band.unk-s(특이도 0,2,0)가 v9의 .tl-band(0,1,0)를 이김
border-style: dashed
```

## 1-6. 실재성 `hs-*` (C:1550~1591 · T:6794~6795)

`HT.historicityOf(p)` — `attested`(딱지 없음 · 클래스 없음) · `semi` · `legendary` · `disputed` · `refuted` (K:133~138).

### 전설 `hs-legendary` · 반전설 `hs-semi`

띠 자신은 **속이 빈다**(C:1555): `background: transparent; border-color: transparent; box-shadow: none`.
안개는 띠 맨 밑의 `::before`가 그린다(C:1560~1567) — 띠를 통째로 가리면 안의 칸까지 옅어지므로 바탕과 테두리만 옅어지게 한 것이다.
```
::before { inset: -1px;  border-radius: inherit;
  border: 1px solid var(--edge);  border-style: inherit;  border-bottom-width: 0;
  background: mixSrgb(c, paper, var(--fog)) }
hs-legendary  mask = linear-gradient(to bottom, #000, rgba(0,0,0,.5) 45%, 투명)
hs-semi       mask = linear-gradient(to bottom, #000 66%, 투명)
```
`--fog`(C:1555~1558):

| 조건 | `--fog` |
| --- | --- |
| 보통 | `24%` |
| `kind-vassal` · `kind-org` · `kind-era` · `fam-dep` · `kind-exile` · `kind-movement` | `10%` |
| `unk-s` · `unk-e` · `kind-federation` | `7%` |
| 올렸거나 고른 것(`is-hot` · `is-selected`) | `36%` |

안개 띠는 어떤 상태에서도 그늘이 없다(C:1559).
전승 연대(`cert-legend`)가 겹치고 위 (가)의 제외 목록에 들지 않으면, 안개의 바탕이 빗금으로 바뀐다(C:1569 — 값은 `cert-legend`와 같음).
`kind-movement`의 깃대는 안개 안쪽에 `box-shadow: inset 3px 0 0 mixSrgb(edge, 투명, 85%)`로 겹쳐 그린다(C:1572) — `::before`를 안개가 쓰기 때문.

### 부정됨 `hs-refuted` (C:1574~1579)

```
background: mixSrgb(paper-muted, paper, 9%)
border-color: mixSrgb(paper-muted, 투명, 50%)
kind-federation 이면 바탕 mixSrgb(paper-muted, paper, 5%)
cert-legend(제외 목록 밖)이면 회색 빗금:
  repeating-linear-gradient(135deg, mixSrgb(paper-muted,paper,14%) 0 6px, mixSrgb(paper-muted,paper,5%) 6px 12px)
kind-movement 의 깃대 색 = mixOklab(paper-muted, edge-to, edge-k)
```

### 실재 논쟁 `hs-disputed`

CSS 규칙이 없다 — **보통 띠와 같고 탭의 딱지(`논쟁`)만 다르다**. 덤프로도 확인(6절 A-5).

## 2. 책갈피 탭 `.tl-tab`

## 2-1. 자리 (T:6896~6918)

```
atCorner = !p.startUnknown && x1 >= 0
tabL = atCorner ? x1
                : max(p.startUnknown ? X(p.start) : x1, 0) + 6
tabR = min(p.endUnknown ? X(p.endY) : x2, W) - 6
top    = -G.tab = -11        // 줄 안 좌표 — 띠 윗변 위로 11px
height =  G.tab + G.bw = 12  // 아래 1px은 띠 밑에 끼워짐
is-stuck : x1 < -1           // 띠가 왼쪽 밖으로 나가 탭이 화면 가장자리에 붙어 따라옴
at-corner: 위 atCorner
```
- 띠가 왼쪽 밖으로 나가도 탭은 `x = 6`(줄 좌표)에서 멈춰 따라온다 — 이름 자리가 늘 같아 눈이 헤매지 않는다.
- 미정으로 시작하는 띠에서는 사라지는 꼬리가 아니라 **진짜 시작 `X(p.start)`** 에서 6px 안쪽에서 시작한다.
- `p._tabR = tabL + tp.width` — 다른 줄에서 들어오는 승계선이 이 탭을 비켜 간다. 그리지 않는 줄에서도 자리만 잡아 둔다(T:6771~6777).
- 조감(`bird`)에서는 탭이 없다 — 이름이 띠 안으로 들어간다(`.tl-bnm`).

## 2-2. 글의 폭 문턱 — `tabParts` (T:648~660)

**하나의 순수 함수가 정한다.** 화면과 그림 내보내기가 같은 답을 쓴다.

```
kind = p.polityKind || 'state'
hs   = HT.historicityOf(p)
kds  = (종속 갈래가 아니고 KIND_SHORT[kind]가 있으면) [{ t: KIND_SHORT[kind] }] : []
hsTag = hs ? HT.historicityTag(hs) : ''

baseW = textWidth(p.name, 10.5, 700) + 14
      + Σ_kds ( textWidth(k.t, 8.5, 500) + 12 )
      + ( hs ? textWidth(hsTag, 8.5, 500) + 12 : 0 )
      + ( hs === 'legendary' ? 2 : 0 )          // 이름이 기울어 조금 넓어짐
rkNeed = rk ? textWidth(rk.name, 8.5, 500) + 12 : 0
rkOn   = !!rk && room >= baseW + rkNeed
fullW  = baseW + (rkOn ? rkNeed : 0)
shortW = textWidth(p.name[0], 10.5, 700) + 14

room = tabR - tabL
mode = room >= fullW ? 'full' : room >= shortW ? 'short' : ''
width = mode === 'full' ? fullW : mode === 'short' ? shortW : 0
```
- `mode === ''`이면 탭을 그리지 않는다(왼쪽 칸에 이름이 있으므로).
- `short`는 **이름 첫 글자만 · 딱지 없이**.
- **폭은 10.5px로 재지만 글자는 10px로 그린다**(C:1515 · C:1519). 예전 10.5px 글자가 띠 윗변에 붙어 보여 글자만 줄이고 폭 계산은 그대로 두었다 — 배치가 1px도 바뀌지 않게. 옮길 때 이 어긋남을 그대로 두어야 자리가 같다.
- `KIND_SHORT` (T:563 + K의 `short`): `vassal 종속 · federation 연맹 · org 조직 · era 시대 · culture 문화 · overlay 기관` + 종류 표의 `short`(`조공 · 봉국 · 자치 · 군벌 · 보호 · 위성 · 괴뢰 · 위임 · 식민 · 점령 · 망명 · 세력`). **종속 갈래(`fam-dep`)는 딱지를 달지 않는다**(T:651) — 상국 띠의 이름표가 말하기 때문.
- 실재성 딱지 글(K:133~138): `semi 반전설 · legendary 전설 · disputed 논쟁 · refuted 부정` (`attested`는 빈 글이라 딱지 없음).
- 지위 딱지 `rk`: `tabRank(p, show, rankH)` (T:662) — **지위 단이 없는 줄(`rankH === 0`)에서 지위 구간이 하나뿐인 정권**일 때만, 그리고 이름 · 종류 · 실재성 딱지와 **함께 들어갈 때만**.

## 2-4. 모서리 밑으로 비치는 조각 `at-corner::after` (C:1529~1533)

띠의 왼쪽 위 둥근 모서리가 화면 안에 있으면 탭을 그 모서리에 맞춰 끼우고, 모서리의 둥근 틈(띠 바깥)으로만 탭의 아랫부분이 비친다 — 띠가 탭을 덮고 있다는 단서.
```
at-corner            → border-bottom-left-radius: 0
at-corner::after     left: 0;  top: calc(100% - 1px);  width/height: var(--br)
                     background: inherit (탭의 바탕 그대로)
                     mask: radial-gradient(circle at var(--br) var(--br),
                             투명 calc(var(--br) - .5px), #000 var(--br))
--br = 10px (줄 안의 띠) · kind-culture 이면 12px
```
덤프에서 이 조각은 `top: 11px`(= 탭 높이 12 − 1), `10 × 10`으로 나온다(6절 B-2).

## 2-5. 이웃 탭과 겹칠 때 · 고리와 겹칠 때

- **이웃 탭끼리는 비키지 않는다.** 탭은 늘 제 띠의 시작(또는 화면 왼쪽 6px)에 있고, 띠가 겹치지 않으면 탭도 겹치지 않는다. 띠가 좁으면 `room`이 줄어 `full → short → 없음`으로 스스로 줄어든다. **탭끼리의 밀어내기 · 비킴 규칙은 없다(확인함).**
- 띠 윗변에 걸친 '다른 견해' 고리(`.tl-palt`)가 탭 자리에 걸릴 때만 `has-pin`이 붙어 탭이 위 층으로 올라가고(`z-index: 3`), 띠 밑에 든 아래 1px을 `clip-path: inset(0 0 1px)`로 잘라 띠의 윗 테두리를 덮지 않는다(T:6917 · C:1536).
  걸림 판단: `showAlt && HT.datedAlts(p)의 어떤 해 y에 대해 X(y) > tabL - 5 && X(y) < p._tabR + 5`.

## 3-2. 칸 무리 배치 — `layoutStrip` · `joins` (T:223~260)

이어 붙는 칸(앞 칸의 끝 = 뒤 칸의 시작 · 같은 무리)은 **틈 없이 하나의 긴 둥근 칸**이 되고 안쪽은 가는 구분선만 남는다.

```
joins(cells, keyOf, a, b):
  l = 앞 칸이 있고 keyOf 같고 |b(앞) - a(이)| < 1.5
  r = 뒤 칸이 있고 keyOf 같고 |b(이) - a(뒤)| < 1.5

layoutStrip(items, keyOf, a, b, lo, hi, minW = 1):
  vis = b(it) > lo && a(it) < hi 인 것
  atL = a <= lo ;  atR = b >= hi
  l = a > lo ? a + (jn.l ? 0 : 0.5) : lo      // 잇지 않는 쪽만 0.5px 틈
  r = b < hi ? b - (jn.r ? 0 : 0.5) : hi
  drawn = (r - l) >= minW 인 칸만
  drawn 안에서 이웃한 두 칸 p, c 가 그 사이의 모든 이음이 살아 있으면(linked)
     c.jl = p.jr = true ; p.r < c.l 이면 p.r = c.l    // 건너뛴 빈틈은 앞 칸을 늘여 메움
```
**옮길 때의 뜻:** 너무 좁아 그리지 않는 칸이 사이에 있어도 무리가 끊기거나 둥근 끝이 열리지 않는다. 새 엔진에서도 "그리는 칸끼리만 잇고 빈틈은 앞 칸을 늘인다"를 그대로 해야 한다.

`lo · hi`는 단마다 다르다.

| 단 | `lo` | `hi` | `minW` | `keyOf` |
| --- | --- | --- | --- | --- |
| 지도자 · 내각 | `P = 3` | `iw - 3` | 1 | `c.dynasty || c.dynastyAuto || ''` (같은 왕조끼리만 이음) |
| 시기 | `P = 3` | `iw - 3` | 1 | `''` (늘 같음) |
| 지위 | `P = 3` | `iw - 3` | 1 | `0` (늘 같음) |
| 예속 안 칸 | `P = 3` | `iw - 3` | **2** | 속국 uid |
| 매달린 이름표 | `lo`(아래 3-9) | `hi` | **2** | 속국 uid |
| 왕조 | `layoutStrip`을 쓰지 않음 — 칸마다 따로(아래 3-3) |

## 3-3. 칸의 미정 — `unkCell` · `unkFade` (T:694~701 · T:976~981)

```
unkCell(c, prev, jl, w, tw, cutL, cutR):
  s  = !!c.startUnknown && !cutL        // 화면 밖에서 잘린 끝은 미정이 아님
  e  = !!c.endUnknown   && !cutR
  ul = jl && prev && prev.endUnknown    // 앞 칸의 끝이 미정 → 사이 구분선도 점선
  아무것도 아니면 { cls:'', css:'' }
  f = max( 3, min( 44, w * 0.4, tw != null ? (w - tw)/2 : w * 0.3 ) )
  cls = ' unk-s'? + ' unk-e'? + ' u-l'?
  css = '--fl: f px' (시작 미정) · '--fr: f px' (끝 미정)
```
`tw`는 가운데 놓인 이름표의 글자 너비 — **꼬리가 글자까지 먹어 들어가지 않게** 한다. 앞글자만 보이는 좁은 칸은 `tw = w`를 넘겨 꼬리를 아주 짧게(3px) 만든다.

`unkFade(unk, l, r)` → 꼬리가 덮는 구간 `[[l, l+f]]` · `[[r-f, r]]` — 그 안에는 유령 구분선을 긋지 않는다.

모양(C:1456~1467):
```
mask = linear-gradient(to right,
        rgba(0,0,0, var(--ma,1)) 0, #000 var(--fl,0px),
        #000 calc(100% - var(--fr,0px)), rgba(0,0,0, var(--mb,1)) 100%)
unk-s → --ma: 0 · border-left-style: dashed
unk-e → --mb: 0 · border-right-style: dashed
unk-s.j-l → --ma: .35      // 이어 붙은 쪽은 .35까지만 옅어져 긴 칸이 끊겨 보이지 않음
unk-e.j-r → --mb: .35
u-l       → border-left-style: dashed
```
같은 규칙을 `.tl-cell` · `.tl-acell`(날짜 칸) · `.tl-dep`이 함께 쓰고, 줄 직속 요소인 `.tl-fig`(C:1665~1670) · `.tl-hang`(C:1715~1722) · `.tl-houseline`(C:1679~1683)이 같은 말투를 따로 한 번 더 적는다.
`.tl-fig`는 **올리거나 고르면 가림을 거둔다**(막대 밖으로 뻗는 수명선이 잘리지 않게 · C:1670).

## 3-4. 모호한 칸의 무늬 — `zoneCls` · `zoneCss` (T:819~894 · T:1021~1027)

이설이 아니라 **연대 자체가 흐린 칸**은 띠의 연대 폭과 같은 말로 칸 바탕에 무늬를 깐다.

```
zoneKindOf(c) = c.certainty === 'legend' ? 'legend' : 'estimated'
그 줄의 모든 칸에서 구간을 모은다:
  c.startRange · c.endRange 가 있으면 [X(a), X(b)]
  없고 certainty 가 estimated | legend 이면 [칸 왼쪽 - 0.5, 칸 오른쪽 + 0.5]   // 칸 전체

칸 i 마다:
  inL = l + bl ;  inR = r - br            // bl · br = 좌우 테두리 두께(좁은 칸은 0)
  ink = 이름표 글자를 비킬 구간
        움직일 수 있는 이름표: [c - w/2 - 3 - 0.5, c + w/2 + 3 + 0.5]   (c = 비킨 뒤의 가운데)
        고정된 이름표: [inL, inR]  (= 칸을 다 덮음 → 무늬 없음)
  구간마다 a = max(z.a, inL), b = min(z.b, inR)
  zl = (l > z.a + 0.25 && l < z.b - 0.25)        // 이 칸의 왼쪽 경계가 폭 안
  zr = (!jr && r > z.a + 0.25 && r < z.b - 0.25) // 이어 붙지 않은 오른쪽 끝이 폭 안
  b - a >= 1 일 때 ink 로 자른 조각마다 layer { a - l, b - l, kind }  (조각 길이 >= 1)
```
CSS로는 배경 그림 여러 겹(T:1023~1027):
```
estimated : repeating-linear-gradient(90deg,  var(--zc) 0 1.5px, 투명 1.5px 4px)
그 밖(전승): repeating-linear-gradient(135deg, var(--zc) 0 1.5px, 투명 1.5px 4.5px)
background-size     : 겹마다 (b - a)px 100%
background-position : 겹마다 (a - bl)px 0
background-repeat   : no-repeat
--zc = mixSrgb(--edge-soft, 투명, 42%)              (C:1865)
z-l → border-left-style: dotted ;  z-r → border-right-style: dotted   (C:1866~1867)
```
띠의 `.tl-zone`(1-4 나)과 무늬의 **각도는 같고 줄 간격이 다르다**: 띠는 2/6 · 5/10, 칸은 1.5/4 · 1.5/4.5. 새 엔진에서 두 무늬를 같은 타일로 뭉뚱그리면 안 된다.

## 3-5. 이설의 유령 구분선 `.tl-calt` (T:718~786 · T:6195~6212 · C:1835~1873)

- 이설이 말하는 경계 해마다, 칸 높이만 한 옅은 세로 점선: **폭 1px · `repeating-linear-gradient(to bottom, --gc 0 1px, 투명 1px 3px)`**(1 켜고 2 끔) · 위아래 2px 들임(`top + 2`, 높이 `h - 2 - bottom`, `bottom` 기본 2 · 가문 줄이 있는 지도자 칸은 4).

- 긋지 않는 곳: 진짜 구분선 · 칸 끝에서 `ALT_GAP = 3`px 안 · 칸의 미정 꼬리 안(`unkFade`) · 이름표를 비킬 자리가 없을 때 · 칸 폭 `< 8px`(문턱 둘) · '이설' 체크가 꺼짐 · 조감. 대신 이름 밑에 가로 점선 하나(`is-has`, 높이 1px, 가로 방향 같은 점).
- 이름표 비킴: 선에서 `3px`(칸 끝과도 3px) 떨어지는 자리 가운데 **가장 적게 움직이는 곳**으로 `translate` (T:756~783).

## 5-1. 타일에 실을 값

### 구역 1 — 띠 `look · tag · sub`

```
look (u32, 비트 나눔)
  bits 0-5   종류 kind      0 state · 1 vassal · 2 federation · 3 org · 4 era · 5 culture
                            6 tributary · 7 fief · 8 dominion · 9 warlord · 10 protectorate

                            16 exile · 17 movement          (K:265~290의 KIND_ORDER 그대로)
  bit  6     fam-dep (종속 갈래) — kind 에서 끌어낼 수 있으나 그리기가 자주 보므로 따로
  bits 7-8   확실성 certainty  0 accepted · 1 certain · 2 estimated · 3 legend
  bit  9     whole  (띠 전체에 무늬 — 곧 연대 폭이 없음: T:6791의 whole)
```

`flags`(이미 있는 열)의 `1 왼쪽 잘림 · 2 오른쪽 잘림 · 4 시작 미정 · 8 끝 미정`은 그대로 쓰고, `fadeL · fadeR`은 그리는 쪽이 1-1의 식으로 셈한다(화면 폭이 필요하므로 타일에 넣지 않는다).

### 구역 2 — 칸 `lane · style · color`

```

  bit 0  시작 미정(unk-s)      bit 1  끝 미정(unk-e)      bit 2  앞 칸의 끝이 미정(u-l)
```

## 5-3. 빠뜨리기 쉬운 가장자리 경우

1. **탭의 폭은 10.5px로 재고 글자는 10px로 그린다.** 같게 맞추면 자리가 어긋난다(C:1515).
2. **`bandStart`/`bandEnd`는 연대 폭까지 품은 값**이다(T:304~305). 띠의 자리는 `start`가 아니라 `startRange[0]`에서 시작한다.
3. **미정 꼬리는 띠 폭에 더해진다.** `x1 -= 44`한 뒤에 `left = max(x1, -1)`를 셈하므로, 화면 밖으로 밀리면 `fadeL`이 줄어든다.
4. **`whole`(띠 전체 무늬)은 연대 폭이 있으면 꺼진다.** 전승 연대인데 `startRange`를 적은 띠는 띠 전체가 아니라 그 구간만 빗금이다.
5. **전설 · 반전설 띠는 바탕과 테두리가 투명**하고 `::before` 한 겹이 전부를 그린다. 띠 안의 칸은 옅어지지 않는다.
6. **`is-alt`(번갈아 짙기)는 원래 목록의 번호**로 정한다(T:6308의 `i % 2`). 보이는 칸의 차례로 셈하면 옆으로 옮길 때 짙기가 깜빡인다.
7. **`joins`의 문턱은 1.5px**이고 `layoutStrip`은 잇지 않는 쪽만 0.5px 틈을 준다. 두 값을 뭉뚱그리면 이어진 칸에 실금이 생긴다.
8. **그리지 않는 좁은 칸이 무리 한가운데 있어도 이음은 살아 있다**(`linked` · `p.r = c.l`).
9. **예속 안 칸의 줄 번호는 거꾸로다**(`0번이 맨 아래`). 게다가 줄 수는 그 **줄 전체**의 `rowLanes`로 재야 한다.
10. **매달린 이름표와 책갈피 탭은 띠보다 아래 층**(`z-index: -1`)이다. 줄 상자가 쌓임 맥락이라 줄 바탕보다는 위다.
11. **기관 칸은 띠의 자식이 아니라 줄 직속 요소**다(인물 막대도 같다) — 그래서 띠가 흐려져도 함께 흐려지지 않는다.
12. **`kind-vassal` · `fam-dep` · `exile` · `movement`의 9% 바탕이 미정의 6%를 이긴다**(CSS 차례). 옮길 때 이 우선순위를 표로 굳혀 두어야 한다.
13. **`.tl-band .tl-cell`의 6px 반지름은 `.tl-cell.k-leader`의 4px를 이기고, `.tl-cell.k-phase`/`k-rank`의 4px는 다시 그것을 이긴다**(파일 뒤에 있으므로). 결과: 지도자 6 · 내각 5 · 시기 4 · 지위 4.
14. **점령 빗금(45° 1/4)과 전승 빗금(135° 5/10)은 기울기가 반대**다.
15. **조감에서는 탭 · 칸 · 무늬 · 이름표가 전부 사라지고 띠 하나만 남는다**(높이 14 또는 8, 반지름 4.5 또는 2.5).
16. **`kind-movement`의 깃대는 `::before`를 쓴다** — 전설 · 반전설이면 그 자리를 안개가 쓰므로 `box-shadow: inset 3px`로 바뀐다.
17. `.tl-cell.is-dense`의 **불투명도 .7**은 v3(C:372)에서 온 값이고 뒤에서 덮이지 않는다.
18. 띠의 `box-sizing: border-box`이므로 **테두리는 `width` 안쪽**이다. 칸의 `l · r`도 모두 안쪽 상자 기준(`ox`).

## 7. 미확인으로 남긴 것

1. **어두운 화면의 실측값.** 모든 색 식은 적었으나 덤프는 밝은 화면만 떴다. `--edge-k 70% · --edge-soft-k 60% · --film 42/54/66%`의 실제 픽셀은 재지 않았다.
2. **`.tl-cell.k-leader`의 `HT.leaderLabel`이 내놓는 글**(지도자 표시 방식 `leaderMode` · `leaderOrdinal`에 따라 달라짐)은 이름 맞춤의 입력일 뿐이라 내용까지는 파고들지 않았다.
3. **조감(밀도 4단계)의 띠 모습**(`BIRD` · `_birdName` · `.tl-bnm`)은 묶음 6의 몫이라 상수(14/8px · 반지름 4.5/2.5 · 이름 10px/700 · 띠 시작에서 6px)만 적고 자세한 규칙과 실측은 하지 않았다.
