## 0. 읽는 법 · 좌표계 · 층

- **좌표.** `X(해)`는 그 해의 **트랙 안 가로 좌표**(0 … `W`)다. 연표 전체 화면에서 왼쪽 칸(`GUTTER = 196`, 실측 장면은 240)을 뺀 값이고, 선·네모의 SVG는 모두 이 좌표를 쓴다(덤프의 `r`은 쪽 좌표라 `+gutter`만큼 크다). 세로는 트랙 위쪽부터의 px.
- **좌표 다듬기.** 화면에 쓸 때 `cx(t) = t.toFixed(1)`(107) — 0.1px까지만 적고 정수 격자에 붙이지 않는다. 새 엔진도 0.1px 해상도 이상으로 반올림하지 않는다.
- **시간 → px.** `bandStart(p) = p.startRange ? p.startRange[0] : p.start`, `bandEnd(p) = p.endRange ? p.endRange[1] : p.endY`(304~305). 연대 폭(`startRange`·`endRange`)이 있으면 띠는 바깥 끝까지 길고, **네모는 안쪽의 확정 해**(`p.start`·`p.endY`)에 선다 — 이 차이가 관문·다리를 끄는 조건의 뿌리다.
- **미정 끝의 꼬리.** `FADE = HT.UNKNOWN_FADE || 44`(72). 시작 미정이면 띠의 바깥 왼쪽 끝 `x1 = X(bandStart) − 44`, 끝 미정이면 `x2 = X(bandEnd) + 44`.
- **층 차례**(3980 · css 889~891 · 1617~1618):

  | 층 | 요소 | z |
  | --- | --- | --- |
  | 1 대범위 테두리 | `.tl-lanes > .tl-scope` | 0 (DOM 앞) |
  | 2 띠 뒤 선 | `.tl-links` — 소속선 · 승계선 · 고리 · 대범위 부흥선 | 0 (DOM 뒤 → 테두리 위) |
  | 3 띠와 띠 안 | `.tl-lane`(띠 채움 · 무늬 · 칸 · 테두리 · 탭 · 사건 · 단추) | 1 |
  | 4 띠 위 표식 | `.tl-marks` — 문 → 관문·다리·고리·합류 조각 → 건국·멸망 네모 | 3 |

  2층의 선이 띠를 가로지르는 부분은 3층 띠에 **가려지고**, 그래서 네모에 닿는 마지막 몇 px만 4층에 다시 그린다(이것이 '관문'이다).
- **`_drawLinks`의 묶음**(7368~7403): 4층은 `줄 → 정권` 두 겹 묶음(`<g data-row>` 안에 `<g data-p>`)이고, 한 정권 묶음 안의 차례는 `pre`(문·관문·다리·합류 조각·고리) 다음 `sq`(네모)다. 대범위를 켜고 끌 때 4층을 줄과 같은 거리·같은 시계로 옮기기 위한 묶음이다.

## 2. 건국·멸망 네모 (`_squares` 3286~3314 · `_anchorY` 3277~3280 · `_sqZones` 3360~3367)

### 2-1. 세로 자리

```
anchorY(row) = rowTop[row] + (geo.lines > 1 ? geo.textTop + geo.lineH
                                            : geo.textTop + geo.lineH / 2)
```

네모의 가운데와 **모든 승계선·소속선의 가로 획**이 이 높이에 온다. 글줄이 둘 이상이면 첫 글줄과 둘째 글줄 **사이**, 하나면 그 글줄 **가운데**다(`geo.lineH = G.line = 21`). 조감에서는 `textTop = 0 · lineH = 띠 높이`라 띠 한가운데가 된다(2998).

### 2-2. 가로 자리

```
x1 = X(bandStart(p)) − (p.startUnknown ? 44 : 0)     // 띠의 바깥 왼쪽 끝
x2 = X(bandEnd(p))   + (p.endUnknown   ? 44 : 0)     // 띠의 바깥 오른쪽 끝
mL = 6.5 + (p._seamL ? seamPush( x1 − X(bandEnd(p._seamL)) ) : 0)
mR = 6.5 + (p._seamR ? seamPush( X(bandStart(p._seamR)) − x2 ) : 0)
fc = p.startUnknown ? X(p.start) : max(X(p.start), x1 + mL)     // 건국 네모 가운데
ec = p.endUnknown   ? X(p.endY)  : min(X(p.endY),  x2 − mR)     // 멸망 네모 가운데
```

- 연대 폭이 없고 이음매도 아니면 네모 가운데는 **띠 바깥 끝에서 6.5px 안쪽**(테두리 1 + 여백 2 + 반 3.5).
- **이음매 비키기.** `_seamL`·`_seamR`은 `chainRows`(496~546)가 적어 둔, 같은 줄에서 곧바로 이어지는 승계 쌍이다. 두 띠가 맞닿으면 `seamPush(0) = 3`px만큼 더 안으로, 틈이 12px 벌어지면 0 — 그사이는 이어지는 값이라 확대하는 동안 네모가 튀지 않는다(문턱 없음).
- **연대 폭이 있으면** `X(p.endY) < x2 − mR`이므로 `ec = X(p.endY)`, 곧 네모가 띠 끝에서 멀어진다. 이때 관문·다리를 두지 않는 것이 `GATE_MAX` 검사다(4-3).
- 미정 끝은 사라지는 꼬리 한가운데(제 해 `X(p.start)`·`X(p.endY)`)에 서고 **점선 동그라미**가 된다.

### 2-3. 생략 문턱

`w = x2 − x1`(띠의 바깥 폭), `lines` = 그 줄의 글줄 수.

| 차례 | 조건 | 결과 | 근거 |
| --- | --- | --- | --- |
| ① | `p.ongoing` | 멸망 네모 없음 | 3297 |
| ② | `lines === 1 && w < 42` | 멸망 네모 없음 — 점 하나 놓을 자리(약 42px)가 없음 | 3302 |
| ③ | `(lines === 1 && w < 29) \|\| w < 11` | **둘 다 없음**, `fc = ec = (x1 + x2)/2` | 3303~3305 |
| ④ | 그 밖에 `showE && ec − fc < 8` | 멸망 네모 없음, `fc = ec = clamp((fc+ec)/2, x1 + 6.5, x2 − 6.5)` — 네모 하나뿐인 좁은 띠는 이음매 비키기를 쓰지 않는다(비키면 반대쪽 테두리에 걸림) | 3306~3309 |

### 2-5. 사건 글자가 비켜 가는 영역 (`_sqZones` 3360~3367 · `_drawTrack` 6936~6939)

- 반너비 `G.sq/2 + SQ_CLEAR = 3.5 + 1.5 = **5**`. 구간은 `[c − 5, c + 5]`(c = `fc` 또는 `ec`).
- **글줄이 둘 이상**이면 네모가 두 글줄 사이에 있으므로 첫째·둘째 글줄의 **글자만** 비킨다(셋째 값 `1`). 점은 글줄 가운데라 네모와 3.5px 떨어져 있어 비키지 않는다.
- **글줄이 하나**면 네모가 그 글줄 가운데에 있으므로 **점도** 밀어낸다(셋째 값 `2`, `noDot`에 `[l, r, dir]` — `dir`은 건국 `+1` · 멸망 `−1`). 이때 `_squares`를 `lines = 1`로 다시 불러 자리를 잡는다(6938).
- 내림줄·오름줄이 띠 안을 지나는 자리도 같은 반너비 5px로 `plan.zones`에 들어가 사건 글자가 비킨다(7618 · 7673 · 7686 → 7001).

## 3. 승계선의 길 (`_linkPlan` 7446~7730)

### 3-0. 줄 정하기는 그리기 앞의 일 (`chainRows` 496~546)

**승계(직접·간접·부흥·부분)로 이어지는 정권만 같은 줄을 쓴다** — 관계가 없으면 같은 민족이라도 새 줄이다. 시작 차례(`byStart`)로 훑되 같은 해에 시작하는 무리는 배치를 통째로 고른다:

1. 무리(같은 `bandStart`) `grp`를 잡는다.
2. 점수 = (직접으로 이은 수, 직접·부흥·간접으로 이은 수, 이은 수) 세 겹 사전 순. 한 줄의 마지막 정권이 선대이고 그 앞에서 끝나야(`bandEnd(last) ≤ bandStart(p)`) 이을 수 있다.
3. 같은 점수면 **먼저 찾은 배치**가 남으므로 결과는 예전 규칙(차례대로 각자 이을 수 있는 첫 줄)에 가장 가깝다.
4. 무리가 9개 이상이면(`greedy`) 첫 줄만 보고 끝낸다.
5. 그래서 한 선대의 줄을 여럿이 다투면 **직접 > 부흥·간접 > 부분**(`SUCC_KINDS.rank` 0/1/1/2)이다.

줄이 정해지면 줄 안에서 `q.endUnknown` · `p.startUnknown` · `q.endRange` · `p.startRange`가 **모두 없고** `p`가 `q`를 잇는 쌍에 `q._seamR = p` · `p._seamL = q`를 적는다(536~544). **표시 체크와 무관하게 자료로 정한다.**

### 3-1. 어떤 쌍에 선을 긋는가 (7513~7528)

```
if (!show.succession) 승계선 전체 없음        // 메뉴 '숨기기'
for p in tr.periods:
  if p._folded or p._hidden or p._overlay: 건너뜀
  for edge in p.predecessors:
    q = edge.from
    if q.track != tr.id: 건너뜀                 // 트랙을 건너는 승계는 긋지 않음
    if q._row == null or p._row == null: 건너뜀
    if q._folded or q._hidden or q._under or q._overlay: 건너뜀
    if tr.hiddenRows.has(q._row) or tr.hiddenRows.has(p._row): 건너뜀   // 빈 줄 접힘
    if show.succession == 'direct' and edge.type != 'direct': 건너뜀
    if tr._bundled.has(edge): 건너뜀             // 대범위 부흥선으로 묶임
    edges.push({edge, q, p})

edges.sort( q.uid 오름차순, 그다음 |p._row − q._row| 오름차순 )
```

정렬 차례가 곧 세로 통로 번호(`outIdx`)의 차례다 — 같은 선대에서 나가는 선은 줄 거리가 가까운 것부터 안쪽 통로를 쓴다.

### 3-2. 두 끝의 좌표와 자격

```
sq = _squares(q, …)                 // 선대
sp = _squares(p, …)                 // 후대
half = G.sq/2 + 1 = 4.5
x1 = 보통: sq.ec + 4.5              조감: q.endUnknown ? X(q.endY) : X(bandEnd(q)) − 3
y1 = anchorY(q._row)
x2 = 보통: sp.fc − 4.5              조감: p.startUnknown ? X(p.start) : X(bandStart(p)) + 3
y2 = anchorY(p._row)
if max(x1,x2) < −20 or min(x1,x2) > W + 20: 건너뜀     // 화면 밖

qe = X(bandEnd(q))                  pf = X(bandStart(p))
qEnd = qe + (q.endUnknown ? 44 : 0) // 꼬리까지 센 선대의 오른쪽 끝
pl   = pf − (p.startUnknown ? 44 : 0)

okQ = 조감 ? (!q.endUnknown && birdEnd(q, qe))
           : (sq.showE && !q.endUnknown && x1 ≤ qe − 1.5)
okP = 조감 ? (!p.startUnknown && birdEnd(p, pf))
           : (sp.showF && !p.startUnknown && x2 ≥ pf + 1.5)
gq  = okQ && x1 ≥ qe − GATE_MAX(5.5)      // 관문·다리를 둘 수 있는 선대 끝
gp  = okP && x2 ≤ pf + GATE_MAX(5.5)      // 같은 것, 후대 시작
multi = (kind.strands || 1) > 1
```

- `okQ`·`okP`는 "네모가 그려지고, 그 끝이 확정이며(미정 꼬리는 지날 테두리가 없다), 네모 쪽 선 끝이 문 안쪽"이다. 네모 하나뿐인 좁은 띠에서 네모가 테두리에 바짝 붙으면 거짓이 된다.
- `gq`·`gp`는 여기에 "네모가 **띠 끝 자리**에 있다"를 더한다. 이음매 비키기(3)까지 더해도 `x1 = qe − 5`라 `5.5` 안에 들지만, **연대 폭이 있는 끝**은 네모가 확정 해에 서서 테두리에서 멀어지므로 거짓이 되고 → 관문·다리 없이 띠 뒤 선만 남는다. 띠 위 획이 연대 폭 구간의 사건 점·글자를 가로지르지 않게 하려는 것이다(442~443).
- 조감의 `birdEnd(o, x) = (−1 ≤ x ≤ W+1) && X(bandEnd(o)) − X(bandStart(o)) ≥ 2×(STUB + 3) = 12`(7452).

### 3-3. 관문 (`gatePiece` 467~476 · `gate` 7508~7512)

띠 뒤 선은 띠에 가려지므로, 네모 ↔ 제 띠 테두리의 짧은 한 획을 4층에 다시 그린다.

```
gatePiece({a, b, at, vertical, border, kind, edge, dh, sg}):
  h  = 문 높이(3-5)
  lo = min(border) − 0.5 ;  hi = max(border) + 0.5
  door = vertical ? { x: at − h/2, y: lo, w: h, h: hi − lo }
                  : { x: lo, y: at − h/2, w: hi − lo, h }
  segs = 가닥마다 × beatRuns(a, b, kind.beat) 의 칠 구간
```

쓰는 자리 넷:

| 부름 | a (네모 쪽) | b (테두리 밖) | at | vertical | border |
| --- | --- | --- | --- | --- | --- |
| `gateOut()` 선대 오른쪽 | `x1` | `qe + 0.5` | `y1` | 아니오 | `[qe − 1, qe]` |
| `gateIn()` 후대 왼쪽 | `x2` | `pf − 0.5` | `y2` | 아니오 | `[pf, pf + 1]` |
| 내림줄 `drop` | `yS` | `edgeY + dir×0.5` | `xm` | 예 | `[edgeY − dir, edgeY]` |
| 오름줄 `rise` | `yE` | `edgeY − dir×0.5` | `xm` | 예 | `[edgeY + dir, edgeY]` |

- 가로 관문의 문은 폭 **2**(테두리 1 + 양쪽 0.5), 높이 = 문 높이. 실측 `#705 tl-door [1055.8, 632, 2, 8]`.
- `gate()`는 `plan.top`에 **문을 먼저, 선 조각을 나중에** 넣는다(7510~7511) — 4층에서 문이 밑에 깔린다.
- 세로 관문의 `yS`·`yE`(4-2·4-4 참조): 보통 `y1 + dir×4.5` · `y2 − dir×4.5`(네모의 그쪽 변 1px 밖), 조감은 띠 안쪽 `STUB`.

## 4. 선의 모양

### 4-1. 가닥 (`strandsOf` 404~408 · `offsetHV` 410~424)

> **2026-10-13 바뀜 — 부분 승계는 이제 가는 한 줄입니다.** 감독 결정('A 한 줄 · 짙기 80%' — 처음 35%로 골랐다가 너무 안 보여 80%로)으로 세 가닥 · 유령 가닥 · `strandsOf` · `offsetHV` · `partialLit` · `doorSpan`이 없어졌습니다. 지금 규칙: 종류 표의 `thin`(부분 승계만) → 밀도의 가는 선 값 `G.thin`(보통 1px · 픽셀 칸 가운데, 조감 a·b .8 · c .6) · 짙기는 띠 뒤 선도 띠 위 조각도 .8 · 문 높이 · 세로 통로 간격(한 칸 5px) · 합류 조각은 다른 승계와 같음 · 정도(약 · 중 · 강)는 선에 그리지 않고 풍선 · 상세 창의 글로만. 이 절과 아래 4-3 · 4-4 · 7-2 · 9절의 가닥 값(간격 2.1 · 문 높이 8 · 1.6칸 · .7 / .32)은 그 전의 기록입니다.

```
strandsOf(kind, edge, sg):
  n = max(1, kind.strands || 1)
  n === 1 → [{ o: 0, ghost: false }]
  아니면 i = 0 … n−1 에 대해 { o: (i − (n−1)/2) × sg.pitch,
                              ghost: !kind.lit(edge, i, n),
                              w: sg.w }
```

부분 승계는 `n = 3`, `pitch = 2.1` → `o = −2.1, 0, +2.1`. 진한 가닥은 `partialLit(degree, i)`(395~398):

| 정도 | 진한 가닥 |
| --- | --- |
| 1 약 | 가운데 하나(`i === 1`) |
| 2 중(정도가 없으면 이것) | 바깥 둘(`i !== 1`) |
| 3 강 | 셋 다 |

나머지는 **유령 가닥** — 같은 색 · 같은 굵기의 **실선**에 `stroke-opacity: .32`(css 905). 점선은 불확실의 뜻이라 쓰지 않는다. 가닥 자리가 늘 셋이라 폭이 정도와 상관없이 같고, 그래서 이음매·문 크기도 일정하다.

`offsetHV(pts, o)`는 가로·세로 꺾은선을 옆으로 `o`만큼 나란히 옮긴다(나아가는 쪽의 왼쪽이 +). `roundHV(pts, rad, o)`(284~297)는 모서리를 `Q`로 둥글리되 **바깥쪽 가닥은 반지름을 늘이고 안쪽은 줄여**(`r = clamp(rad + o × turn, 0.5, 두 변의 반)`) 가닥들이 한 중심의 굽이를 돌게 한다.

### 4-2. 점선 박자 (`beatRuns` 426~438)

```
beatRuns(from, to, beat):
  len = |to − from| ;  len < 0.5 → 없음
  beat 없음 → [[min, max]] 한 획
  [on, off] = beat
  n = max(1, round((len + off) / (on + off)))
  d = (len − off × (n − 1)) / n                  // 칠 길이를 늘이거나 줄임
  i = 0 … n−1 : [from + dir×i×(d+off), + dir×d]
```

칠을 늘여 **양 끝이 늘 칠로 끝난다**. 띠 뒤 선은 SVG `stroke-dasharray`(`'5 4'`)를 그대로 쓰지만, 띠 위 조각은 짧아서 이 식으로 직접 나눈다.

## 7. 확대 수준과 조감에서 달라지는 것

### 7-1. 확대(밀도 0~1)에서 저절로 달라지는 것

관계선에는 확대 문턱이 따로 없다. 달라지는 것은 모두 **px로 재는 값**이다:

- 네모 생략(2-3의 42 / 29 / 11 / 8) — 멀리 볼수록 띠가 좁아져 멸망 네모 → 둘 다 순으로 사라지고, 그러면 `sq.showE`·`sq.showF`가 거짓이 되어 **관문·다리도 함께 사라지고 띠 뒤 선만** 남는다.
- 이음매 비키기 `seamPush`는 0~3px 사이를 이어지게 움직인다(문턱 없음).
- `GATE_MAX` 검사는 연대 폭이 있는 끝을 늘 뺀다(확대와 무관).
- 길 고르기(`hv` → `당김` → `drop` → `rise` → `되돌아감`)는 `x2 ≥ xm + 6` 같은 px 비교라 확대하는 동안 갈릴 수 있다.

### 7-2. 조감 (`_bird` — 밀도 2 · `G_BIRD` 59 · `BIRD` 60~67 · `STUB` 70)

- **네모가 없다**(3289: `_squares`는 `showF = showE = false`, `fc = x1 · ec = x2`를 돌려준다). 선은 **띠 끝 가운데**에 닿는다.
- 띠 끝 안쪽 `STUB = 3`px까지가 관문(문 + 띠 위 획)이다: `x1 = X(bandEnd(q)) − 3` · `x2 = X(bandStart(p)) + 3`.
- 관문을 둘 조건 `birdEnd`: 끝이 화면 안(−1 … W+1)이고 띠 폭이 `2 × (3 + 3) = 12`px 이상.
- 미정인 끝은 사라지는 꼬리라 관문 없이 제 끝 해에서.
- 내림줄·오름줄의 세로 획은 **네모가 있었을 자리** `stationX = 7.0`px(띠 끝에서) — 네모 가운데 6.5px보다 0.5px 안쪽이라 문 4.4px이 모서리 4.5px 밖의 곧은 변에 든다.
- 띠 안 이름·단추를 비켜야 한다: `birdClear(row, x) = tr._bnmZ[row]에 [l, r] 가운데 l < x+4 && r > x−4 인 것이 없다`(7454).
- 값 묶음(`_G()` 1612~1617): `pad 4 · gap 6 · memberGap 6 · groupGap 6 · tab 0 · hem 0 · folded 22 · foldedGroup 14 · scopeHead 12 · scopeFoot 4`, 모양마다 `door`(a·b 4.4 · c 3)와 `radius`(a·b 4.5 · c 2.5), 가닥 값 `a·b {w .8, pitch 1.4, pad .6}` · `c {w .6, pitch .8, pad .35}` → 부분 승계의 문 높이 a·b **4.8**(≤ 14 − 4.5×2 = 5) · c **2.9**(≤ 8 − 2.5×2 = 3).
- 줄 사이가 모두 6px인 까닭: 5.5px보다 좁으면 이웃 줄 사이의 소속선이 사라진다(57).
- 모양 c(8px 띠)에는 띠 안 이름·단추가 없다.
- 자동 조감 문턱 `BIRD_AUTO = 2600`년, 나가는 문턱은 8% 아래(`LOD_GAP`).

- `x0 · x1`은 `start`·`end`에서 나오므로 **통로가 그 밖으로 나간다**: 오른쪽으로 `qEnd + 9 + k×5 + 1.5`, 왼쪽으로 `pl − 9 − k×5 − 5`, 미정 꼬리 `±44`. 타일을 고를 때 가로로 **±(44 + 9 + 5·k_max + 8) ≈ ±100px** 넓혀 묻고, 그리기에서 화면 밖은 잘라 낸다.
- 네모의 화면 자름(2-3 ⑤)은 `W`(화면 폭)를 쓰므로 타일 경계가 아니라 **화면 경계**로 판정해야 한다. 타일 경계에서 자르면 이음매마다 네모가 깜빡인다.

층 차례는 0절의 표 그대로(테두리 → 띠 뒤 선 → 띠 → 띠 위 표식). 한 트랙 안에서 ②~④는 한 번에, ⑤~⑨는 4층에서 한 번에 낼 수 있다.

### 8-5. 가장자리 경우

1. **화면 밖 줄과 이어진 선.** 두 끝의 `anchorY`는 `SceneLayout`이 모든 줄 자리를 갖고 있으므로 셈된다. 다만 **접힌 줄**(`hiddenRows`)에 닿는 선은 아예 그리지 않는다(7522) — 접힘이 흐르는 동안에는 지금 연표가 매 프레임 다시 셈하므로, 새 엔진도 흐름의 매 프레임에서 `hiddenRows`를 다시 봐야 한다.
2. **타일 경계.** 선 하나가 여러 타일에 걸리면 같은 선을 두 번 그리게 된다 → 트랙 단위로 **`from`·`to` 띠 id 쌍으로 한 번만** 그리도록 거른다.
3. **선대가 화면 밖.** 합류 선은 `qEnd < −50 || x1 > W + 20`이면 그리지 않는다(7594). 보통 승계선은 `max(x1,x2) < −20 || min(x1,x2) > W + 20`일 때만 끈다(7541) — 곧 통로가 화면 안이면 두 끝이 밖이어도 그린다.
4. **네모가 반쯤 잘림.** 그리지 않는다(2-3 ⑤).
5. **`W` 의존.** `_squares`는 `W`를 받아 자름을 판정하므로, 그림 내보내기(`toSVG`)는 제 폭을 넘긴다(8777). 새 엔진도 화면과 내보내기가 같은 함수를 같은 인자로 부르게 한다.
6. **책갈피 탭.** `tabR(p)`는 그 그리기에서 잰 탭의 오른쪽 끝(`p._tabR`)이다 — 탭 이름이 줄어들면 값이 바뀌므로, 탭을 먼저 배치하고 관계선을 나중에 셈해야 한다.
7. **한 정권에서 선이 여럿 나갈 때.** `outIdx`가 5px씩 비끼고 부분 승계는 1.6칸(약 8px)을 쓴다. 통로가 열 개를 넘으면 `xm`이 50px 넘게 밀리므로, 선대 띠가 짧으면 통로가 후대를 지나쳐 `되돌아가는 길`로 떨어진다 — 지금 연표와 같은 모습을 내려면 **같은 정렬·같은 증분**을 반드시 지켜야 한다.

## 8-가. 동군연합 이음줄 (건의 8의 6-다 · 2026-10-14 감독 "이음줄 진행" · 고른 안 A · 늘 옅게)

같은 사람(지도자 칸의 `person`)이 **같은 때 두 나라의 지도자**이면(`HT.unionPairs` — 그려진 구간 `HT.cellSpan`이 겹치는 두 나라의 짝 · 복위 · 맞닿기만 한 칸은 뺌):

- **줄**: 겹친 기간의 **가운데 해**에서 위 나라의 지도자 칸 아랫변 → 아래 나라의 지도자 칸 윗변까지 세로로. 먹 60% · 1.5px · 평소 짙기 .5(줄에 올리거나, 두 나라 · 두 칸 가운데 하나를 고르거나 올리면 1).
- **끝의 고리**: 두 칸의 변 위에 지름 7 · 종이빛 채움 · 먹 1.5px 테(평소 테 짙기 .5).
- **층**: 두 나라 띠 안의 몫(칸 → 띠 끝)과 고리는 띠 위, 그 사이(다른 줄 · 다른 트랙 — 견본은 모두 두 나라가 다른 트랙)는 승계선처럼 띠 뒤.
- **못 그을 때**: 한쪽 칸이 화면 세로 밖이거나 그려지지 않으면(접힌 줄 · 지도자 단 없음 · 조감) 줄 대신 보이는 칸의 **이름 2px 앞에 겹고리 표지**(고리 둘 · 5px 어긋남 · 폭 12 · 채움 없음). 이름이 칸 왼쪽 안 3px보다 앞으로 밀리면(칸이 좁음) 표지도 없다. 가운데 해가 화면 가로 밖이면 아무것도 없다.
- **자료**: 내보내기 구역 49(계약 6-10절 — 끝마다 하나 · 짝은 `text2`). 새 앱 `scene/paint/unions.dart`(띠 뒤는 `unions-back` · 띠 위는 `unions-front` 걸음 · 표지는 칸 층의 이름 자리 `StripLayer.drawnCell`), 웹 `_planUnions` · `_unionHTML`(트랙마다 제 몫을 `.tl-links` · `.tl-marks`에) · `.tl-umark`.

## 10. 미확인으로 남긴 것

1. **내림줄 `drop` · 오름줄 `rise` · 합류 조각 `is-join` · 부흥 고리의 실측.** 견본 `samples/sample-moonwake.json`의 승계는 모두 (가) 같은 줄의 이음매이거나 (나) 아주 먼 줄로 되돌아가는 길이어서, 뜬 덤프 어디에도 이 셋이 없다. 고리는 자리는 잡히지만(`플랜`에 들어감) 세로 자리가 화면 아래(쪽 y ≈ 3510)라 덤프의 '보이는 요소' 걸름에 걸렸다. **식과 조건은 코드에서 정확히 옮겼으나 px 대조는 못 했다.**
2. **대범위 테두리 · 이름표 · 기간 칠 · 왼쪽 점선 칸 · `▸ 〈성격〉 n` 단추의 실측.** 견본의 대범위 넷은 모두 꺼진 채 시작하고(`scopes`에 처음부터 켬 표시가 없다), 기준 덤프 도구는 화면 상태를 건드리지 않는다. **할거기 칠(`z-hollow`)만 실측했다.** 값은 코드와 CSS에서 옮겼다.
3. **소속선(`.tl-part`)의 실측.** 소속 펼치기(`▸ 2`)가 접힌 상태라 덤프에 선이 없다. 단추만 실측했다.
4. **어두운 화면의 값.** `.tl-door.is-seam`의 `bandTint` 섞임(547~562)은 어두운 화면에서만 쓰인다 — 밝은 화면 덤프로는 확인할 수 없었다.
5. **`_linkPlan`이 쓰는 `tabR(p) = p._tabR`의 정확한 정의.** 책갈피 탭을 그리는 쪽(`_drawTrack`)이 적는 값이라 이 명세에서는 "그 그리기에서 잰 탭의 오른쪽 끝"까지만 적었다. 탭 담당 명세와 맞추어야 한다.
6. **구역 번호 20~25와 `a`~`d`의 뜻**(8-3)은 **제안**이다. 이미 쓰이는 16~19 · 32~38은 피했지만 계약 6절이 아직 비어 있어 다른 작업자가 20~25를 집을 수 있다 — 총괄이 표를 확정해야 한다.
7. **`row2` 범위 항목을 줄 묶음 타일마다 싣는 값어치**(8-3의 첫 주의)는 측정하지 않았다 — 되돌아가는 긴 선이 많은 자료에서 얼마나 늘어나는지 재 봐야 한다.
