### 0.2. 좌표계 — 두 가지 기준점

한 줄(`.tl-lane`)은 `position: relative`이고 `z-index: 1`(`css:889`)이라 **제 쌓임 맥락**을 만든다. 그 안의 요소는 두 가지 기준으로 놓인다.

| 기준 | 어떤 것 | 보정 |
| --- | --- | --- |
| **줄(lane)의 왼쪽 위** | 기간 막대 · 실 · 구슬 · 눈금 · 연대 폭 · 이설 · 발효 · 인물 막대 · 기관 칸 · 구역 탭 · 매달린 이름표 · 세로 끈 · 바탕 문화 · 책갈피 탭 · 사건 · 알약 | 없음 |
| **띠(`.tl-band`)의 padding box** = 띠 테두리 1px 안쪽 | 왕조 · 시기 · 지위 · 지도자 · 내각 칸 · **예속(품은) 칸** · 글줄 구분선 · 연대 폭 무늬 · 조명 | 코드가 `top`에 `− BW(=1)`, `left`에 `− ox(= left + BW)`를 미리 빼 둔다 |

그래서 띠 안의 것은 `화면 y = 줄 top + 1 + (style top)`, 줄 직속은 `화면 y = 줄 top + (style top)`이다. 새 엔진은 기준이 하나(캔버스)이므로 **줄 기준 하나로 모으고, 띠 안의 것에만 +1을 더하면 된다**.

### 0.4. 기준 덤프의 함정

`prototype/scripts/dump-dom.mjs:93`~`98`은 `bt · br · bb · bl`에 네 변의 테두리를 적은 뒤, **모서리 반지름이 0이 아니면 `br`을 반지름으로 덮어쓴다.** 그래서 `br`이 `"6"`이면 반지름, `"1 solid #…"`이면 반지름 0 + 오른쪽 테두리라는 뜻이다. 또 화면(1920×1080) 밖으로 40px 넘게 나간 요소는 덤프에 실리지 않는다(`dump-dom.mjs:136`) — 바탕 문화의 이름 단을 재려고 `--scroll 420`으로 한 장면을 더 뜬 까닭이다.

## 3. 속국 이름표

2026-09-20 감독 결정 '뒤집기': 속국 띠 안에 상국을 그리지 않고, **상국 띠가 제 아래 나라들을 품는다**(`timeline.js:568`~`577`, `css:1685`~`1691`, README 1-1절 '자율성이 다른 나라와 소속 관계').

### 3.1. 자료 구조 — `depProxies` (`timeline.js:586`~`631`)

```
대상: p.hosts 가 있고 p 가 띠로 그려지는 정권(기관·왕조·문화 제외),
      h.host 도 같은 조건이고 지금 자료에 있음(트랙이 달라도 됨)
      a = h.start ?? p.start,  b = h.end ?? p.endY,  b > a

look = depLook(p, h):                                       // timeline.js:578
  rel = h.relation || HT.relationOfKind(p.polityKind)
  r   = HT.relationInfo(rel)
  r 없음 · hollow(구성국 · 동군연합) · autonomy 없음 → { look 'plain',    side 'out' }
  rel === 'nominal'                                  → { look 'nominal',  side 'out' }
  rel === 'occupied'                                 → { look 'occupied', side 'in'  }
  autonomy ≥ 3 (조공 · 봉국 · 자치령 · 명목상)        → { look 'loose',    side 'out' }
  autonomy = 2 (종속 · 보호 · 위성)                   → { look 'firm',     side 'out' }
  autonomy = 1 (괴뢰 · 위임)                          → { look 'held',     side 'in'  }
  autonomy = 0 (식민 · 점령)                          → { look 'owned',    side 'in'  }

p.singleHost(상위 띠 아래에 접힌 소속) && look === 'plain' 이면 이름표를 달지 않음

결과: Map(상국 uid → {
   items: [{ p, segs: [{ h, a, b, rel, look, side }],   // segs 는 a 오름차순
             out:  side==='out' 인 구간 전체의 [min a, max b] 또는 null,
             inn:  side==='in'  인 구간 전체의 [min a, max b] 또는 null,
             outLane, inLane }],
   outLanes, inLanes })
```

**단 배정**(`timeline.js:617`~`627`) — 밖(out)과 안(in)을 따로:

```
정렬: 밖↔안을 옮긴 속국(out과 inn 둘 다 있음)이 먼저 → 시작 이른 순 → 같으면 끝이 늦은 순
greedy: ends 에서 ends[k] ≤ it[key][0] 인 첫 칸, 없으면 새 칸
lane 0 이 상국 띠 아랫변에 가장 가깝다 (매달린 탭은 띠 바로 밑, 품은 칸은 띠 안 맨 아래)
```

겹침은 **화면이 아니라 자료의 구간 전체**로 본다 — 줄 높이가 확대에 따라 출렁이지 않게.

- `.is-deep`(둘째 줄부터, `outLane > 0`): `border-top: 1px solid color-mix(edge-soft 45%, transparent)` + `padding-top: 1px` — 윗줄과 가르는 가는 선.
- `j-l`: 왼쪽 아래 모서리 0 + 왼쪽 테두리 `edge-soft 55%`. `j-r`: 오른쪽 아래 모서리 0 + 오른쪽 테두리 폭 0.
- `clip-l`(`atL && xa < −1`) / `clip-r`(`atR && xb > W + 1`): 그쪽 아래 모서리 0 + 그쪽 테두리 폭 0.
- 미정 · 모호한 연대는 품은 칸과 같은 규칙(`css:1715`~`1722`, `1865`~`1867`).
- 이름 맞춤은 `_depLabel(it, w − 4)` — 품은 칸보다 4px 더 엄하게 본다(`timeline.js:8084`).
- 이설 표식은 탭마다가 아니라 `.tl-dep-marks` 상자 하나(`left 0 · width W · top 같은 top · height 14 · z −1`)에 모아 그린다(`timeline.js:8152`).
- '같은 시기를 타국에도'의 흐리지 않는 구간은 탭이 띠 밖에 있으므로 **제 좌표로 따로** 가림 판(`--lm`)을 받는다(`timeline.js:8137`~`8141`, `css:1737`~`1760`).

### 3.5. 세로 끈 (`.tl-hang-link` — `timeline.js:8154`~`8167`, `css:1723`)

같은 속국이 밖 ↔ 안으로 옮긴 곳마다 하나:

```
이웃한 두 구간 a(k−1), b(k) 에 대해
  a.side !== b.side 이고 |X(a.b) − X(b.a)| ≤ 1.5 일 때만
  x = X(b.a);  lo ≤ x ≤ hi 여야 함
  yIn  = gr.depTop + depInTop(depRowLanes(gr), it.inLane) + 12 / 2
  yOut = bandH − 2 + it.outLane × 14 + 8
  depLinkBlocked(...)이면 긋지 않음      // 그 x 에서 이 속국보다 띠에 가까운 다른 이름표를 지나면 (timeline.js:638)
left = x, top = min(yIn, yOut), height = |yOut − yIn|
```

모양: 폭 1.5 · `margin-left: −0.75` · 반지름 1 · 배경 `var(--edge)` · 누름 없음.

### 3.6. 상국이 다른 트랙일 때

`this._proxies = depProxies(periods)`는 **트랙과 무관하게 전체 자료로 한 번** 만든다(`timeline.js:1355`). 이름표는 상국 띠가 있는 트랙에만 달리고, 속국 트랙에서는 제 띠(`fam-dep` — 옅은 띠 하나)만 보인다. 그래서 속국 트랙만 보면 누구를 섬겼는지는 설명글·상세 창에서만 알 수 있다(README 1-1절).

- `lod`는 계약 4절의 `-1`(기간에서 셈함)을 그대로 쓰면 된다. 다만 **폭이 0인 것**(이설 세로바 · 구슬 · 눈금 · 발효 마름모 · 세로 끈)은 `-1`로 두면 lod가 최소로 떨어지므로, 내보내는 쪽이 제 사건·제 이름표의 lod를 그대로 물려주어야 한다(부모가 보이는 단계에서만 표식이 보이게).
- 줄 높이에 쓰는 값(`rail_levels` · `fig` · `dep` · `zones` · `hem`)은 이미 계약 1절의 `rows` 열에 있다. **타일이 아니라 줄 표에서 읽어 쌓는다** — 확대에 따라 줄 높이가 출렁이지 않게.

### 7.3. 가장자리 경우

1. **타일 경계에 걸친 것.** 이름표·막대는 `flags`의 잘림 비트로 다루면 되지만, **이어 붙은 칸(`j-l`/`j-r`)과 "이름은 긴 칸의 첫 칸에만"은 통을 넘으면 답이 달라진다.** 이음 여부는 자료가 정하는 것이므로 내보낼 때 항목의 `d` 플래그에 굳혀 싣고, 이름 맞춤에 쓰는 폭도 **잘리지 않은 칸 전체의 폭**이어야 한다. 그러려면 `x0`/`x1`은 잘리지 않은 값으로 싣고 화면이 그릴 때 자르는 편이 낫다(지금 연표도 `layoutStrip`에 자료의 구간 전체를 준다).
2. **폭 0인 항목.** 세로 끈·이설 세로바·구슬·발효는 `x0 = x1`이라 r-tree(`item_bounds`)에서 통 경계에 딱 걸리면 빠질 수 있다. `lo_day`/`hi_day`를 ±1분 넓혀 넣을 것.
3. **제 띠 안에 가두기.** 기간 막대와 표식(`inside(e, x, 5)`), 인물 막대(띠 안쪽 4px), 기관 칸(4px)·구역 탭(10px), 매달린 탭(10px)은 모두 **얹히는 띠의 좌표**가 있어야 자리를 정할 수 있다. 타일의 띠 구역(1)과 일반 구역이 같은 통에 실리므로, 화면이 `ref`로 띠를 찾아 그 `x0/x1`(미정 꼬리 44px 포함)로 가두면 된다. 띠가 같은 통에 없을 수 있으므로(아주 긴 띠) **띠의 양 끝을 항목의 `a`/`b`에 함께 싣거나, 띠 구역을 통 밖으로 한 칸 넓혀 싣는 것** 가운데 하나를 골라야 한다 — 지금 설계에는 없는 결정이다.
4. **아주 많은 속국.** 지금 연표는 매달린 탭의 단 수에 제한이 없다(구역 탭만 3단). 속국이 수십이면 줄이 수백 px 높아진다. 새 엔진도 **줄 높이는 자료로(확대와 무관하게)** 정해야 하므로 그대로 두되, 한 줄의 이름표가 너무 많아지면 `lod`(기간 길이로 셈한 값)로 짧은 소속부터 빠지게 하면 된다 — 짧은 소속이 먼저 사라지는 것이 자연스럽다. 다만 **lod로 항목이 빠져도 단 번호와 줄 높이는 그대로**여야 한다(빈 단이 생길 뿐).
5. **구역 탭이 4단 이상일 때.** 지금 연표는 4단째부터 마지막 단에 포개어 그린다(`timeline.js:2817`). 새 엔진도 같게 하려면 내보내는 쪽이 `lane`을 이미 3으로 눌러 두어야 한다.
6. **바탕 문화가 걸친 줄이 접힐 때.** `_underRows`의 일부가 접히면 그 줄만 건너뛰고, 이름 단은 `_underRows[0]`에만 붙는다 — **접힌 줄이 `[0]`이면 이름이 아예 나오지 않는다**(지금 연표의 실제 동작. 기준 덤프의 `전체`·`아주-넓게` 장면에서 이름이 없는 까닭이 여기에 있는지는 미확인이고, 화면 밖이라 덤프에 안 실린 경우도 확인했다).

### 8.4. 기준 덤프에 없어 **실측 미확인**인 것

| 항목 | 까닭 |
| --- | --- |
| `.tl-fuzz`(연대 폭 빗금) | 월흔해 견본에 `startRange`/`endRange`를 가진 **기간** 사건이 없다 |
| `.tl-alt` · `.tl-altline`(이설 세로바·연결선) | 같은 까닭 — 이설이 붙은 사건 둘은 모두 점 사건이라 구슬로 그려진다 |
| `.tl-edge`(연대 폭 눈금) | `p-coast-6-disputed-date`의 연대 폭 양 끝이 이설 구슬과 6px 안에서 겹쳐 구슬에 흡수된다 |
| `.tl-fig.is-dense`(`인물 n명`) | 가장 넓게(≈5,722년 — 자료 범위로 잘림) 봐도 막대 평균이 9.3px이라 문턱 6px 아래로 내려가지 않는다 |
| 미정 끝 꼬리(`--fl`/`--fr`)의 실제 px | 마스크는 계산된 스타일에 식으로만 남아 덤프가 숫자를 적지 않는다. 식은 2.5절 참조 |
| 바탕 문화가 여러 줄에 걸친 모습 | 견본의 바탕 문화는 모두 한 줄에만 깔린다 |
