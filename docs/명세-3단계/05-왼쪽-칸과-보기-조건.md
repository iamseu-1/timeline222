## 2. 트랙 이름 · 민족 칸 · 민족 딱지

### 2.1. 트랙 이름 (`.tl-tname` · `_fitTrackName` js:3135~3142)

- 세로 범위: 트랙 전체(`left:0; top:0; bottom:0; width:24`). 접힌 줄을 빼는 셈은 없다 — 트랙 높이 자체가 접힌 줄을 뺀 값이다.
- 글은 세로(위→아래), 글자는 눕히지 않음(`text-orientation: upright`).
- **줄임의 차례**: `shortName(tr.name, t => [...t].length × 15.5 + 4 <= tr.height)`. 한 자 ≈ 15.5px(12.5px 글자 + 자간 .24em = 3px), 위아래 여유 4. 들어가지 않으면 다음 후보로, 모두 안 되면 **빈 글**(칸 색과 풍선만).
- 풍선(`title`): 줄이지 않았으면 `"접기"`, 줄였으면 `"<온 이름> · 접기"`.
- 다시 셈하는 때: `_buildTracks`(3995) · `_collapseRows`(3130).

### 2.2. `shortName` — 이름 줄임의 차례 (js:358~379)

`shortNames(name)`가 **뜻이 남는 차례**로 후보를 만들고, `shortName`이 `fits`가 참인 첫 후보를 고른다. 모두 실패하면 `''`.

```
후보 = []
add(name)                                            // ① 온 이름
bare  = name에서 괄호 묶음을 지운 것                   // 정규식 /\s*[(（][^)）]*[)）]\s*/g → ' '  · trim
add(bare)                                            // ② '한(삼한)' → '한'
words = bare를 [공백 · - · ‐ · – · · · ・ · /]로 가른 것 (빈 조각 제외)
stem(w) = w에서 끝의 '민족' 또는 '족'을 뗀 것          // /(민족|족)$/
if (words.length === 1) {
  add(stem(words[0]))                                // ③ '흉노족' → '흉노'
  if ([...stem].length > 1) add([...stem][0])        // ④ '흉노' → '흉'  (한 낱말일 때만 한 글자까지)
} else if (words.length > 1) {
  add(words[0])                                      // ③ '초기 유력 이민족' → '초기'
  add(stem(words[0]))                                // ④ '여진-만주족' → '여진'
}
```

- `add`는 `trim` 뒤 빈 글과 이미 있는 후보를 걸러낸다(같은 글이 두 번 들어가지 않음).
- 여러 낱말 이름은 **한 글자로 자르지 않는다**('초' · '후'는 뜻을 알 수 없어서).
- 실측(조감 a · 민족 칸 높이 14): '문화' → 후보 ['문화', '문'] → `2 × 11.8 + 2 = 25.6 > 14`, `1 × 11.8 + 2 = 13.8 ≤ 14` → **'문'**.

### 2.3. 민족 칸 (`.tl-people` · `_peopleSpan` js:3145~3154)

- 세로 범위 = 그 묶음(`gp.first` ~ `gp.first + gp.count − 1`) 가운데 **지금 펴져 있는(`hiddenRows`에 없는) 첫 줄의 윗변 ~ 마지막 줄의 아랫변**. 모두 접혔으면 `null` → `.is-collapsed`(`display: none`, css:615) · 높이 0.
  ```
  top    = tr.rowTop[first]
  height = tr.rowTop[last] + tr.rowHs[last] − tr.rowTop[first]
  ```

### 2.4. 민족 딱지 (`_rowPeopleChip` 3159 · `_pchipsHTML` 3177 · `_placePchips` 3202)

**끼워지는 규칙**(`_rowPeopleChip`):
1. 접힌 민족 줄(`foldedRows`)과 트랙 공통 줄(`commonRow`)은 묻지 않는다 → `null`.
2. 그 줄의 정권 가운데 `peopleId`가 있고 숨지 않은 것을 모은다. 없으면 `null`.
3. 그 줄을 **덮은 묶음**(`cover`)을 고른다: 이름이 있고 문화가 아닌 묶음 가운데 그 줄을 품은 것 — 대범위 가지가 있으면 그 가지, 아니면 가장 깊은(`depth`가 큰) 묶음.
4. 덮개와 **다른 민족**의 정권들만 남겨, 민족마다 `Σ(bandEnd − bandStart)`(기간 합)를 더한다. 하나도 없으면 `null`.
5. 기간 합이 가장 큰 민족을 딱지에, 모두는 풍선 글에.

**모양**(`_pchipsHTML`):
- 자리: `left = (depth − 1) × 22 + 4`(민족 칸 묶음 안 좌표) · `width = 22 − 8 = 14` · `top = tr.rowTop[r]` · `height = 접혔으면 0, 아니면 tr.rowHs[r]`.

- `depth === 1`이고 대범위 가지 안의 딱지면 **가는 띠**: `left = 22 − 2 − 6 = 14` · `width = 5` · 글 없음 · `.is-thin`. (월흔해는 `depth = 3`이라 **미확인** — 코드로만 읽었다.)

**딱지가 끼워진 민족 칸의 이름 자리**(`_placePchips` 3245~3271):
- 막히는 줄(`blocked`): 대범위가 아닌 묶음이고 (그 묶음의 `depth`가 `depth − 1`(오른쪽 끝 단)이면서 딱지가 있는 줄) 이거나 (대범위 가지에 속한 줄).

- 넓은 대범위 칸에 딱지가 끼면 `.is-side`(`span { padding-right: 22 }`, css:1647), `depth === 1`이면 `.is-thin`(`padding-right: 6` · 10px 글, css:1649).

## 3. 줄 이름 (`_drawTrackLabels` js:7241~7337)

### 3.1. 어느 띠의 이름을 보이는가

```
center = (view.start + view.end) / 2            // 화면 가운데 '시기'(해)
줄마다:
  1) row === tr.commonRow      → { name: '그 밖', color: '#9c978d', years: '', common: true }

       atCenter = p.start <= center && center <= p.endY 인 첫 정권
```

### 3.5. 칸보다 길 때 줄이는 차례 (`fitName` 7297~7320)

`room`은 1.5절. 차례대로:

1. `nameW(이름) + (연도가 있으면 textWidth(연도, size × 0.6, 400) + 4) <= room` → **이름 + 연도 그대로**.
2. `nameW(이름) <= room` → **연도를 뺀다**.
3. `shrink(이름)`: `s2 = floor(size × (room / nameW(이름, size)) × 10) / 10`에서 시작해, `s2 >= 10`이고 `nameW(이름, s2) > room`인 동안 0.1px씩 내린다. `s2 >= 10`이면 **글자를 그 크기로**(연도는 뺌).
4. 10px으로도 넘치면 **괄호 속 딴이름을 뗀 이름**(`bare`)으로: 그대로 들면 그것, 안 들면 `shrink(bare)`.
5. 그래도 안 되면 온 이름 그대로 두고 CSS 말줄임(`text-overflow: ellipsis`)에 맡긴다. 온 이름은 늘 `title`에 있다.

`nameW`에 자간(`bodyLS()`)을 더해 쓰는 것이 중요하다 — 빠뜨리면 들어가는 연도까지 빼게 된다(7301의 주석).

### 3.6. 다시 그리는 조건 (`_labelSig` 7292)

```
줄마다:
  띠: bandStart(p) − (startUnknown ? FADE × span / W : 0) ~ bandEnd(p) + (endUnknown ? FADE × span / W : 0)
      — 미정인 쪽은 화면의 FADE(44px)만큼을 해로 바꿔 넓혀 잡는다
  사건: eventIndexByRow가 있으면 구간 색인으로 near/far를 한 번에 묻고(intervalHas),
        없으면 _extent(e)(연대 폭 · 이설 · 놓인 해까지 — 2026-10-14부터 점 사건의 정밀도 구간 전체는 넣지 않음)로 mark
  바탕 문화(underlays): p._underRows의 줄마다 bandStart~bandEnd로 mark

seen[r] = near[r] || (첫 배치가 아니고 && 지금 접혀 있지 않고 && (keepOpen || !far[r]))
```

- **히스테리시스**: 화면 폭의 25% 안으로 들어오면 펴지고, 75% 밖으로 나가야 접힌다. 이미 펴져 있던 줄은 `far`가 아닌 동안 계속 펴져 있다.
- **첫 배치**(`first = !tr._rowMemo`)에는 기억이 없으므로 `near`만으로 정한다.
- **움직이는 동안은 펴지기만**: `keepOpen`이 참이면 `far`를 무시해 접히지 않는다. `keepOpen = this._inMotion() || !!this._settleDue`(6056) — 손에 잡힌 동안과 **정착을 기다리는 동안** 모두.
- `_inMotion()`(4761) = `.tl-body`에 `is-dragging` · `_coast`(관성) · `_pinching`(두 손가락) · `_glide`(휠 · 단추 · 키의 미끄러짐) · `_animating`(멀리 가기) 가운데 하나라도 참.
- 돌려주는 값은 **접힘 서명**(`[...hidden].join(',')`). `_collapseRows`(3098)는 서명이 DOM에 적어 둔 것(`tr._hiddenSig`)과 다를 때만 DOM을 고친다.

### 6.2. 접힌 뒤의 줄 쌓기 (3068~3092)

```
y = G.pad ; lastVisible = −1 ; groupStart = new Set(tr.groups.map(gp => gp.first))
줄마다 r:
  if (!seen[r]) { hidden.add(r); rowGap[r] = 0; rowHs[r] = 0; rowTop[r] = y; continue }   // 접힌 줄: 틈 0 · 높이 0
  crossesGroup = (lastVisible+1 … r) 가운데 groupStart에 든 줄이 있는가      // 숨은 줄을 건너뛰어도 민족 경계는 남는다
  tab  = (foldedRows.has(r) || r === commonRow) ? 0 : G.tab
  gap  = (lastVisible < 0 ? 0
          : memberRows.has(r) && !crossesGroup ? G.memberGap
          : G.gap + (crossesGroup ? G.groupGap : 0))
         + tab + _scopePad(tr, r, lastVisible)
  y += gap ; rowGap[r] = gap ; rowTop[r] = y ; rowHs[r] = baseRowHs[r] ; y += rowHs[r] ; lastVisible = r
tr.height = max(y + G.pad, G.folded)
```

`_layoutTrack`의 원래 쌓기(3011~3026)와 두 군데가 다르다:
- 원래는 `r === 0`을, 여기서는 `lastVisible < 0`을 본다(앞의 줄이 모두 접혔으면 첫 줄처럼 셈).
- 원래는 소속 줄이면 무조건 `G.memberGap`, 여기서는 **민족 경계를 건너지 않았을 때만** `G.memberGap`.

`_scopePad(tr, r, prev)`(7878~7887): 가지의 펴진 첫 줄이면 `G.scopeHead`(본국 줄에 매달린 가지면 `G.scopeHead + 2 − G.gap − G.groupGap`), 가지가 끝난 뒤 처음 펴진 줄이면 `G.scopeFoot`.

실측(접힌-민족-전체 · 유리해안): `rowGap = [11, 22, 19, 19, 19]` = [0+11(tab), 8(gap)+14(groupGap)+0(접힌 줄이라 tab 0), 8+11, 8+11, 8+11] · `rowHs = [125, 30, 125, 125, 125]`(접힌 민족 줄 30).

### 6.3. 접힘의 기억이 다시 지어도 이어짐 (`_foldAhead` js:1468~1485)

다시 지을 때(`setData`) DOM을 만들기 **전에** 모델만으로 접힘을 계산해, 새 DOM이 처음부터 접힌 크기로 태어나게 한다(원칙 ③ — 큰 크기로 태어났다가 줄어드는 "풍선" 없음).

```
view = _clampView(지금 보기)            // 곧 setView가 맞출 범위
W    = max(60, (다시 짓기 전에 잰 clientWidth) − gutter)   // 여기서 재면 옛 DOM 전체를 헛되이 다시 계산(≈15ms)
X    = y => (y − view.start) × W / (view.end − view.start)
트랙마다:
  이름 · 묶음의 기억(_lab · _clu · _wide · _bnm)도 이어받는다
  carried = 앞선 배치가 있고 그 줄 수가 지금 줄 수와 같다      // 줄 수가 달라지면 기억을 버린다
  carried면 tr.hiddenRows = 옛 hidden 그대로, tr._rowMemo = true
  tr._hiddenSig = _foldRows(tr, X, W, _inMotion())
  carried가 아니면 tr._rowMemo = false
```

대범위를 켜고 끄면 줄 번호가 바뀌므로 기억을 끊는다(`tr._rowMemo = false`, 7802).

### 6.5. 높이가 흐르는 법

- `.tl-lane` · `.tl-row` · `.tl-people`이 한 줄의 CSS 전환을 공유한다(css:610):
  `transition: height var(--t-move) var(--spring), margin-top var(--t-move) var(--spring), top var(--t-move) var(--spring), background-color .2s ease`.
- `.tl-track`도 `transition: height var(--t-move) var(--spring)`(css:389). 트랙 높이와 줄 높이가 **한 시계**다.
- `.tl-pchip`은 `top` · `height`가 같은 값, 바탕은 `--t-in`, 눌림은 `--t-micro`(css:1598). `.tl-scope`도 같다(css:1620).
- `.is-entering`(첫 등장) 동안에는 전환을 끈다(css:613). `.tl-lane.is-collapsed` · `.tl-row.is-collapsed`는 `overflow: hidden` + 클릭 통과, `.tl-people.is-collapsed` · `.tl-pchip.is-collapsed`는 `display: none`(css:614~615 · 1603).
- 다시 지은 뒤의 트랙 높이는 FLIP으로 맞춘다(`_applyFlip` 4005~) — 높이가 그대로인 트랙은 1px도 움직이지 않는다.

### 6.6. 흐르는 동안의 세로 닻

**어느 줄을 붙잡나** (`_holdNow` 1785~1793):
1. `anchorUid`(상세 창이 열린 항목)가 있고 그 줄이 지금 그려져 있으면(`_anchorLane` 1805) **그 줄**.
2. 아니면 `_heldAuto()`(1852): 접기 · 펼치기의 흐름이 도는 동안(`_held.until` + 스프링이 있으면 1.2초까지)은 **누르기 직전에 잡아 둔 줄**(`_pressHold`/`_holdOf` 1489), 그 밖에는 `_autoAnchor()`.
3. `_autoAnchor()`(1829~1849): `mid = scrollTop + clientHeight / 2`보다 위에 있는 줄 가운데 **가장 아래 줄**(접힌 줄은 건너뜀). 접힌 트랙은 `{ row: −1 }`(트랙 위쪽).

**어떻게 붙잡나** (`_keepAnchor` 1874~1910):
- 손이 쥐고 있으면(`_handHeld()` 1869 — `is-dragging`이거나 관성 중) **아무것도 하지 않는다**(닻은 쉰다). 멎은 자리가 새 기준(`_rehold` 2380).
- 닻이 있으면 `scrollTop = _laneAbs(a) − _anchorOff`로 맞춘다. `_laneAbs(a) = a.tr.el.offsetTop + a.lane.offsetTop`.
- 세로 스크롤을 쓰는 곳은 `_keepAnchor` 하나뿐이다(`_draw`의 끝 6096). 줄 높이가 흐르기 시작했으면 `_anchorLoop(T.move + 60)`으로 **매 프레임** 다시 맞춘다(6097).
- 브라우저의 자동 닻은 끈다(`overflow-anchor: none`) — 우리가 맞춘다.

**데려오기**(`setAnchor` 1703 · `_revealAnchor` 1732 · `_revealTo` 1751):
```
lo = SAFE_Y + this._G().tab            // 56 + 11 (조감은 56 + 0)  — 띠 위 책갈피 탭까지 보이게
hi = clientHeight − SAFE_Y − h         // h = a.tr.baseRowHs[row] (접혀 있어도 펴졌을 때의 높이)
center면  to = max(lo, (clientHeight − h) / 2)
아니면    hi >= lo ? clamp(cur, lo, hi)
                   : (cur > lo ? lo : max(cur, hi))     // 화면보다 높은 줄
to = _reachable(tr, rowTop[row], to)   // 스크롤이 닿는 데까지 (모델의 최종 높이로 — 흐르는 중에는 화면을 재지 않는다)
|to − from| < 0.5 이고 _anchorTo가 없으면 아무것도 하지 않는다   // "잘 보이면 0px"
```
- 움직임은 되튐 없는 스프링 하나: `new HT.motion.Spring(value, { response: 0.36, restDelta: 0.25, restSpeed: 2 })`(1726).
- 닻을 다른 줄로 옮길 때 앞선 데려오기가 돌고 있었으면 **그때의 속도를 이어받는다**(1714~1720).
- 접힌 줄(`hiddenRows`에 든 줄)로는 데려오지 않는다(1737) — 보여 줄 것이 없다.
- 가운데 맞춤(`center`)은 검색 · "여기로 가기"처럼 멀리 갈 때만(`focusOn`). 그때의 세로 이동은 가로 비행과 **같은 진행값**에 실려 대각선 한 번에 같은 프레임에 도착한다(`_flyRow` 1922).

### 7.3. 띠 안 이름 (`_birdName` js:3341~3356 · 그리기 6925~6935)

```
l    = (p.startUnknown ? X(p.start) : X(bandStart(p))) + BIRD_NAME.inset        // 6px
room = (p.endUnknown ? X(p.endY) : X(bandEnd(p))) − BIRD_NAME.inset − l         // 들 폭은 띠 전체 (화면에 잘린 폭이 아님)
RANK = { '': 0, short: 1, full: 2 }
fit(t, mode) = room >= textWidth(t, 10, 700) + (지난 모양보다 긴 모양이면 8 : 0) ? 그 폭 : −1
mode = fit(p.name, 'full') >= 0 ? 'full'
     : fit(p.name.slice(0,1), 'short') >= 0 ? 'short' : ''
text = full이면 온 이름 · short면 첫 글자 · 아니면 없음
```

- **자리는 띠 시작에 고정**(원칙 ①) — 옆으로 옮겨도 이름이 화면 가장자리를 따라오지 않는다. 들 폭도 화면에 잘린 폭이 아니라 띠 전체라 옆으로 옮겨도 모양이 바뀌지 않는다.
- **문턱은 두 개**(원칙 ⑨): 더 긴 모양(`''`→`short`→`full`)으로 바뀌려면 **8px**(양옆 4px)의 여유가 더 있어야 하고, 지금 모양은 딱 들어가는 동안 그대로. 기억은 `tr._bnm`(지난 그리기) → `bnMemo`(이번)로 옮기고, 다시 지어도 `_foldAhead`(1475)가 이어 준다. `prev`가 없으면(맨 처음 · 그림 내보내기) 문턱은 하나.
- **화면 안에 다 드는 이름만 그린다**: `nm.l >= −0.5 && nm.l + nm.w <= W + 0.5`. 조건에 맞지 않아도 **자리(`bnm`)는 그대로 비워 둔다** — 점 · 알약이 숨거나 드러나지 않게.
- 이름 둘레 `BIRD_NAME.clear = 3`px 안의 점 · 알약은 **옮기지 않고 숨긴다**(`bnm[row].push([l − 3, l + w + 3])` 6932 → `_placeRow`).
- 모양: `.tl-bnm`(css:1777~1786) — `position: absolute; top: 0; height: 100%; z-index: 2; display: flex; align-items: center`(띠 세로 가운데), 10px · `font-weight: 700` · `line-height: 1` · `letter-spacing: −.01em` · 색 `color-mix(in srgb, var(--c) 30%, var(--paper-ink))` · 클릭 통과. 흐림은 책갈피 탭과 같은 밝기(고른 동안 .5 · 제 것 1 · 강조 밖 .25), 전설이면 이탤릭 · 부정이면 `--paper-muted` + 취소선.

### 7.6. 자동 조감 (`_birdNow` 1595 · `_birdSettle` 1602 · `_past` 4789)

```

조감인가 = (density === 2) || (birdAuto && !_birdHold && _autoOn)
```

- 맨 처음(`_autoOn == null`)과 `setBird({ auto: true })`를 켜는 순간에는 지금 보기로 한 번 판정한다(1571 · 1596).

### 7.7. 밀도가 바뀔 때의 흐름 (`_squash` 4132~4220 — 개요)

- 모든 움직임의 시작 시각을 한 문서 시각에 못 박는다(`_squashClock` 4127 · `_squashRun` 4304에서 `a.startTime = g.tl`). CSS 전환은 한 프레임 늦게 시작하므로 쓰지 않는다.
- 줄 높이 · 위 틈 · `.tl-lanes`/`.tl-rows`의 `padding-top` · **민족 칸 · 민족 딱지 · 대범위 테두리**의 `top`/`height`가 옛 값에서 새 값으로 `T.move`(360) `C.spring`으로 흐른다(4168~4205).
- 옛 줄 안의 것은 잘린 잔상(`.tl-sqz`)으로 옛 모습 그대로(`was-bird` · 옛 `--nameSize` · `--evSize`) `T.out`에 옅어지고, 새 것은 `T.in`에 떠오른다(`_squashIn` 4332).
- **왼쪽 줄 이름**(`_squashLabels` 4342~4373): 새 줄 이름 칸의 줄마다 옛 높이 · 옛 위 틈에서 흐르며(`T.move` `C.spring`) `T.in`에 떠오르고, 옛 줄 이름 칸(`.tl-sqz-rows`)은 그 자리에 남아 같은 곡선으로 새 높이까지 흐르면서 `T.out`에 옅어진다. 옛 칸에는 옛 글자 크기(`--nameSize`)와 조감 여부(`was-bird` · `was-bird-<모양>`)를 그대로 물려준다 — 새 트랙의 값을 물려받으면 옛 이름이 커지며 칸을 넘친다.
- **글이 바뀐 칸**(`_squashText` 4315~4327): 조감에서 나올 때 '문' → '문화'처럼 글이 길어진 민족 칸 · 딱지는 글을 비워 두었다가, 칸이 그 글이 들 높이에 닿는 순간부터 `T.in`에 떠오른다.
  ```
  need = 딱지면 글자수 × 10.1 + 4 , 민족 칸이면 글자수 × 11.8 + 2
  req  = 딱지를 비켜 앉은 이름(has-pchip · --lt · --lh)이면 lt + lh/2 + need/2 , 아니면 need
  f    = h1 > old.height + 0.5 ? clamp((req − old.height) / (h1 − old.height), 0, 1) : 0
  delay = f > 0 ? T.move × bezierTimeAt(C.spring, f) : 0
  ```
- 붙잡을 줄과 다 흐른 뒤의 스크롤은 `_squashPlan`이 먼저 셈하고 `_squashHold`가 건다(4226 · 4263) — 스크롤이 줄 높이와 **같은 곡선 · 같은 진행값**으로 곧게 옮겨 간다. 조감에서 나올 때는 그 사이 손으로 옮기거나 고르지 않았으면 조감에 들기 전에 붙잡았던 줄을 그때의 자리에 되돌린다(`_birdBack`).
- 흐르는 내내 화면 밖인 트랙은 줄 안의 움직임을 걸지 않는다(`_squashAway` 4248, 여유 `SQZ_NEAR = 120`px).

### 8.1. 자료 처리부(Rust)에 물을 것

계약 2절의 `{"op":"layout"}`에 이미 있는 것으로 대부분 된다(`tracks[].color` · `rows[].kind`/`group_start`/`scope_pad`/`cats` · `groups[]`). 왼쪽 칸에 더 필요한 것:

1. **`{"op":"row_labels"}`** — 줄 이름의 내용. 보기가 움직일 때마다 화면이 묻는다(기다리지 않음 — 답이 오기 전에는 지난 답을 그대로 쓴다).

```jsonc
// 물음: 보이는 트랙 · 줄 범위와 '화면 가운데 시기'만 보낸다 (줄 수에 비례 · 자료량과 무관)
{ "op":"row_labels", "at": 정수분, "rows": [[lo,hi], …], "packs":[…] }
// 답: rows와 같은 차례. 그 줄에 보일 것이 없으면 null
{ "labels": [
    { "row": 12,
      "uid": "…",                  // 대표 띠 (없으면 null)
      "name": "유리항 물길왕국",
      "bare": "유리항 물길왕국",     // 괄호 속 딴이름을 뗀 이름 (같으면 생략)
      "color": 14332309,           // 0xRRGGBB
      "years": "240–340",          // 이미 만들어진 글 (BC 규칙은 자료 쪽에서)
      "sub":  "은결 레미나 · 문 · 유리항 첫불 왕조",   // 지도자 · 지위 첫 글자 · 왕조를 이미 이어 붙인 글
      "cap":  true,                // 도읍이 있는가 (노선 표시)
      "kind": 0,                   // 0 보통 · 1 소속 · 2 그 밖('그 밖' 줄) · 3 접힌 민족
      "cats": [0, 3, 5],           // 분류 번호 (없으면 [])
      "count": 24 },               // 접힌 민족 줄일 때만: 그 줄의 정권 수
    null, … ] }
```

- **'화면 가운데에 띠가 없을 때'의 대표(`best`)는 화면 px이 정하므로 자료 처리부가 답할 수 없다.** 두 갈래 가운데 하나를 고른다:
  - (가) 물음에 `view: [lo, hi]`(보이는 기간)를 함께 보내고, 자료 처리부가 `at`에 걸친 띠 → 없으면 `view`와 겹치는 폭이 가장 큰 띠를 고른다. `view`와 화면 px은 일차 변환 관계라 **결과가 같다**(월흔해에서 확인 필요). 추천.
  - (나) 줄마다 후보 몇 개(겹치는 기간과 함께)를 받아 화면이 고른다. 물음이 커진다.
- `sub`를 화면이 아니라 자료 쪽에서 만들어야 하는 까닭: `HT.cellSpan`의 칸 경계 `[lo, hi)` 규칙과 `leaderLabel`의 표기 방식(`leaderMode` · `leaderOrdinal`)이 자료와 설정을 함께 봐야 정해진다. 설정이 바뀌면 물음에 함께 실어 보낸다.

2. **`{"op":"rows_near"}`**(계약 2절에 이미 있음) — 빈 줄 접기. 화면은 `[−m1, W+m1]`과 `[−m2, W+m2]`를 해로 바꿔 `near` · `far`로 보낸다:
```
near = [X⁻¹(−W×0.25), X⁻¹(W×1.25)]
far  = [X⁻¹(−W×0.75), X⁻¹(W×1.75)]
fade = FADE(44px)을 해로 바꾼 값 = 44 × span / W        // 미정인 끝을 넓히는 몫
```
답이 오기 전에는 지금 접힘을 그대로 두고, 오면 **펴야 할 줄은 바로 펴고**(움직이는 중에도) **접을 줄은 정착 때 한 번에** 접는다.

3. 접힌 트랙 · 접힌 민족 줄의 **가는 막대 단**(`_laneAll` · `_laneRow`)은 **넣을 때 한 번** 정해 저장한다(원칙 ① — 화면이 정하면 안 된다). 계약 1절 `tracks.rail_levels`와는 다른 값이다. 제안: `periods`(또는 `items`의 한 구역)에 `mini_lane_all` · `mini_lane_row` 두 열을 더한다.

4. 민족 딱지(`_rowPeopleChip`)는 **줄마다의 자료**다: 덮개 묶음과 다른 민족, 기간 합이 가장 큰 민족, 모든 민족의 이름(풍선). 보기 조건(대범위 켬/끔 · 소속 펼침)이 줄 구성을 바꿀 때만 달라지므로, **넣을 때 두 상태를 모두 만들어 두고**(설계 6절의 "숨은 줄"과 같은 길) 보기 조건으로 고른다. 제안: `groups`처럼 `row_chips(row, people_id, name, color, all_names, cover_name, host_name, scope_name)` 표.

## 10. 미확인으로 남긴 것

1. **어두운 테마의 값** — 덤프를 밝은 테마로만 떴다. 색 토큰(css:641~645 · 776)은 읽었지만 `color-mix`를 푼 실제 값은 재지 않았다.
2. **`depth === 1`일 때의 가는 딱지(`.tl-pchip.is-thin`, 폭 5)와 `.tl-people.is-scope.is-thin`** — 월흔해는 `depth = 3`이라 실측하지 못했다. 코드(js:3187~3196 · css:1649~1650)로만 읽었다.
3. **트랙 공통 줄(`commonRow`, '그 밖' 줄)** — 월흔해의 모든 트랙이 `commonRow = −1`이라 실측하지 못했다. 코드(7248~7250 · css:265)로만 읽었다.
4. **올림 · 누름 · 초점 상태**(`:hover` · `:active` · `:focus-visible` · `.is-hot` · `.is-selected`) — 정적 덤프라 실제 그려진 값을 재지 못했다. CSS 규칙만 적었다.
5. **`row_labels`의 (가) 안이 지금 연표의 `best`와 늘 같은 띠를 고르는가** — 화면 px 비교와 해 비교가 같은 차례를 주는지 월흔해로 대조하지 않았다. 새 엔진에서 붙일 때 확인해야 한다.
6. **라틴 글자가 섞인 세로 글의 한 자 높이** — `15.5` · `11.8` · `10.1`은 한글 · 한자 기준의 근사값이다. `text-orientation: upright`에서 라틴 글자가 어떻게 세워지는지 재지 않았다.
7. **`_squash`의 흐름을 실제로 재지 않았다** — 7.7절은 코드를 읽어 적은 것이고, 프레임별 자리를 측정하지는 않았다(정적 덤프는 흐름이 끝난 뒤의 값이다).
8. **`_pchipsHTML`의 `t.length`와 다른 곳의 `[...t].length` 차이** — 서로게이트 쌍이 든 이름에서 갈릴 수 있지만, 그런 이름으로 시험하지 않았다.
9. **`fitName`이 조감에서 `room`을 3.5px 좁게 잡는 것**(1.4절) — 지금 연표의 동작 그대로이지만, 의도한 것인지 실수인지는 확인하지 못했다. 새 엔진에서는 **같은 값을 그대로** 옮겨야 그림이 같아진다.
