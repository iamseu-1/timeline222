## 결론

* **가능하고, 비용이 낮습니다.** 이 프로그램은 서버 없이 HTML·CSS·JS 파일만으로 돌아가는 순수 정적 웹앱이라, 웹 화면을 그대로 감싸는(웹뷰) 방식의 포팅이 곧바로 됩니다. 애니메이션·확대 축소·드래그·핀치 줌·저장 등 **모든 기능이 코드 수정 없이 그대로 보존**됩니다.
* 사용자 말씀대로 **연표 앱과 DLC 메이커 앱 두 개**로 나올 수 있고, 하나의 앱 안에 두 화면(탭)으로 넣을 수도 있습니다. 둘은 이미 `js/core.js`를 공유하고 브라우저 저장소(localStorage)로 데이터를 주고받으므로, 한 앱에 넣는 쪽이 자연스럽습니다.

## 방식 비교

| 방식 | 대상 | 장점 | 유의점 |
| --- | --- | --- | --- |
| **PWA** (설치형 웹앱) | PC·안드로이드·iOS 모두 | 파일 2개(`manifest.json`, 서비스 워커)만 더하면 끝. 홈 화면·바탕화면에 설치되고 오프라인 동작 | 앱 스토어 배포는 아님. iOS는 저장 공간 제한이 조금 있음 |
| **Tauri** | Windows·macOS·Linux 실행 파일 | 설치 파일 수 MB로 가벼움. Rust 기반, 웹뷰는 OS 내장 | Rust 툴체인 설치 필요 (코드는 안 짜도 됨) |
| **Electron** | Windows·macOS·Linux 실행 파일 | 자료가 가장 많고 익숙함 | 설치 파일 100MB 안팎 |
| **Capacitor** | 안드로이드·iOS 앱(스토어 배포) | 웹 폴더를 그대로 앱으로 감쌈. 파일 열기/저장 플러그인 제공 | 안드로이드 스튜디오·Xcode 필요, 스토어 등록 절차 |

권장 순서: **PWA → Tauri(PC) → Capacitor(모바일)**. PWA는 지금 코드에 바로 붙일 수 있고, 나머지도 같은 웹 폴더를 재사용합니다.

## 그대로 되는 것

* 확대·축소·드래그·핀치(두 손가락) — 이미 Pointer Events로 구현되어 터치에서도 동작
* 트랙·민족·연호 접기, 계승선·소속선, 지도자·내각 칸, 간지·연호 줄, 범례, 검색
* 사건 추가·수정·숨기기, DLC 설치·켜기·끄기, 백업 — 모두 localStorage
* 이미지(PNG·SVG) 내보내기, CSV 내보내기 — 브라우저 다운로드 API

## 앱으로 갈 때 손볼 것 (작은 일들)

1. **파일 열기·저장** — 브라우저의 다운로드/파일 선택 대화상자가 앱에서는 플랫폼 API로 바뀌어야 자연스럽습니다. `HT.downloadBlob`, `HT.downloadJSON`, `HT.pickFiles`, `HT.readFile` 네 함수(`js/core.js`)만 감싸면 되도록 이미 한곳에 모여 있습니다.
2. **끌어다 놓기 설치** — 모바일에는 없으므로, "파일 선택" 버튼과 "다른 앱에서 공유 → 연표로 열기"로 대신합니다.
3. **저장 용량** — localStorage는 보통 5~10MB. DLC가 많이 늘면 IndexedDB로 옮기는 것이 안전합니다. `HT.store`(`js/core.js`) 한 객체만 바꾸면 됩니다(비동기로 바뀌는 점만 주의).
4. **화면 폭** — 필터 바가 좁은 화면에서 여러 줄로 접히므로(이미 반응형), 모바일에서는 필터를 접이식 서랍으로 바꾸면 더 좋습니다. 상세 패널은 이미 좁은 화면에서 전체 폭으로 바뀝니다.
5. **`100vh`** — 모바일 브라우저 주소창 때문에 `100dvh`로 바꾸는 편이 안전합니다(`css/viewer.css`, `css/maker.css` 각 한 줄).
6. **인쇄** — 새 창을 여는 방식(`window.open`)은 앱에서 막힐 수 있어 PDF 저장으로 대체합니다.
7. **폰트** — 기기에 맑은 고딕이 없을 수 있으니 Noto Sans KR을 함께 묶습니다.

## 준비해 둔 것 / 준비하면 좋은 것

* 코드가 이미 **서버·빌드 도구 없이** 동작하므로 어떤 포장 방식이든 폴더를 그대로 넣으면 됩니다.
* PWA로 시작할 때 만들 파일: `manifest.json`(이름·아이콘·시작 화면), `sw.js`(파일 캐시), `index.html`·`dlc-maker.html`에 `<link rel="manifest">` 한 줄씩.
* 두 앱을 따로 낼 경우 공통 코드(`js/core.js`, `js/timeline.js`, `css/common.css`, `packs/`)는 그대로 복사해 쓰면 됩니다.

## 하지 않아도 되는 것

* 프레임워크(React 등)로 다시 짜기 — 필요 없습니다. 현재 구조 그대로 포장하는 것이 가장 안전하게 모든 기능·애니메이션을 보존합니다.
